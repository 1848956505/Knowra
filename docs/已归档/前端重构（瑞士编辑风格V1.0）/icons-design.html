设计差异总结

旧 (Phosphor Duotone)
  • 256×256 viewBox，单个 SVG 文件
  • Duotone 双色填充，两段路径
  • 路径密度高，缩放到 22px 后细节模糊
  • 通过 <img> 标签引用，color 无法继承
  • Inactive 态用 CSS opacity 减淡 (0.35)
新 (自定义描边)
  • 24×24 viewBox，统一坐标系
  • 纯线条描边，无填充色块
  • 路径精简，小尺寸保持清晰可辨
  • 内联 SVG，color 直接继承
  • Inactive 态用 muted/line 颜色值直接控制
