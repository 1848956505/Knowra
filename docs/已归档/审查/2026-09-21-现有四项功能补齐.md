# 现有四项功能补齐

## 实现范围

| 功能 | 本次行为 |
| --- | --- |
| 桌面功能一致性 | 回收站说明永久删除/清空当前仅支持网页版，桌面入口禁用，store 拦截不支持写入；本机支持分析范围预览，快照保存明确说明同步限制。 |
| 历史记录 | 摘要游标分页、正文按需读取；根据正文哈希标记当前内容；相邻编辑间隔 5 分钟内合并展示，可展开全部快照；提供正文差异、恢复和另存。 |
| 备份与恢复 | 列表选择、完整性检查、用户确认、恢复前自动保护备份、独立目录恢复、重载后使用新资料集；保留原资料、队列和恢复草稿。 |
| 同步冲突 | 正文增删高亮和基线对照；关联资料按实体、中文字段显示变化与删除状态；保留采用本地、云端、两篇及手动合并。 |

## 数据保护

- 历史恢复先保存当前草稿，再通过同一自动保存基线执行恢复；保存失败或中途切换笔记时停止。恢复前正文仍能在历史记录中找回。另存使用新笔记 ID，不覆盖原笔记。
- 历史记录的归组只改变展示，不删除任何不可变来源快照。标注、证据、分析范围、试题和未确认同步记录依赖这些版本；引用安全的自动物理淘汰仍需独立设计，不通过降低自动保存频率节省空间。
- 全库恢复不替换开放的 SQLite 文件；先检查并准备独立目录，等待在途操作与同步结束，创建保护备份后原子切换活动指针。失败保留原服务可用。
- 恢复后的资料集标识改变，旧页面业务请求被拒绝；当前页面明确要求重新加载。原生图片和下载请求仍可读取经会话授权的附件。
- 恢复后的草稿作用域与恢复前隔离。旧草稿继续可导出，不能自动覆盖已恢复正文；新的待保存内容使用新的资料集作用域。
- CLI 救援导出跟随活动资料目录，同时保留根目录草稿；未来 schema 的救援包仍可离线复制，当前应用不会将不受支持版本激活。

## 使用入口

- 编辑器 → 文档检查器 → 历史记录。
- 底部云端同步状态 → 备份与恢复。
- 底部同步冲突提示 → 逐项核对正文和关联字段，再选择解决方式。

本轮不部署在线服务器，不执行用户真实备份恢复、永久删除或冲突覆盖。
