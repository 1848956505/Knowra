什么是「印格」？
印格是 Markdown 笔记应用的视觉方向，源自 Neo-Brutalism，强调"暖纸底 + 硬阴影 + 零圆角 + 蓝色强调 + 点阵桌面"的纸面工作站感。
为什么要做个性化扩展？
基础库偏标准。希望通过印章、便签、胶带、账本等"纸面物件"隐喻，让组件更有个性，更贴合"知境"的产品定位。
如何使用本组件库？
直接复制对应 HTML 片段和 CSS 类名即可。每个变体都是独立的 class，不会破坏印格基础库的使用方式。
