# 表格行列与键盘操作补齐

基线：PR #10 合并提交 `35a3ce1`。范围来自 `现有问题.md` 的表格完善要求，以及 `docs/前端/V4/03-功能保留与验收矩阵.md` 表格行。

## 复现与缺口

表格插入、输入及 Tab 导航已有实现，但正文中没有行列管理/选择/对齐菜单。新增真实 Chrome 页面用例在基线找不到「表格操作」按钮而失败。本批补齐可见入口，不重写已有上传/附件或 AI 能力。

## 实现与保护

- 选中单元格显示固定表格工具栏，提供上下插行、左右插列、行/列/整表选择、列左/中/右对齐和显式删除。
- 使用 Markdown 唯一表头模型，禁止在表头前插数据行、删除表头、删除最后数据行或最后列。列对齐写到表头与同列数据，保证保存重载保留。
- 命令使用 ProseMirror transaction 并隔开各操作历史，连续操作可分别撤销/重做，选择不清空历史。
- 事务完成后刷新控件状态，避免 DOM selectionchange 先发生而菜单沿用旧行位置。菜单打开时捕获 view/doc/selection，操作前复核，过期上下文不写入。
- 菜单关闭后再归还正文焦点，支持键盘撤销；用户已转到其他输入时不抢焦点。阅读模式不显示写入工具栏。
- 独立复审发现长表滚动后控件覆盖固定格式栏；新增回归修复前失败，修复后通过，控件下限包含格式栏底边与 8px 间距。

## 本地验证

- 表格模型 6/6：数据/邻近正文保留，列对齐、CellSelection，表头/最后行列保护，连续操作单独撤销重做。
- V4 全部 Vitest 80 文件、469/469。
- TypeScript、架构边界、生产构建通过；既有大于 500 kB chunk 提示保持。
- 服务器回归 9/9，使用获批的回环端口环境。
- Chrome 合成 HTTP 页面：结构编辑/对齐/保存重载/撤销，以及 700px 键盘菜单/Escape 归焦/阅读态通过。上一批 3 条图片/章节异步页面回归同时复验，总计 5/5。合成粘贴前等待浏览器光标到正文末尾，避免仅 ProseMirror Home 命令结束而 DOM 光标仍在归位时触发过期保护；原安全与撤销断言保持。
