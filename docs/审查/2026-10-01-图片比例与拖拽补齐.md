# 图片比例与拖拽补齐

范围：`现有问题.md` 图片完善与 `docs/前端/V4/03-功能保留与验收矩阵.md` 图片行。上传、附件核验/恢复/删除依赖及下载已有实现；异步上传取消保护已由 PR #10 交付，本批补实际缺失的比例预设与拖拽。

## 复现、实现和验收边界

- 基线真实 Chrome 页面选中图片后找不到「图片尺寸工具栏」，新增用例失败。本批提供小图 40%、中图 66%、大图 82%、适应宽度和角落拖拽，宽高保持原图比例，宽度限制于内容区。
- 旧版图片以数字 alt 保存比例，继续沿用该格式且保留标题。普通图片保持 alt/src/title 说明，在 Markdown title 尾部保留 `{knowra-image-ratio=0.40}` 格式的尺寸元数据；正文渲染和 HTML 导出清除显示标题中的内部尾标记，回到适应宽度时删除元数据。比例限制 0.1–4；原有文件不会批量改写。
- 使用图片 NodeView 响应加载与可用宽度变化；长图不截断或改变宽高比。拖拽仅更新视觉预览，松开时一次 ProseMirror transaction，独立撤销/重做。Escape、失焦、pointercancel、卸载及正文/选区/编辑器变化取消，不落正文。
- 回归发现尺寸观察器会重置拖拽预览，已隔离预览期间观察器；属性 transaction 会失去 NodeSelection，已显式保留；连续图片点击可进入双击/三击分支，已统一保持图片选区。切换选区后再双击并拖拽在正式页面用例中覆盖。
- 固定控件避开格式栏并限制于窄屏；预设可键盘操作，阅读模式隐藏写入控件，取消后的资源仍由附件引用保护管理，不发送删除请求。
- HTML 输出按文档顺序复用实际渲染尺寸，同一附件多次插入可保留不同大小；替代说明、标题和附件地址保留。

## 验证

模型覆盖旧格式、普通说明与元数据更新/清除、宽度边界和连续缩放独立撤销重做；HTML 覆盖同 URL 独立尺寸。生产页面覆盖预设/说明/保存重载/撤销、拖拽提交/Escape/切换选区取消，以及旧比例长图/窄屏键盘/阅读状态，另复验图片上传、原生粘贴、章节焦点与表格批次。
