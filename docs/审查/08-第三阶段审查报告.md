## 4. 已核对的保护机制与判断限度

- JSON 原子文件替换、事务内内存回滚，以及永久删除协调器的整批引用预检均有实现；S3-01 是其他调用链未完整使用事务，不能归因于“没有原子文件写入”。
- 笔记正文写入维护 NoteVersion，并通过回调传播来源 stale/invalid；知识、目标、题目有确认门禁。完整正式资产失效链与双驱动事务回滚仍需运行验证。
- 自动保存按笔记排队并携带并发基线；409 暂停自动覆盖，组件仍在时保留草稿。S3-02 针对离开整个编辑页的生命周期缺口。
- V4 mutation 统一检查 `dataMode === 'api'`。web-core 中允许 local 的通用 guard 不能直接等同于 V4 恢复模式允许写入；已追踪实际 store，未将其误报。
- 附件路径管理校验 ID、受管目录、普通文件与 realpath；主动内容下载使用 attachment、nosniff、sandbox 响应头。上传有 pending/ready/failed 补偿，目录导入有 staging/backup 回滚；symlink 竞态、进程中断与多进程共享目录尚未实测。
- React Aria 浮层由 UI 包装层提供键盘/焦点契约；这属于代码证据，不能替代中文输入法、屏幕阅读器、缩放和真实焦点验收。
