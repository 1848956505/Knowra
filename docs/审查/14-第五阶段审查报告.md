日期：2026-09-06。基线：KNOWRA-REVIEW-20260906-B5；提交 `22231a28b27bba3fb0b0f265e4bd28d505a754dc`，含原有未提交改动。本阶段完成当前环境内可执行的测试、构建及定向专项；真实数据库、跨平台与联网漏洞扫描仍有缺口，不宣称全部专项闭环。

## 1. 核心结论

标准测试、类型/架构检查、生产构建与 Prisma schema 校验全部通过。可明确计数的 API、共享核心、V4 和脚本用例合计 500 项；V3 遗留 runner 另外报告 151 个测试文件成功，不能将其等同于 151 个独立断言用例。

既有浏览器套件首次完整运行 48 项：43 通过、5 失败、0 跳过。4 项失败由旧功能断言或缺失接口 mock 导致，在审查副本中纠正后全部通过；另 1 项表格操作在原用例单独串行复跑及两个真实 API 页面样本中通过，暂记不稳定结果。原测试未修改，不能把诊断副本的通过数改写为原套件全绿。

新增 3 项确定问题，详见 [16-第五阶段问题与待验证项](16-第五阶段问题与待验证项.md)：

- **S5-01 / P2**：大于 8 MiB 的 JSON 请求被直接断开，经生产代理后成为 500，而不是可识别的 413。
- **S5-02 / P1**：备用文件替换流程中断后，主文件缺失但备份仍在，启动却创建空库；需人工识别并恢复旁边的备份。已在真实子进程中注入替换错误并强制终止；不是实机 Windows 认证。
- **S5-03 / P2**：4 项现有编辑器 E2E 与图片功能、关联查询接口不一致，阻断完整回归并掩盖其后断言。

S2-06 的规模风险得到量化：1 万篇笔记在浏览器发出 334 次分页请求，图标视图创建 1 万个卡片节点。按本机一次冷启动样本，初始卡片约 3.7 秒出现，最后一页查询约 9.8 秒完成。没有预先约定 SLO，因此以确定的请求/节点增长和环境测量报告，不凭单次耗时判定所有设备的性能达标或不达标。
