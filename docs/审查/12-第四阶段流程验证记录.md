## 3. 重跑入口与证据口径

在仓库根目录、已安装依赖和 Playwright Chromium 的环境运行：

```sh
node docs/审查/证据/阶段4/http-flows.mjs
node docs/审查/证据/阶段4/browser-flows.mjs
node docs/审查/证据/阶段4/browser-index-flows.mjs
node docs/审查/证据/阶段4/browser-recovery-flows.mjs
node docs/审查/证据/阶段4/browser-import-flow.mjs
```

脚本使用实际 API/前端与自建临时目录，执行后关闭自己启动的服务并清理数据。脚本会写入同名结果和截图；复核历史时先复制证据目录，避免覆盖本次原始记录。不要改为指向真实 storage。运行需要本地监听与浏览器启动权限，且不等于运行仓库注册的全部测试。

H03 初次误读返回形状；H07 初次把 verifiedAt 等易变元数据和启动补齐分组当作严格相等对象；H14 初次标注请求缺少必填字段。B03 调整了启动/缓存准备和恢复文案断言；B07 修正编辑器定位。对应初次失败保留，不作为产品发现；H07 中分组补齐的异常已由独立 H12/B08 确认 S4-02。
