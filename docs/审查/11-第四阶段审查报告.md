## 2. 实际环境与方法

- Node v26.4.0；local-json；用实际 `createAppContext`、`createServer` 在动态回环端口启动 node:http。使用独立临时 data.json 和附件目录。
- Chromium 151.0.7922.34，1440 × 1000；加载实际 V4 源码，Vite 同源代理连接上述真实 API。隔离 Vite 缓存，使用 React 插件与 web-core 源码别名；不是生产构建或生产代理验证。
- 磁盘失败在审查 fixture 的写入适配器中注入；断网用浏览器请求拦截；冲突由另一客户端改动触发。中文分块场景发送真实 HTTP 字节块。
- 浏览器操作使用 Playwright。创建、输入、菜单、文件上传、视图切换、分页、导入及恢复保护均有页面断言；关键结果进一步核查 API、附件文件或重启读取。接口场景不冒充所有业务都有 UI 入口。
- 默认 fixture 在创建空间后重启，使后续场景具备系统分组；H12/B08 专门不重启，验证首次使用。不能把其他场景通过解读为首次初始化无问题。
- 本轮监听与浏览器启动最初受沙箱限制；隔离回环启动获自动批准后完成验证。未连接真实 PostgreSQL，未操作用户开发服务器或真实 storage。
