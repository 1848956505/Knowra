## 中断替换后的恢复步骤

1. 停止 API 进程，完整复制数据目录作为恢复前备份，保留所有 `.bak` / `.tmp` 文件。
2. 根据错误信息定位主文件对应的候选，在隔离目录核验 JSON 内容及关联引用；不要仅按修改时间自动选择文件。`.bak` 通常是替换前版本，`.tmp` 可能包含未提交的新版本。
3. 将确认完整的候选复制为隔离目录中的主文件，用 `createFileDataStore()` 验证可加载并核对业务数据。确认后再复制为正式主文件，保留原候选。
4. 重启 API 并核对数据；无可确认的完整候选时，从已验证备份恢复。
