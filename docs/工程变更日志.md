# 工程变更日志

本文档是 **Study Accelerator** 项目的**唯一**变更日志，主要读者是 **AI Agent**。

本文档同时承担「产品变更日志」与「工程变更日志」两种职责：
- 「产品变更」放在 `Added` / `Changed` / `Fixed` / `Removed` / `Deprecated` 章节
- 「纯工程变更」放在 `Refactor` 章节
- 「工具/构建/CI 变更」放在 `Chore` 章节

> 📌 **维护原则（给 Agent 看）**
> 1. 每次完成结构性变更（新增/拆分/迁移文件、依赖升级、构建脚本、API 行为变化）必须**在本文档对应版本下加一条**
> 2. 每条记录末尾用**括号标注平台**（见下方规则）
> 3. 旧版本不要修改，只在 [Unreleased] 或新版本下追加
> 4. 写完后 grep 验证段落结构没坏

## 平台/系统标注规则

每条记录末尾用括号标注涉及的平台，便于 Agent 快速判断是否需要考虑平台差异。

- **不标 = 默认全平台**（macOS / Windows / Linux/Ubuntu / Web）都行
- 常见标签：

  | 标签 | 含义 |
  | --- | --- |
  | `macOS` | 仅 macOS 客户端 |
  | `Windows` | 仅 Windows 客户端 |
  | `Linux/Ubuntu` | 仅 Linux/Ubuntu 客户端或服务器 |
  | `Server` | 仅服务端（部署在 Linux/Ubuntu 上的 Node 进程） |
  | `Web` | 仅浏览器端运行 |
  | `多端` | 涉及 2 个及以上平台 |

- 示例：
  - `（Server）` —— 仅服务端 Linux/Ubuntu
  - `（macOS）` —— 仅 macOS 客户端
  - `（多端）` —— 涉及 2 个及以上平台
  - `（macOS + Server）` —— 同时涉及两端

## [2.0.0 ~ 2.0.5] - 2026-07-04（项目初始化里程碑）

> v2.0.0 ~ v2.0.5 是 [`docs/已归档/开发计划/V2.0开发计划.md`](已归档/开发计划/V2.0开发计划.md) 中的开发计划路线图，作为里程碑一起记录在此。
> 本仓库 git 起点是 `43cae67 feat: 初始化 Knowra 项目并修复跨平台编辑器兼容性问题`。
> 之前的 v1.x 历史规划见 [`docs/已归档/`](已归档/)。

### Added

#### 项目骨架
- 项目初始化（commit 43cae67）：本地优先知识库工作台（多端）
- 后端：plain Node.js HTTP API + DDD 风格分层（`apps/api/src/{domain,application,infrastructure,http}`）（Server）
- 前端：vanilla JS SPA + 模块化拆分（`apps/web/src/{app,controllers,services,server,client.js}` + `apps/web/lib/*`）（Web）
- 编辑器：Milkdown 集成（`apps/web/lib/editor/milkdown-entry.js` + bundle 产物）（Web）
- 数据持久化：本地 JSON 文件 `storage/data/knowledge-base.json`（Server）
- 自动化测试：API + Web 都用 Node.js 自定义 runner（无 Jest/Mocha）（多端）
- 部署：阿里云 ECS + Nginx + PM2（Server）
- 客户端覆盖：macOS / Windows / Web 三端均验证可运行（多端）

#### v2.0.0 数据底座
- 知识点能力：新增实体 `KnowledgePoint`、`KnowledgePointSource`、`TagGroup`、`KnowledgePointTag`、`NoteKnowledgePoint`（Server）
- 扩展本地 JSON 状态，兼容旧 `knowledge-base.json`（Server）

#### v2.0.1 标签体系
- 4 个预定义标签组：`ordinary`（多选）、`mastery`（单选）、`importance`（单选）、`purpose`（多选）（Server + Web）

#### v2.0.2 右侧知识点面板
- 接入右侧栏 `知识点` Tab（Web）
- 顶部数量、搜索筛选、卡片列表、展开卡片、编辑标题/注释/标签、原文片段列表（Web）

#### v2.0.3 正文选区创建闭环
- 编辑器右键菜单加「创建知识点」（Web）
- 选中文本 → 创建知识点 → 右侧卡片展示 → 保存（Web）

#### v2.0.4 双向定位与轻量标记
- 正文 marker ↔ 右侧卡片双向定位（Web）
- 选区快照 + context/offset 轻量定位（Web）

#### v2.0.5 管理增强
- 加入已有知识点（Web）
- 一个知识点支持多个原文片段（Web）
- 卡片搜索、普通标签筛选、系统标签筛选（Web）
- 「从当前笔记移除」与「删除知识点」区分（Web）

#### 配套基础设施
- 文件菜单：新建/导入/复制/导出（MD/HTML/PDF）（Web）
- 标签页系统：多笔记 tab、关闭、拖拽、复制路径（Web）
- 查找/替换面板（Web）
- 表格插入弹窗（Web）
- 拖拽移动文件夹和笔记（Web）
- 回收站：软删除、恢复、永久删除、清空（Web + Server）
- 收藏、最近访问分组（Web）
- 知识点 marker 装饰、图片块增强（Web）
- 跨平台端口管理：`scripts/dev-runtime-ports.js` + `scripts/start-dev.mjs`（多端）
- Windows 兼容入口：`scripts/start-dev.ps1`（Windows）

### Changed
- 前端从单一 `client.js`（~5300 行）重构为模块化（`src/{app,controllers,services,server,client.js}` + `lib/*`），入口收敛到 ~150 行（Web）
- 拆分 `apps/api/src/server.js` → `http/{cors,request,response,storage-routes}.js` + `modules/knowledge/http/*-routes.js`（Server）
- 拆分 Milkdown 编辑器：Host 门面、commands、plugins、table、schema 各成子目录（Web）
- 拆分 `apps/web/src/client.js` 为 10+ 个 controller 和 event binder（Web）
- 拆分 `apps/web/styles/components.css` 为 `styles/components/*`（Web）

### Fixed
- 修复 note route 直连 service、Milkdown 图片上传直连 fetch、`knowledge-api.js` 过密、API client 双 envelope 兼容壳、JSON body 无大小限制、`src/styles.css` 混入任务列表样式、styles demo 文档不同步等问题（多端）
- 修复浏览器 ESM 静态访问问题，`main.js` 静态白名单补充 `/src/controllers/`，避免 controller 文件 404（Web）

### Chore
- 引入 CORS 处理模块（默认关闭，可选启用）（多端）
- 引入 npm workspaces 协议（`apps/*` + `packages/*`）（多端）
- Node.js 版本要求：`>= 24.0.0`，npm `>= 11`（多端）
- 添加 Prisma schema 脚手架（`prisma/`），尚未启用（Server）

### Refactor
- 全面按职责拆分大型文件：editor / navigation / sidebar / knowledge-point / file menu / shell / status 等 controller 拆分为子 controller（Web）
- Milkdown 内部按 `milkdown/{commands,plugins,schema,table,host,utils}` 子目录组织（Web）
