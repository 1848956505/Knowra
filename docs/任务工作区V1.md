# 本地任务工作区 V1

## 宿主与数据边界

- 支持桌面 SQLite 与 API `local-json`。PostgreSQL 返回 `TASK_WORKSPACE_UNAVAILABLE` 能力状态，不创建旁路 JSON；普通笔记功能保持可用。
- 工作区、文档、任务、执行尝试与操作回执为独立五聚合。JSON 顶层 `taskWorkspaces`、SQLite 独立表保存；扩展版本独立于 AI schema。未知版本或损坏数据只关闭本域，保留原文。
- 工作区不加入普通笔记同步、搜索、附件集合与 AI 知识空间授权。普通笔记快照不包含任务；桌面完整备份包含 SQLite 与 uploads，JSON 完整备份需保留原数据文件及 uploads。两宿主的普通笔记快照导入、以及桌面受管完整恢复会更新本域 epoch，旧页面和旧执行不能继续写。手工覆盖 JSON 原文件不是应用内的完整恢复流程；运行中的其他实例检测文件变化后关闭本域读取，需重新打开。
- 不自动调用模型。用户建立、发布和验收任务；外部 Agent 经单独配对许可领取、续租、协作文档、报告、提交或释放。旧配对默认无任务权限。

## 接线入口

- `apps/api/src/modules/task-workspaces/`：唯一领域服务、状态机、结构关系验证和 HTTP 协议。
- `apps/api/src/infrastructure/task-workspace-*.js`：JSON repository 与受控图片验证、存取；`file-data-store.js` 承担原子写入、事务回滚与坏数据保留。
- `apps/desktop-runtime/src/task-workspaces/`：SQLite schema/repository 与完整备份恢复；`runtime-services.mjs` 重建 service，`runtime-server.mjs` 的 getter 在恢复时跟随新资料库。
- `apps/desktop-runtime/src/mcp/task-*.mjs`：配对范围、执行与安全文本/图片出口。事务内重验实时授权，不能以 Agent 自报身份授予权限。
- `packages/web-core/src/api/task-workspace-api.ts` 与 `task-workspaces/`：共享 DTO/API；`apps/web-v4/src/features/task-workspaces/`：页面、草稿与本域图片限制。

## 接口与限制

HTTP 根路径 `/api/task-workspaces`；先读取 `/capabilities`，mutation 必须带 `X-Task-Workspace-Epoch`，正文使用 UUID `operationId` 及适用的 `expectedRevision`。服务端产生 actor/identity，拒绝客户端伪造身份字段。同操作重试重用回执，异 payload、过期租约与 CAS 冲突明确拒绝。

图片仅接受 PNG/JPEG/WebP，最大 5 MiB 和 16 MP；通过 sharp 真实解码，元数据不外泄本机路径。图片通过精确文档版本和不可变 hash 验证。工作区编辑器拒绝远程/私人笔记图片与外部资源自动加载。

## 原生图片依赖与构建

`sharp` 使用 npm 官方包的 pinned 版本与 lockfile，`npm ci --ignore-scripts` 即可安装当前平台预编译模块。API 与 desktop-runtime 声明生产依赖。Windows/Linux 使用本机 npm 安装，不复用其他平台的 node_modules。

Mac 构建仅在 Apple Silicon macOS 运行。esbuild 将 sharp 保持 external；`native-image-runtime.mjs` 复制当前平台生产依赖闭包并拒绝跨平台/架构构建。验证器要求依赖确实存在于产物内部，拒绝向上回退到开发依赖。构建阶段和 Mac CI 对隔离 staging / 最终 APP 执行 PNG/JPEG/WebP 真实解码。Linux 上通过此测试不代表 Mac 应用已经通过实机验收。

## 验证入口

- `npm run test:api`：显式 runner 注册领域/HTTP/JSON 测试。
- `npm run test:desktop`：SQLite、图片、备份恢复、MCP 与宿主回归。
- `npm run test:web-core`、`npm run check:web:v4`：DTO/API、类型、架构和 UI。
- `node --test apps/desktop-shell/test/native-image-runtime.test.mjs`：隔离生产依赖闭包的真实解码与错误平台拒绝。
- `npm run test:e2e -w @study-accelerator/desktop-runtime`：真实合成页面、实际设置配对与 stdio 闭环验收；CI 保留合成页面截图，不上传资料库、配对文件或凭据。

验证只使用合成资料；不读取真实笔记、模型凭据，不要求真实模型调用、远程监听或部署。此次不新增公网监听、不部署服务。最终通过情况以当前提交测试日志与 CI 为准；本地检查点提交不等于完整验收通过。

受限本地执行环境若拒绝 Unix socket（`EPERM`），真实 stdio / 配对 / 完整页面闭环仍为待验收项，必须由 CI 原始测试门禁执行通过；不能以跳过、模拟接口或仅语法检查代替。
