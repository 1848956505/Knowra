# AI-01-06 助手与任务交互

> 适用范围（2026-09-27）：本文件记录原 P1 的实现与验收，文中的状态、日期和通过数不代表新版 Agent 已完成。范围问答基础继续复用；多轮对话、自动库检索、授权 v2 与插件故障隔离按 [补齐方案](../06-P1对话Agent补齐方案.md) 和 [任务表](../04-分阶段开发任务.md) 另行实施。旧发送预览流程仅作为显式指定范围/历史复测入口，不是普通聊天的必经步骤。

状态：**代码与合成验收完成，未发布；真实生成仍关闭**。日期：2026-09-27。

## 交付

- V4 左轨和移动端增加「AI 助手」入口。页面显示当前模型、执行位置（本机／服务器）、可用性、知识空间内最近任务；选一篇笔记或一个目录后输入问题，先检查接收方、实际片段正文与遗漏，再明确确认。切换问题或范围会废弃旧预览。
- 同源 `/api/ai/assistant` 提供状态、预览、确认创建、任务列表／详情、取消。预览中的待发送请求仅在服务端内存保留五分钟，确认请求带范围和完整外发体哈希；确认前不写授权或任务。POST 要求自定义请求头，响应不包含密钥或内部请求体。
- 任务状态由服务端持久记录，页面每两秒轮询进行中任务；刷新后从当前资料集和知识空间回读最近任务。已核验的回答与引用保存在 AI 私有任务记录中，不进入普通业务快照／同步；成功状态与结果在同一次任务记录更新中提交。引用按钮读取不可变笔记版本，显示 UTF-16 范围高亮的原文，再可打开对应笔记。
- Worker 对待执行任务可直接取消；重启时未执行任务转失败，已送达但未结算的尝试沿 01-04 保守恢复。Web 服务在助手路由首次使用前运行恢复，Mac 仍由本地服务启动流程恢复。
- SQLite 增加 v4→v5 备份迁移；PostgreSQL 增加 `b_ai_assistant_result` 迁移；JSON 私有记录沿用现有原子持久化。新字段只存问题和通过 01-05 校验的回答／引用。
