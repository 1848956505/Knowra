# AI-01-07：桌面路由、能力声明与真实小样本

> 适用范围（2026-09-27）：本文件记录原 P1 的实现与验收，文中的状态、日期和通过数不代表新版 Agent 已完成。范围问答基础继续复用；多轮对话、自动库检索、授权 v2 与插件故障隔离按 [补齐方案](../06-P1对话Agent补齐方案.md) 和 [任务表](../04-分阶段开发任务.md) 另行实施。旧发送预览流程仅作为显式指定范围/历史复测入口，不是普通聊天的必经步骤。

日期：2026-09-27。状态：**开发与本机验收完成，尚未发布云端／Mac 新版**。云端真实页面、Mac 与云端共享预算的实网调用、真实 PostgreSQL 仍未验收。

## 交付

- 桌面本地运行时放行助手状态／任务读取及受信预览、启动、取消路径，保持其他 AI 写入路径受限。未配置 Mac 凭据时仍可读取明确的未配置状态。
- 所有桌面助手 HTTP 请求（包含只读状态与任务列表）都必须携带页面加载时注入的 `X-Knowra-Dataset`。备份恢复后旧窗口无法读取新资料集助手记录，也不能确认旧预览；新页面取得新资料集标识后才能继续。
- 助手状态公开当前执行位置、可用性、只读范围、轮询与取消能力、供应商**声明**能力及其当前运行时是否**实测**，不把供应商声明当作已验证。预算不可达／耗尽、模型未核价、价格过期均给出明确原因；确认前再次读取预算状态。
- 2026-09-27 核对 [DeepSeek 中文价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)后，以 `deepseek-flash` 高峰期、输入缓存未命中价格（输入 2 元／百万 token、输出 8 元／百万 token）建立人民币价格版本；低峰和缓存命中仍保守按该档预留。此版本于 **2026-10-05 08:00 北京时间**失效，须重新核价发布，否则自动停止付费调用。其他模型即使密钥可用也不能套用此价格。紧急停止可设置 `KNOWRA_AI_EGRESS_ENABLED=0` 并重启运行端。
- Worker 在预留后、发送前再次检查价格有效期与北京日期。预留跨零点时释放旧日额度且不发送；继续沿用单任务最多 2 元、北京日 10 元的预算限制与发送前来源复核。用户确认 Mac 与云端 Key 属于同一 DeepSeek 计费账户；Mac 实际执行仍必须连通云端唯一预算权威。

## 发布与未验收边界

- 当前安装的 Mac 应用和云端服务仍是旧版本；本次源码与构建验收不会自动改变它们。Mac 的现有云端同步处于暂停状态，真实付费调用会按设计因预算不可达而拒绝；恢复同步须由用户在应用中决定。
- 发布新版后，需分别核对云端 Web 的真实页面、Mac 在云端预算连通时的同账户共享预留／结算、以及重启和版本回读。现有服务器内存不支持真实 PostgreSQL 验收，继续使用 `local-json` 时不因此伪称 PostgreSQL 已通过。
- 本次真实小样本验证了一条可回答的合成笔记。它不是 80 条质量样本与 20 条对抗样本的完整人工评测，也不证明所有回答正确。P1 当前只提供只读问答，不提供笔记写入工具或多轮对话。
