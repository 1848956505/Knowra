# AI-01-R01 插件隔离与执行边界

日期：2026-09-27。状态：本地代码与故障注入验收完成；跨环境、正式 Mac 包及真实模型组合验收归 AI-01-R07。旧 P1 范围问答仍是当前交互，R01 不表示对话 Agent 已交付。

## 交付

- `KNOWRA_AI_ENABLED=0` 提供无 AI 运行实现；插件装配失败或 JSON/SQLite AI 私有状态损坏时，核心资料服务仍可启动和保存。损坏的 JSON `aiRuntime` 原文保留，不以空数据覆盖。PostgreSQL 私有表运行中失效由助手状态报告，并将相关列表请求限定为 503；核心健康、笔记和同步路由不依赖它。
- 实际任务执行搬至独立子进程。宿主只开放当前任务的 AI 记录、预算、凭据引用和来源校验白名单桥；子进程不能直接持有笔记、知识、同步或业务写入服务。供应商调用也可使用单独子进程适配器。关闭或桌面资料库替换时停止活动任务，迟到结果不能写回已关闭资料库。
- V4 助手模块按需加载，局部错误边界捕获模块加载及渲染故障；返回笔记入口留在常驻外壳内。重试会重新加载页面，以清除失败的动态导入缓存。
- Mac 打包将两个子进程入口与运行时一起打包；Electron 子进程以 Node 模式启动。独立进程和受控桥为后续 R02–R04 的授权与工具循环保留接口，不提前开放写工具。

## 资源与退化门槛

| 限额 | 当前值 |
| --- | --- |
| 同时运行 / 排队任务 | 2 / 8；超额拒绝 `AI_QUEUE_FULL` |
| 单任务进程墙钟时间 | 100 秒；超时终止并保守处理已发送请求的预算 |
| CPU / RSS / V8 heap | 20 秒 CPU、192 MiB RSS（子进程心跳与宿主 `ps` 兜底采样）、128 MiB heap；采样无法取得数据时由墙钟限额终止 |
| IPC 请求 / 响应 | 1 MiB / 4 MiB；模型适配器另有 4 MiB 响应上限 |
| 临时文件 | 子进程没有临时文件或业务文件接口；本任务不产生 AI 临时文件。后续若增加文件型工具，必须另设目录和硬配额。 |

同一环境、每组 8 次“新建笔记 → 读取笔记 → 查询同步状态”的 HTTP 组合操作，验收阈值冻结为：故障期 p95 小于 `max(250 ms, AI 空闲期 p95 × 3)`，最大阻塞小于 1000 ms。该门槛用于 R01 的本机隔离回归；R07 需在 Web、正式 Mac 和 PostgreSQL 上重测并记录真实分布，不能引用本机数值替代发布验收。

本机实测：AI 关闭 p95 9.2 ms、空闲 p95 10.1 ms、执行进程卡死期 p95 11.0 ms，故障期最大 11.0 ms。每次样本只覆盖上述三个 HTTP 操作的组合耗时，不代表单接口生产 p95。
