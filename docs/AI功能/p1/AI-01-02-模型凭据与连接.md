# AI-01-02：模型凭据引用、设置与最小连接

日期：2026-09-26。状态：**代码与本地模拟验收完成，Mac、本机 Web 和云端 Web 运行端的真实账号只读连接检查通过。** 设置页由先前工作实现，本次补齐运行时引用和 Mac 进程桥。

## 实现

- V4「设置 → 模型接入」保留手动保存、更换、移除和只读 `GET /models` 检查；Mac 使用 Electron `safeStorage` 加密后保存到应用 `userData` 受限文件，Web 使用服务端 `0600` 文件。服务端和 Mac 检查均禁止 HTTP 重定向，不发送笔记或生成请求。
- [Web 凭据服务](../../../apps/api/src/modules/ai/model-settings.js)和[Mac 凭据服务](../../../apps/desktop-shell/src/model-settings.cjs)在私有记录中生成随机 `credentialRef`。只改无关设置时保持引用，更换密钥或模型时轮换；旧引用失败关闭。旧格式凭据文件在首次内部取引用时原子补充随机引用。
- Web 运行时通过服务内部 `credentialReference()` 与 `resolveCredential(ref)` 读取，HTTP 状态接口只返回供应商、模型 ID 和配置状态，绝不返回引用或密钥。
- Mac [主进程处理器](../../../apps/desktop-shell/src/ai-credential-handler.cjs)与[utility 进程桥](../../../apps/desktop-shell/src/ai-credential-bridge.mjs)只处理随机请求 ID、引用及凭据解析；不通过 preload、renderer 或 HTTP 开放。Gateway 当前默认预算拒绝，因而不会借此读取密钥并发起生成。
