# AI-01-R05 对话主页面与状态恢复

日期：2026-09-28。状态：V4 本地页面和合成回归完成。真实模型跨环境、正式 Mac 包及 PostgreSQL 验收仍由 R07 执行。

## 交付

- `/assistant` 以 v2 会话为主入口。新对话默认普通聊天，不要求先选笔记；用户可从同一会话连续追问。会话 ID 保存在 hash URL，刷新或退出重入后按序回读消息和最后一轮状态；运行中每 2 秒轮询，网络恢复时重读，失败可手动重新加载。
- 首次需要引用资料时，用户在弹窗中明确授权当前知识空间、单个目录或单篇笔记，选择 1/7/30 天有效期；页面说明只有相关且合法的片段可能发给 DeepSeek，附件不发送。后续轮次可复用有效授权，用户可撤销。普通聊天的 `requestedPolicyId` 为 `null`，不会读笔记；发送请求显式使用 `execute: true`，问题限制 3800 个 UTF-16 单位。
- 回答将引用列为来源卡，可读取不可变笔记版本并核对版本/摘录哈希，定位引用范围；检索与调用记录按需展开。Agent 的首轮自动检索也写入工具轨迹，页面不会把这一步误报成“没有读取”。运行、检索、生成、失败和中断状态在会话内显示，支持停止与显式重试。新建与发送使用稳定 ID/幂等键，同一请求的连接失败后可原样重试。
- 旧 v1 任务经 `/assistant?view=legacy` 回看，使用 R03 的只读历史入口，不提供旧版新建、预览或取消操作。模型状态与读取授权接口分别加载；一处暂时失败不清空已恢复的会话消息，助手模块加载错误仍由原局部边界接管。
