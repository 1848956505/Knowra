# AI-01-05：只读范围、检索片段与引用校验

日期：2026-09-26。状态：**受信应用服务代码与合成验收完成；无助手页面、任务创建路由或真实资料外发。** 真实 DeepSeek 生成仍关闭，生产运行时没有有效价格配置。

## 实现

- [只读上下文服务](../../../apps/api/src/modules/ai/read-context-service.js)从服务端已确定的 owner 和资料集出发，先核对空间归属，再读取明确选中的选区、Markdown 标题、笔记、多笔记或目录。目录只固定当时的子目录和笔记；新增笔记不会进入旧范围。知识对象范围与附件暂不开放。
- 只读取当前笔记正文对应的不可变 `NoteVersion`。UTF-16 左闭右开偏移不能切断代理对；来源片段记录版本正文哈希、逐字摘录哈希与稳定来源 ID。标题范围须覆盖完整标题章节。范围超过 128 个片段或 20 个子目录时拒绝，要求用户缩小范围。
- 授权范围内做关键词检索和确定性排序。输入预算以实际外发 JSON 请求体的 UTF-8 字节数作为保守 token 上界；排除、未命中与预算遗漏均进入 manifest。选区只发送选中原文，不扩展到整篇；模型请求只含已选片段、问题和必要来源 ID，不含附件。预览包含片段原文、接收方、估算及遗漏。
- 受信调用方展示预览并取得用户确认的 `scopeHash` 和 `payloadHash` 后，服务重新核对版本、目录、资料集，再持久化不可变 scope／manifest 与五分钟只读 grant。后续 Worker 在预留前及发送前复核来源；实际请求体哈希必须等于 manifest，变更消息或工具定义会在读取密钥前被拒绝。
- 回答采用 JSON `{ answer, citations }`；非空回答须带引用。每条引用只接受 manifest 中已发送的来源，并逐字核对不可变版本的 UTF-16 范围。回答格式或引用无效时不能将任务记为成功。此校验只证明引文确实存在，语义是否支持回答仍需模型质量评测。
- [预算报价](../../../apps/api/src/modules/ai/worker.js)改为使用与 [DeepSeek adapter](../../../apps/api/src/modules/ai/infrastructure/providers/deepseek-adapter.js)相同的[请求体序列化](../../../apps/api/src/modules/ai/outbound-payload.js)，覆盖消息、工具定义、模型与输出配置；超大工具 schema 在预留前拒绝。预留仍不能直接控制供应商的最终账单。
