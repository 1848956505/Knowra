# AI-01-04：有界执行器与跨端预算

日期：2026-09-26。状态：**代码与隔离验收完成；未发布、未进行真实付费生成。** 当前生产运行时仍将 `allowExternal` 留为 `false`，且未装入有效价格配置。AI-01-05 完成实际发送范围核验前，不开放生成入口。

## 实现

- [Worker](../../../apps/api/src/modules/ai/worker.js)按 CAS 将任务从 `pending`／`retrying` 领取为 `running`，逐次记录 attempt 与递增租约代数。单任务最多 4 次、输入保守上界 100,000 token、输出上限 20,000 token、最多 8 个只读工具；取消会中止在途调用，结果接纳前再复核租约、资料集 epoch、授权和任务状态。失败后只允许显式重试；发送后的错误保守记为费用未知，不自动再次发送。
- [预算账本](../../../apps/api/src/modules/ai/budget-ledger.js)以 `deepseek-primary + 北京日期` 为权威键。每次调用先原子预留，按账户合计的已结算费用与仍占用的预留不能超过 10 元；同一任务所有 attempt 的累计预留不能超过 2 元。已知用量按价格版本结算，未知用量持续占额，后续可按核实账单转为已结算或确认未收费后释放。价格配置缺失或过期、网络不可达、预算不足一律拒绝执行。
- 云端 JSON 在私有原子文件中保存账本；[PostgreSQL](../../../apps/api/src/modules/ai/postgres-budget-authority.js)新增 [迁移](../../../prisma/migrations/b_ai_budget/migration.sql)，以计费账户 advisory lock 串行化跨 owner／设备预留；两者通过受部署 Basic Auth 保护的 `/api/ai/budget/*` 提供同一权威。Mac 的[远端客户端](../../../apps/api/src/modules/ai/remote-budget-authority.js)复用已配置云端同步连接的认证和地址，断网或断开同步时拒绝预留；本地 SQLite 仅保存任务用量，不另给 10 元额度。
- [Gateway 运行时](../../../apps/api/src/modules/ai/runtime.js)只认可 Worker 在成功预留后临时登记的 attempt 票据；票据在调用结束后立即撤销，未持票时在读取 API Key 前阻断。服务器启动时恢复过期任务；Mac 启动和重新连接云端时尝试恢复，云端预算不可达时推迟恢复且不执行付费调用。

## 后续边界

预算限制的是 **Knowra 对模型调用的预留和账本**。供应商最终账单可能因价格调整、计量差异或发送后丢响应而高于估算；这种情况保持未知占额并阻止继续调用，不能承诺直接控制供应商侧扣费。开启真实调用前须核对当前价格版本、实际账号与计费账户对应关系，并完成 AI-01-05 的来源范围和 payload 核验。当前没有助手 UI、任务创建路由或用户资料外发，也没有云端／Mac 新版发布验收。
