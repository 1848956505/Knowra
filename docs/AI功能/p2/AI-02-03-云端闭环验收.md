## 契约

受信 UI 用显式记录入口提出新建 / 追加 / 局部改写 / 整理指令，读取授权不授予写入权限。首版所有动作均预览并明确确认；确认绑定服务端生成的 planHash、actor 和有效期。客户端不可提供 operationId、新建 noteId、基线、回执或审核状态。动作响应失联后用原 requestId / actionId 查询恢复，不重建盲目追加。

私有动作账本不与业务同步；最小核心回执、版本和现有同步日志共同落库。提交后私有状态更新失败返回 applied 核心回执并标记待对账；未知核心回执必须停止，不可当作未提交。撤销是新计划，新建撤销只进回收站；正文恢复通过正常版本/标注服务，后续修改必须冲突。
