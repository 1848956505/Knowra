# AI-02-01 固定目标与正文计划

日期：2026-10-01。状态：计划契约与本地回归已实现，尚未接入 Agent 写工具、用户批准、持久动作 ledger 或核心提交，不代表笔记写入已验收。

## 当前产物

- `contracts/note-tools-v1.schema.json` 为新建、追加、精确局部替换定义版本化模型字段白名单。禁止模型提供目标新 ID、operationId、基线、授权、状态、回执或批准字段；未注册工具和原型名称均拒绝。
- `note-plan.js` 只构建不可变 `planned` 结果。宿主固定 actor/owner/dataset/epoch/space/request/operation/目标 ID，重试不重新分配 ID；同输出同基线计划哈希稳定，不同迟到输出不同 hash，由后续 ledger 决定首次接纳权。
- 新建只接受宿主允许的目录、标签，复用领域 DTO 内容策略。追加使用宿主固定的 UTF-16 位置（默认末尾），原样插入包含换行的内容；模型不能自选锚点。已有笔记保留 expectedUpdatedAt、正文 hash 和元数据 hash。
- 局部替换要求确切 start/end/quote，一次基于同一快照应用不重叠片段；重复原文不会模糊全局替换，emoji 代理对边界不能切断。无变化、越界、重叠、失效/跨空间目标拒绝，原始快照不变。
- 计划包含 before/after/edits 供后续差异与撤销预览，planHash 覆盖身份、操作、目标、内容与基线。`requestBound` 只说明所需授权模式，仍未授予任何写权限；改写标记 `previewRequired`。现有只读 Agent 不注册这些工具，能力接口仍不声明可写。

首版每个模型建议正文/替换字段最多 100000 字符，局部替换最多20片段，最终单篇计划正文最多400000 UTF-8字节，超限明确失败；不自动改写现有长笔记。业务提交时仍必须重查当前状态与所有 CAS，计划生成时的检查不能代替事务内检查。

## 验收与剩余
