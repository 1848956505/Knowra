# 对话文件与图片输入实施计划

日期：2026-10-04。四包已由 PR45 合并至 `1a74f1227d7d5166e3d32f25b47ec6ac9bb19636`，精确主干 CI37190900036 全绿。本文件继续区分附件的已实现基础与尚未完成的问答/视觉能力；下方原有审计记录对应附件开发之前。

## 用户已确认

首版对话支持 PDF、Word、TXT/Markdown、PNG/JPEG；支持图片粘贴、预览、移除及失败提示。附件默认属于当前对话，用户要求保存或明确采纳时才进入笔记库。围绕附件问答和生成笔记稿复用自主助手及成果收件箱。

具体 Word 格式与大小限额按安全可实现范围定义，不推导为所有二进制格式兼容。工程建议先支持 DOCX，旧 DOC 明确提示不支持；每文件5MB、每轮最多4份仅为待落实的工程建议，PDF页数、图片像素与解压展开量另设限。

## 当前实现证据

- `MarkdownImportDialog.tsx` 读取 Markdown并立即入正式笔记，不满足默认归对话；现有附件需 noteId，只存二进制与校验信息，没有 PDF/DOCX/OCR 解析。
- `gateway.normalizeAiRequest` 只接受字符串 content。纯合成 image_url parts 被拒 `AI_REQUEST_INVALID`，实际供应商调用0。
- v1/v2来源都未注册对话附件；v2 `includeAttachments:false`，manifest、历史来源、checkpoint及成果sourceRefs均为笔记版本引用。
- 现有完整文本 JSON 发送上限12KB、供应商隔离 IPC 上限1MB；不能为支持图片直接放大上限或按 Base64 字节当视觉 token。

当前 [DeepSeek官方模型表](https://api-docs.deepseek.com/quick_start/pricing/)列 deepseek-flash 的 Vision 能力；这只证明官方声明，仓库适配器仍纯文本且 `verified:false`。图片和扫描PDF必须新增多模态协议、能力门禁及视觉估价后验收，不把文件上传成功冒充内容已读取。

## 依赖与独立批次

1. 四包隐私/成果/恢复基础先完成固定head审查与CI合并。
2. 对话拥有附件记录及独立目录：上传完整性、解析任务、持久状态、删除/移除前向隔离、重启恢复；TXT/MD、DOCX段落/表格、文本PDF页码先离线实现。扫描/加密/损坏或超限分别明确状态。
3. 扩展统一来源契约：附件ID、原文件哈希、解析版本、页码/文本范围，贯穿模型manifest、历史provenance、checkpoint与成果。只提供附件也可问答，不自动授予笔记库读取；任意本地路径或外部图片URL不得作为模型资料。
4. 输入预览/移除/粘贴及图片协议：只在真实可读取能力可用时启用对应问答；图片与扫描PDF的视觉/OCR通路先用合成工具验证，真实视觉适配器另行核验。

schema/router/sync继续单负责人协调。对话附件默认不进入正式业务同步，跨设备对话附件同步及保留期限尚未决定，不能假称已同步。

## 合成验收和外发边界

验收包括中文TXT/MD、DOCX表格、文本PDF页码、扫描无文字层、PNG/JPEG内容协议；伪MIME/损坏/加密/解压超限；跨owner/conversation/epoch越权、私密父笔记附件、移除后历史重新发送、附件原文不得成为联网搜索词；上传响应丢失、幂等、解析崩溃、重启、差异与唯一采纳。

从笔记库引用附件仍受父笔记私密状态约束。用户直接向对话提供的附件建立独立当前任务授权，前向撤销后不得重新发送原内容；历史回答残留提示沿用四包规则。

不安装收费OCR、不引入真实凭据、不上传私人文件、不调用付费模型。真实视觉验证所需最小新增授权：指定模型/供应商、受控凭据引用、明确费用上限及仅合成图片/扫描PDF外发；不从当前开发授权推导这些授权。离线解析和合成协议开发不依赖这项付费验证授权。

## 第一批：私有存储、离线解析和轻量输入

本批实现上传、列表、显式预览、按版本移除和重启恢复；附件仍不参与模型请求。JSON 私有状态从5升级6，显式兼容1至5，不接受旧版本倒签新集合；SQLite/PostgreSQL 复用会话私有记录表，业务同步和笔记导出不包含对话附件。文件采用受控 UUID 路径，不接受用户原路径；完整写入并 fsync 临时文件后原子发布，验证原字节和解析文本 SHA-256，再开放预览。相同上传键与完整内容/元数据幂等；移除清空正文、保存墓碑后清理文件，不能由重试或迟到解析复活。完整 App 备份额外校验新附件文件大小和哈希，恢复切换 epoch 后旧附件不获得执行权。

工程默认是每件5 MiB、每会话20个未移除附件、总计25 MiB。移除释放配额，待写入或失败记录仍占配额。原子事务检查配额，不以页面计数作为权限。孤儿临时文件清理每次最多查看1000项/删除100项，仅处理属于当前 owner/dataset/epoch 已知记录、超过1小时且为普通文件的临时文件；不清理历史资料集或正在写入的文件。这些数值是安全实现选择，不冒称用户已决定附件保留期限。

TXT/MD 按严格 UTF-8 解码；DOCX 使用 Mammoth 原始文本提取并预检 ZIP 条目、展开量、CRC 与外部关系；文本 PDF 使用 PDF.js 文字层保留页码。旧 DOC、扫描无文字层、加密、损坏和超限分别失败，不截断后声称完整。PNG/JPEG 只验证容器、尺寸与像素限额，提供受保护原字节预览，始终标明未启用图片理解。解析限额与隔离事实见 [解析器说明](../../apps/api/src/modules/ai/conversation-attachment-parsers/README.md)。

当前隔离启动器仅支持具备 `prlimit` 的 Linux；其他平台返回 `AI_ATTACHMENT_ISOLATION_UNAVAILABLE`，不会静默在主进程解析。Node 权限模型及应用层网络 API 阻断不等于 OS 级禁网，也不是恶意代码沙箱。跨平台 App 的等价解析隔离启动器仍待实现和验证，本轮没有运行或安装 Mac。

轻量入口沿用既有页面组件，支持文件选择、附件区域图片粘贴、文本与受保护 blob 图片预览、移除和明确失败；展示“尚未发送给 AI”。普通消息仍拒绝 `attachmentIds`，不把上传成功当作附件问答已交付。统一附件来源清单、历史/成果/检查点传播与发送前复核属于下一批；真实模型能力、视觉计价和供应商兼容仍未实测。批准三态视觉继续因原图像素不可用而阻塞，本批未定稿整页布局。
