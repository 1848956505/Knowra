# 模型接入设置：实施与验收

日期：2026-09-26。状态：设置入口与凭据保存已实现；用户尚未在 Knowra 输入密钥，未进行真实 DeepSeek 请求。P0 的 AI-00-03/04 后续已完成设计与样本交付，见本目录对应记录。

## 已实现

- V4「设置 → 模型接入」提供 DeepSeek 模型 ID、API Key、保存、检查连接及移除。默认模型 ID 为 `deepseek-flash`，可手动修改。
- Mac 应用通过受限 Electron IPC 把密钥交给主进程，以 `safeStorage` 加密后写入应用 `userData/ai-provider.json`；密钥不回传页面，不在本地资料库备份、同步或恢复草稿中。
- 网页版通过同源 API 保存到运行服务账号的 `~/.config/knowra/ai-provider.json`，文件权限 `0600`。此配置属于当前服务器，不随浏览器或业务数据同步。公开服务沿用现有 Nginx Basic Auth 边界；产品登录尚未实现。
- 状态接口仅返回供应商、模型 ID、是否配置。连接检查调用 DeepSeek `GET /models`，核实密钥和模型可见性；不发送笔记、不进行文本生成或计费推断。实际模型输出、额度、质量与费用尚未验证。

## 验证

| 命令/场景 | 结果 |
| --- | --- |
| `npm run test:api` | 286/286 通过，含服务端密钥不回显、受限文件权限、连接检查与移除。 |
| `npm run check:web:v4` | 类型、边界、364 个 Vitest 用例与 4 个服务测试通过。 |
| `npm run build:web` | 通过。 |
| `npm run build:mac` | 打包、签名、桌面测试 7/7 通过；脚本同时把新包安装到 `/Applications/知境·Knowra.app`。 |
| 打包 Mac 应用设置页自动化 | 独立资料目录下显示「模型接入」「尚未配置」，原生 IPC 可用，未配置时连接按钮禁用。 |

测试使用合成密钥与模拟模型列表，没有读取用户真实密钥，也没有真实 DeepSeek 调用。网页版在真实远端服务器上的部署/登录边界、Mac 钥匙串真实密钥写入、真实账号模型列表检查仍需用户自行配置后验证。
