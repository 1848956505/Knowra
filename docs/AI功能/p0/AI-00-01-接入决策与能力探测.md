## 2. 协议与凭据位置

1. **首接协议**：DeepSeek OpenAI 兼容 `Chat Completions`，基址 `https://api.deepseek.com`，模型 `deepseek-flash`。实际兼容性必须按下节探测；若特定功能需要 `Responses`，另建 adapter 与版本记录，不静默更换协议。工具调用只产生建议参数，Knowra 应用层执行领域服务。
2. **Web 服务器密钥**：当前设置入口把密钥保存到运行服务账号的受限 `0600` 文件 `~/.config/knowra/ai-provider.json`，不进入业务表、同步、响应、V4 构建或导出包。P1 的执行器仍需定义凭据引用和受信调用边界；公开部署继续依赖现有 Basic Auth，正式登录未完成。
3. **Mac 桌面密钥**：当前设置入口经受限 IPC 交给主进程，以 macOS `safeStorage` 加密后保存在应用 `userData`，不写入 `local.sqlite`、恢复备份、同步队列或浏览器 LocalStorage。P1 还须完成本地 utility process 在任务执行时安全取用的窄接口及资料集隔离。换机和恢复后应显示需重新配置。
4. **连接测试**：当前“检查连接”仅读取 DeepSeek `GET /models`，核对密钥和所选模型在列表中，不读取用户资料或执行文本生成。P1 的短合成文本最小请求及可能费用提示仍待实现；不记录密钥前后缀。
5. **端点约束**：端点由用户/管理员明确设置并固定，不接受模型返回的 URL；校验 HTTPS、重定向和目标主机，避免密钥发往意外域名。本机模型将来使用独立的本地端点模式。

用户已有 DeepSeek API Key；受保护配置入口已有基础实现，P1 仍需接通执行器的凭据引用。本次结项复核不检查、复制或请求明文密钥，也不假定当前执行器能读到它。

## 3. 范围、预算与阻断行为

- `ContextManifest` 在模型调用前由服务端根据 grant、当前资料集/空间和不可变版本生成；目录范围固定展开，本次未包含的标题、搜索摘要和正文都不进入 prompt。实际请求的接收方及范围与用户看到的清单一致。
- 用户已同意将明确选择的真实笔记片段发给 DeepSeek；应用仍要在每次任务中展示实际发送清单，不推导出全库、附件或跨目录授权。P1 首批真实验收优先使用合成样本。
- DeepSeek [隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html)描述输入与输出可能用于模型优化、可通过“数据用于优化体验”退出；[开放平台条款](https://cdn.deepseek.com/policies/en-US/deepseek-open-platform-terms-of-service.html)另规定下游应用的数据处理责任。API 账户启用前应核对这些选项是否适用于该账户并关闭训练使用；若无法核实，只对合成数据做连通测试，不承诺零留存或零训练。
- 预算计算在服务端：按计价版本预留任务最坏用量，含失败/重试；并发请求原子扣减，结束后按提供商 usage 结算。未知 usage 记 `unknown`，不能记 `0`。供应商账单可能与估算有差异。
- 当前凭据是否已由用户配置，本次结项复核未读取；预算执行器尚未实现，因此允许 mock 和静态契约测试，收费探测及真实生成调用保持关闭。未来启用后，每次任务先原子预留最多 2 元；余额不足则拒绝启动。所有并发任务按北京时间自然日共用 10 元硬预算，成功、失败、重试和未知用量都记账；未知用量保留预留额，不能当作免费。取消后只释放可确定未使用的余额。
- 截至 2026-09-24，[DeepSeek 官方人民币价格表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)中 `deepseek-flash` 高峰价为每百万输入 token 2 元（缓存未命中）、输出 8 元，非高峰价为 1 元和 4 元；缓存命中另计。计价会变，P1 连接前重新拉取/核对官方价目及账号账单，再设置价格版本。以上 token 上限在高峰未命中输入下约 0.2 元、输出约 0.16 元，单任务 2 元预留为额外重试和计量差异留余量；这些是工程估算，不是实际账单。

能力声明至少分别包含 `text`、`streaming`、`toolCalls`、`jsonSchema`、`usage`、`cancel`，并携带协议和探测日期。拒答、输出截断、`tool_calls` 参数不合法与用量缺失都应有独立状态。对不支持的能力不让 UI 显示可执行入口。
