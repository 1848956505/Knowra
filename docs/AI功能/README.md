# AI 功能开发工作区

状态：整体方案 v0.3，2026-09-28 需求对齐修订。当前交付重点是可插拔 AI 底座与笔记 Agent。P0/P1 已有基础实现和分环境验收记录，P1-R01–R06 已完成本地补齐；语义召回和跨环境验收继续按任务表推进。

本目录规划 Knowra 从 AI 接入基础到笔记、知识、训练与学习反馈的完整开发路线。目标是让 AI 能读取授权资料、协助整理和记录笔记、生成可追溯的知识与题目，并在真实作答证据上提供学习建议。

本轮共识以 [00-总体方案与决策记录](00-总体方案与决策记录.md) 为准：以多轮对话为主，授权范围内自动搜索与阅读；明确要求的新建/追加可执行，改写和批量管理先预览。未来正式出题、作答和批改采用专门页面与固定系统流程，聊天出题只是非正式练习。

AI 是可关闭、可替换的附加能力，错误或失效不能阻断核心业务。现有 Gateway、凭据、任务、预算及引用基础继续复用；具体差距和补齐顺序见 [06-P1 对话 Agent 补齐方案](06-P1对话Agent补齐方案.md)。R01–R06 的本地实施见 [隔离记录](p1/AI-01-R01-插件隔离与执行边界.md)、[持续授权记录](p1/AI-01-R02-持续授权与逐请求清单.md)、[会话恢复记录](p1/AI-01-R03-会话消息与恢复契约.md)、[有界 Agent 记录](p1/AI-01-R04-有界对话Agent与工具循环.md)、[对话页面记录](p1/AI-01-R05-对话主页面与状态恢复.md)及[检索基线记录](p1/AI-01-R06-授权检索接口与关键词基线.md)。

## 当前开发顺序

1. P1 补齐：插件隔离、授权策略 v2、会话消息、工具循环与自动检索、对话页面及验收。
2. P2：在对话中可靠创建、追加、改写和管理笔记，保留草稿、并发检查、预览与恢复。
3. 知识库成熟后推进 P3 知识候选/目标；试题库成熟后推进 P4–P6 的固定出题、作答、批改流程。
4. 向量检索可按召回质量提前实施；外部 MCP、关系维护、多模态、待办/打卡工具按领域能力扩展。

首接继续使用统一适配层下的 DeepSeek `deepseek-flash`，保留 10 元人民币/北京时间自然日硬预算。既有账号验收以各报告的日期、端侧和版本为准，不由文档推断当前配置或线上可用性。新持续范围授权必须显式配置，不把旧选区授权自动扩大为全库；详见 [03](03-数据工具与权限契约.md)。
