# AI 功能开发工作区

状态：整体开发方案 v0.2；P0 的 001/002 已完成设计决策与代码/恢复基线复核，其余任务未实施。基线核查日期：2026-09-24。

本目录规划 Knowra 从 AI 接入基础到笔记、知识、训练与学习反馈的完整开发路线。目标是让 AI 能读取授权资料、协助整理和记录笔记、生成可追溯的知识与题目，并在真实作答证据上提供学习建议。

本轮没有配置密钥、调用模型、修改业务数据或部署功能。当前能力以代码核查为依据；P0 执行了桌面自动化测试和一份历史备份的只读检查，范围详见对应报告。历史文档中的验收数字不代表本轮重新验收。

## 当前建议

1. 先做统一 AI 基础与 Knowra 内置助手；首个可用版本覆盖读笔记、带引用问答、新建和追加笔记。
2. 接通知识候选提炼，再扩展学习目标建议、题目生成和审核。
3. 将正式试卷、作答、批改和学习证据作为独立领域开发任务，AI 依赖这些能力，不替代它们。
4. 笔记工具与领域服务统一复用，后续通过 MCP 向外部 AI 开放。
5. 先使用可解释的关键词检索和显式范围，语义检索、图谱、多模态和后台自动化按实际需求扩展。

用户已确认：内置助手优先、预留 MCP；首接 DeepSeek，允许发送明确选中的笔记片段，日预算 10 元人民币；授权范围内可读取，明确要求的新建/追加可直接执行，改写和批量管理先预览。首接探测模型为 `deepseek-flash`。用户已有 API Key，但 Knowra 尚未配置，当前不能调用。发送范围与费用执行细则见 [P0 决策](p0/AI-00-01-接入决策与能力探测.md)；产品权限策略不代表写入工具已实现。
