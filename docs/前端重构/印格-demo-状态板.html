8Save 保存状态

idle / saving / saved / failed
Idle · 静默
未修改 最后保存 2 分钟前
Saving · 旋转
保存中 同步中 60%
Saved · 已保存
已保存 已同步 10:32
Failed · 失败横幅
保存失败：网络中断，已保留本地草稿（3 处未保存修改）
契约：状态用 save-state--{idle,saving,saved,failed} 类标记；saving 期间 input 仍可编辑（避免误锁）；failed 必须用 role="alert" 横幅 + 重试入口，保留本地草稿并明确提示变更数。

9Toast 瞬时反馈

契约：默认 2.2s 自动消失，鼠标悬停暂停；info 蓝影、success 绿影、warning 橙影、error 红；role="status" / role="alert" 区分紧急程度；右下堆叠，最新置顶。
阅读顺序：搜索 → 菜单 → Popover → 按钮 → Dialog → 侧栏 → 页面状态 → 保存状态 → Toast 设计原则：暖纸 + 墨线 + 蓝印章 + 零圆角 + 硬影 + 内容优先。所有 hover/active/focus/disabled 都在按钮卡片里就近展示。
