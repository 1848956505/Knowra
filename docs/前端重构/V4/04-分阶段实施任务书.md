# V4 React 分阶段实施任务书

## 1. 执行约定

- 开始前读取本目录 `00`～`05` 文档。
- V4 正式代码进入 `apps/web-v4/`；共享能力进入 `packages/web-core/`。
- 不删除用户已有改动，不直接复制 V3 CSS 和字符串 renderer。
- React 独占渲染树；旧 controller/event binder 不得接管 React DOM。
- React Aria Components 只在 `components/ui` 封装层直接使用，page/feature 不直接依赖第三方 API。
- 每个共享模块迁移必须让 V3 同步引用共享来源，防止双份逻辑。
- 每个任务写明来源、目标、测试替代关系和退出对象。
- 视觉与交互最终 PASS 必须经过支持多模态的验收。

## 2. 模型分工

| 类型 | 建议 |
| --- | --- |
| 架构、Store、共享核心边界、Milkdown adapter | 强推理模型 |
| 明确脚手架、配置、类型声明、机械 import 迁移 | Flash/轻量模型执行，强模型复核 |
| 视觉方向、截图比较、响应式、可访问验收 | 支持多模态的强模型 |
| 已冻结组件的 JSX/CSS Module 与测试 | Flash 或常规模型 |

- 建立 TypeScript、lint/static、unit test 门禁。
- 保留并运行 V3 class query gate。

### V4-02-03 App bootstrap

- `App`、Provider、Error Boundary、loading/error shell。
- API health 或 workspace bootstrap 的最小可观察链路。
- React Strict Mode 下无重复副作用。

### V4-02 准出条件

- V3 与 V4 可独立启动。
- V4 构建产物无 V3 CSS/renderer。
- TypeScript strict、Vitest、V3 test 均通过。
- 暂不要求正式视觉。
