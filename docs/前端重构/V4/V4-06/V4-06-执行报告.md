## 3. 分层与规范检查

- Presentation：`LibraryView` 只负责页面编排；展示模块按 Sidebar / Toolbar / ResourceList / Inspector / Dialog / Pagination 拆分。
- Business：`useLibraryIndex` 管理范围、筛选、搜索、防抖、选中和分页；`useLibraryActions` 管理写入、确认和错误反馈；`libraryModel` 保持可测试的纯规则。
- Data：V4 Store 负责加载快照、写入状态、错误状态和重新加载；web-core 负责 API DTO 与请求路径。
- Infra：复用现有 request/API、V4 UI 包装和 Token/CSS Modules；没有引入新路由框架、第二套 UI 库或 V3 runtime/CSS。
- 开发规范依据：`docs/开发规范.md`、V4 README、V4-00.5 冻结规范。未发现仓库根级 `docs/前端开发规范.md`，因此未将缺失文件当作生产实现依据。
