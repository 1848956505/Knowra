# V4-07 笔记编辑页面骨架执行记录

日期：2026-08-29（2026-08-31 更新标题区、第三阶段编辑逻辑、完整菜单、正文右键快捷面板、文档检查器与保存可靠性）

## 本阶段范围

本阶段只搭建编辑页面的大框架。唯一视觉真源为 `V4-00.5/印格/印格-demo-笔记页面.html`；组件展台不作为页面构图依据。

已落地：

- `/materials/notes/:noteId` 笔记编辑路由与直接访问加载。
- AppShell 工作区模式，以及目录、编辑区、状态栏之间稳定且独立的滚动边界。
- 文档标签栏、快捷工具栏、纸面文档头、正文占位、按需检查器和缺失笔记门禁。
- 索引列表/网格、目录笔记行与全局搜索命中的最小打开链路。
- 编辑路由的“笔记库 / 当前标题”状态路径。
- 文档 Tab 的切换、键盘方向键/Home/End 导航、关闭及相邻标签回退；顶部新建入口复用现有创建 Dialog 与后端 `createNote`。
- 快捷工具栏初始以精简悬浮态位于标题下方，滚动后固定到编辑区顶部并显示完整菜单词；首个 Tab、纸张与固定工具栏共享同一左边界。
- 快捷工具栏复用现有收藏接口与检查器开关；上下文侧栏文件夹展开控件按最新参考改为无横轴的细线尖括号。
- 上下文侧栏顶部栏收紧到与文档标签栏一致的 36px，正文滚动与目录密度不变。
- 标题区继续按唯一视觉真源还原，并拆出 `EditorDocumentHeader`：长标题自然换行，Enter/失焦保存、Esc 撤销、空标题恢复、错误就地反馈和离线只读均已接入；持久化复用现有 `renameNote` 与 `updateNote`，未新增 API。
- 正文通过 V4 独立 `MilkdownNoteEditor` typed adapter 挂载，不导入 V3 runtime/CSS/controller；进入页面按需调用既有单篇详情接口，输入后 700ms 自动调用既有 `updateNote({ rawMarkdown })`，切换笔记时刷新尚未提交的正文。
- 快捷工具栏和菜单已连接正文、H1/H2/H3、粗体、斜体、行内代码、无序列表、引用、3×3 表格、撤销与重做；图片附件和更多操作因依赖尚未完整迁移而保留明确禁用态。
- 标签页已补齐右键关闭/关闭其他/复制路径、拖拽排序、右键键盘排序、全部标签菜单和跨会话缓存；所有排序与关闭继续复用确定性的相邻回退规则。
- 固定态快捷栏的“文件”菜单已迁移旧版已有动作：新建笔记、新建文件夹、显式保存、另存为、重命名、收藏/取消收藏、删除、导出 Markdown 与富 HTML。写入动作复用现有 workspace Store 和后端接口；删除复用统一确认 Dialog；另存为先刷新当前正文，再通过既有 `createNote` 创建同目录副本并切换标签。
- 新增统一 `FileDropField` 与 `MarkdownImportDialog`：支持拖放、键盘触发的文件选择、多文件列表、移除、格式/数量/6MB 总量校验和错误就地反馈；读取后复用后端 `import-markdown` / `import-markdown-batch`，从一级标题推导笔记名、同级重名顺延并在刷新后打开首篇。
- “导出”升级为真实“导出 PDF”：按需加载 `html2canvas` 与 `jsPDF`，捕获当前印格纸张、排除快捷栏、按 A4 比例分页并直接下载 `.pdf`；端到端测试核验文件头为 `%PDF-`，旧 HTML 冒充 PDF 的语义已退出。
- “段落”菜单完整接通正文、H1–H4、无序列表、有序列表、任务列表、引用块、代码块、分割线与表格；标题重复执行可回到正文，同类列表重复执行可退出，无序/有序列表可直接互转。
- 段落快捷键兼容 Ctrl/Meta：正文与 H1–H4 使用数字键，列表与任务列表沿用旧版组合键；任务列表迁移旧版生成与点击勾选插件，不跨目录导入 V3 runtime。
- 正文点击或键盘聚焦时不再显示覆盖内容区的蓝色四边轮廓；焦点反馈收敛为可见插入光标，并补齐 `aria-label`、多行文本框和快捷键可访问属性。
- “编辑”菜单完整接通撤销、重做、剪切、复制、粘贴、查找、替换与全选；历史命令复用 Milkdown，剪贴板经 V4 browser adapter 优先走 Async Clipboard，查找替换复用 V3 已验证的 ProseMirror 匹配、高亮和循环导航语义。
- 查找/替换使用项目 `TextField` 与 `Button` 组成非模态面板，支持上一处/下一处、替换一处/全部替换、F3/Shift+F3 循环与 Esc 关闭，未使用原生 prompt。
- 行内代码与代码块样式拆入 `MilkdownNoteEditor.module.css`；代码块改为浅色纸面底、深色正文与蓝色左强调线，不使用深色背景。
- “格式”菜单完整接通加粗、斜体、删除线、行内代码与高亮，快捷键展示与键盘派发统一复用 `editorShortcuts`；图片因附件能力尚未迁移继续禁用，没有创建临时占位逻辑。
- 内部链接复用后端既有 `[[noteId]]` 领域语义：V4 以本地 Milkdown mark 解析、呈现并无转义序列化双中括号，正文仍通过既有自动保存接口触发后端 `extractInternalLinks`，未新增接口或数据字段。
- 标题前文档大图标按冻结 Demo 恢复 72×98px、折角、四行纸面纹理与亮青硬阴影；悬浮快捷栏在标题下方上移 10px，封面阴影新增 canonical `--ink-cover-shadow` Token。
- “视图”菜单完整接通阅读、编辑、专注模式、左右区域与源码编辑器：视图动作由独立 `editorViewState` 纯状态机统一，工具栏和状态栏共享同一状态，专注模式只改变布局并保留进入前的内容模式及面板偏好。
- 阅读模式真实锁定标题和 Milkdown 正文；源码编辑器使用浅色 Token 分栏，源码变更经 typed `setMarkdown` adapter 同步渲染预览，并继续复用 700ms 自动保存和显式保存链路。
- 正文右键快捷面板按“印格”重新设计为紧凑纸面命令板，不照搬参考图的大方格样式；编辑、格式、列表、缩进、标题和插入动作均复用 `EditorCommandTarget`、剪贴板 adapter 与现有自动保存链路，图片继续保持附件适配前的禁用态。
- 二级“标题/插入”菜单统一经共享 `SubmenuTrigger` 使用 React Aria 的悬浮延迟、指针安全通道、方向键与 Escape 语义；主面板以右键坐标的不可见定位锚点触发，面板和子菜单依赖同一套 `containerPadding + shouldFlip` 定位，贴近视口底部或右侧时自动向上/向左回收。
- 文档检查器从大封面属性占位升级为 Demo 对应的四 Tab 结构，复用共享 React Aria `Tabs` 与 `GhostIconButton`；信息 Tab 展示真实类型、状态、完整目录路径、实时字数、时间、阅读时长、标签与双向关联，附件在数据接口尚未迁移时显示明确接入边界。
- 大纲 Tab 从当前 Markdown 派生 H1–H4 并可滚动定位编辑器标题；链接 Tab 区分引用当前笔记和当前笔记引用的真实记录；AI Tab 在后端能力缺失时明确说明未接入，不生成伪结果。检查器自身独立滚动，≤767px 以全宽覆盖层呈现。
- 正文仍采用停止输入 700ms 后的短延迟自动保存，并非每个按键都发起网络请求；保存请求现在显式绑定产生草稿的笔记 ID，同一笔记按调用顺序提交，切换/关闭活动笔记前直接读取 Milkdown 最新 Markdown，失败草稿继续留待显式保存或后续切换重试。
- 修复详情延迟加载空白：当摘要先以 `contentLoaded=false` 到达、单篇详情稍后返回时，远端正文会在编辑器首次挂载的同一渲染周期作为初值，不再先挂载空编辑器后错过详情更新。
- 完成输入与保存可靠性第一阶段：Milkdown 以独立的 incoming/editor Markdown 与 ready 门禁区分初始化序列化、远端同步和真实用户编辑；存在本地修订时不执行外部 `replaceAll`，空白编辑器也不会覆盖已加载的非空远端正文。
- 正文保存直接复用后端已有 `expectedUpdatedAt` 并发字段：草稿记录产生时的远端基线，同篇连续保存等待前次完成后再推进基线；相同 Markdown 在 Store 层直接返回当前笔记，不发送 PATCH、不刷新时间、不创建版本。
- API 客户端保留 HTTP 状态与领域错误码。后端返回 `NOTE_UPDATE_CONFLICT` / 409 时，当前篇自动保存立即暂停，本地草稿保持可编辑且可导出为 Markdown；切换/关闭仍先走显式保存，因此冲突不会静默丢弃或覆盖任一端内容。
- 正文捕获普通 Tab/Shift+Tab 并优先复用既有缩进/减少缩进 typed command，命令无法继续嵌套时仍阻止焦点穿透；文档检查器宽度改为直接绑定上下文侧栏 Token、标题栏使用同一面板底色，标题前文档图标较上一版下移 8px。

暂不包含：

- CodeMirror 代码块、图片附件块与附件上传。
- 更多文档操作。
- Inspector 的附件、标注与 AI 后端数据。
- 移动端侧栏抽屉和最终视觉精修。

## 边界与影响

- 路由跳转保留在 `app/App.tsx`；`NotesIndexView` 与 `NotesContextSidebar` 仅接收可选 `onOpenNote` 回调。
- 文件夹行单击展开/折叠、文件夹选择、展开箭头和右键菜单逻辑未因编辑路由而改变。
- 编辑器正文当前只读取 workspace 中已有的 Note 摘要/内容字段；标题编辑复用既有重命名接口，不新增 API 或数据语义。
- V4 显式声明仓库既有 `@milkdown/kit` 兼容依赖，仍不导入任何 V3 编辑器实现；V4-07 功能轮版本为 `2.16.0`，输入与保存可靠性第一阶段按 PATCH 规范同步升至 `2.16.1`，实验性 `web-core` 保留独立版本。
- 文件夹尖括号只替换独立展开按钮的图标，文件夹行原有的选择、索引筛选、展开/折叠和右键菜单事件未合并或改写。
- 工具栏加号只展示已接入的表格命令；图片入口在附件适配完成前保持禁用，没有退化为无持久化的占位图片操作。
- 文件选择的可见入口、拖放态、已选列表、验证与反馈统一由项目组件控制；底层隐藏 input 仅承担浏览器安全模型要求的本地文件授权，业务页面不直接呈现或操作原生控件。
- 文件菜单中的写操作在后端离线/缓存恢复模式下统一禁用，Markdown/PDF 导出仍可读取当前编辑器或纸张内容并在本地完成，不要求后端在线。
- 段落格式属于编辑器前端能力，不存在可复用的后端格式接口；本轮复用 Milkdown 官方命令和 V3 已验证的任务列表/块切换语义，格式结果仍由既有正文自动保存接口持久化。
- 编辑菜单的写入结果不新增后端语义；剪切/粘贴/替换仍触发既有 Milkdown listener 与 700ms 自动保存，剪贴板权限失败通过状态栏给出可恢复提示。
- 格式菜单不重复建设后端逻辑：普通格式只序列化为 Markdown，内部链接严格复用后端既有双中括号提取契约；若正文选择的是标题而非笔记 ID，后端会按既有规则保留引用文本但不会错误解析为其他实体。
- 右键面板只编排已经接入的编辑器能力；删除选择、缩进/减少缩进、上下方插入段落补入 typed command adapter，但仍由同一 Milkdown state 与 listener 持久化，不新增业务状态、后端接口或第二套格式逻辑。
- 检查器信息、大纲和链接均由当前 workspace 数据与 Markdown 纯派生，不新增后端接口；附件与 AI 无可复用数据源时保持真实边界。保存可靠性第一阶段复用既有 `PATCH /notes/:id` 与后端已支持的 `expectedUpdatedAt` 字段，没有新增接口。
