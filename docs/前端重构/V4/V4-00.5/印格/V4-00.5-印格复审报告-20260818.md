## 3. 已解除的阻断项（历史）

### P0：390px 索引列表不可用（已修复）

`@media (max-width: 767px)` 仅隐藏了带 `.col-status`、`.col-date` 的表头，但对应数据单元格没有同类 class，仍参与表格列布局。结果是名称、状态与日期被压成逐字竖排，无法快速浏览。

原始问题证据：[`06-笔记索引-390.jpg`](审查证据-20260818/06-笔记索引-390.jpg)。修复后证据：[`02-索引手机-390.jpg`](审查证据-20260818-复验/02-索引手机-390.jpg)。

建议：手机端不要继续压缩桌面表格。改成每项一张两行紧凑列表：第一行图标 + 标题 + 更多操作；第二行状态 + 位置 + 更新时间。保留 44px 最小触控目标，标题最多两行并省略，不允许中文逐字断行。

### P1：冻结规范未闭环（已修复）

- `印格-总控.md` 仍引用不存在的 `印格设计系统-组件库_删减版.html`。
- 旧组件库使用 `208px` 全局功能栏 + `232px` 目录栏；当前三张主视图使用 `64px` 模块轨道 + `224px` 上下文侧栏。
- 三张页面的 Token 命名仍在单文件中复制，并存在 `--ink-dot`、阴影和字体栈等细微差异。
- 没有独立的 V3 禁止继承清单，也没有“不得复制原型 DOM/内联 CSS/JavaScript”的正式实施边界。

### P1：Dialog 键盘与辅助技术行为不完整（已修复）

新建 Dialog 能自动聚焦首个输入框并支持 Escape 关闭，但没有焦点陷阱、背景 `inert`/等效隔离和关闭后焦点归还。视觉原型可以简化业务，但状态板仍应把这些交互契约写清楚，避免 V4-04 误抄不完整行为。
