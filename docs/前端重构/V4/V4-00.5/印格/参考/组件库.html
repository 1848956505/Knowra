勾股定理

直角三角形两直角边的平方和等于斜边的平方，即 a² + b² = c²。这是欧氏几何中最早被严格证明的定理之一，也是联系代数与几何的桥梁。

证法亮点：赵爽弦图用面积割补完成证明，比欧几里得证法更直观，适合作为「无字证明」的课堂引入。

常见证法

除弦图外，还可通过相似三角形、总统证法（加菲尔德）或向量内积推导。整理笔记时建议为每种证法单独建立双链，便于在试题库中按知识点回链。

Markdown 纸张：桌面 = 暖纸底 + 20px 点阵；纸张 = 白底 + 2px 墨边 + 3px 硬影，居中 720px（.paper-wide 880px）；专注模式降级为 1px 边无影（.paper-focus）。正文 15px / 行高 1.75，元信息 11px 等宽。
