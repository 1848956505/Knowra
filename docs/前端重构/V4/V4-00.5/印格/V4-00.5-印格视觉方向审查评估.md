# V4-00.5「印格」视觉方向审查评估

日期：2026-08-16  
任务状态：已领取，视觉方向评审完成，准出材料补齐中  
评审对象：`印格-demo-外壳.html`、`印格-demo-笔记页面.html`

## 1. 结论

「印格」可以作为 V4-00.5 的唯一视觉方向候选。现有两个页面已经形成稳定、可辨识且可扩展的同一设计系统，不再需要继续发散新的风格方案。

当前结论是“有条件冻结”，不是“V4-00.5 已完成”：两页足以冻结设计语言和外壳模型，但任务书要求的独立资料索引页与完整状态集尚未交付，因此暂不解除 V4-04 的前置门禁。

## 2. 已确认的视觉基线

- 暖纸底、白色表面、墨黑主文字、蓝色强调和语义色方点。
- 点阵工作桌面、零圆角、柔化硬阴影与三级线条层级。
- 模块轨道、上下文侧栏、主工作区、检查器、底部状态栏组成的四区外壳。
- 方形图标按钮、纸张式文档 Tab、等宽元信息和短促按压反馈。
- 桌面端折叠/覆盖、手机端目录抽屉与底部模块导航的响应式策略。
- 主页和高密度编辑器使用同一视觉语法，正文继续作为编辑场景的视觉中心。

## 4. 准出缺口

1. 补齐独立“资料索引页”。主页中的最近编辑表格不能替代资料目录、筛选、列表/详情与空结果路径。
2. 补齐搜索、Menu、Dialog、Popover、加载、空、错误、保存失败和禁用状态板。
3. 将两个单文件原型中的共同值提炼为一份 V4 Token 初稿与组件密度表，消除原型之间的变量复制。
4. 明确 V3 不得继承的视觉清单，并声明 V4-04 不直接复制原型 DOM、内联 CSS 或 JavaScript。

## 5. V4-04 使用边界

V4-04 可以把本评估中确认的视觉基线转译为 CSS Variables、CSS Modules 和 `components/ui` 封装，但在 V4-00.5 完成上述缺口并由用户确认整体方向前，不得把当前候选登记为最终冻结，也不得绕过 React Aria 的语义、焦点和键盘行为。

## 6. 下一步

优先按「资料索引页 → 状态板 → Token/密度清单 → 用户冻结确认」顺序完成 V4-00.5，随后解除 V4-04 前置门禁。
