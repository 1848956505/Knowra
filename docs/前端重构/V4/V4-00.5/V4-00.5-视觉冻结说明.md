# V4-00.5 视觉冻结说明

## 1. 方向结论

V4 的整体视觉方向命名为 **Study Ledger / 学习账页**：把 Knowra 设计成一张持续生长的学习工作台，而不是堆叠卡片的通用后台。

视觉核心是“纸面秩序 + 实体操作”：内容区使用暖纸色和清晰编号建立阅读秩序；可点击、可输入、可确认的对象使用方正边框与硬影表达物理反馈；蓝色只标记当前行动、当前上下文与焦点。

## 2. 品牌与视觉原则

1. **内容先于容器**：页面优先展示学习任务、资料标题、正文与状态，不用卡片墙填满界面。
2. **蓝色代表行动**：主按钮、焦点、选择状态与活动定位使用钴蓝；普通结构不用蓝色装饰。
3. **实体操作，平面阅读**：按钮、输入、分页、菜单与 Dialog 有明确边框或硬影；长内容、导航层级、列表和编辑纸面保持平面。
4. **方形语法**：零圆角；状态点、日期块、编号、页码、选择标记均保持方形。
5. **信息像账页一样可定位**：英文等宽眉题、章节编号、资料编号与状态共同形成可扫描的坐标系统。
6. **动效说明因果**：hover 轻抬、active 塌入、Toast 自上而下进入；不使用弹跳、模糊、渐变或无意义漂浮。

## 3. 指定参考组件的继承方式

| 参考 | V4 冻结规则 |
| --- | --- |
| 06 Buttons | 2px 黑边；次级 2px 硬影；主操作钴蓝 + 4px 硬影；hover `translate(-1px,-1px)`；active `translate(2px,2px)` 并去影 |
| 07 Inputs | 2px 黑边；默认 2px 硬影；focus 改为 3px 蓝色硬影；禁用态降为 1px 灰边且无影 |

| 12 Overlays | 遮罩 `rgba(23,23,23,.42)`、无模糊；Dialog 2px 黑边 + 6px 英雄硬影；头部 2px 分隔 |

### 4.3 字体

- UI：`Inter / Noto Sans SC / Microsoft YaHei / system-ui`
- 正文纸面：`Georgia / Noto Serif SC / serif`
- 编号、日期、状态与快捷键：`SFMono-Regular / Consolas / monospace`
- 页面标题：34—58px / 850；工作区标题：18—20px / 800；正文：15px / 1.9；元数据：9—11px。

### 4.4 间距与密度

- 基础步长：4px。
- 控件密度：紧凑 32—34px；默认 36—40px；主行动 38—42px。
- 列表行：默认 74—76px；目录/大纲项 40—42px；菜单项 34px。
- 页面外边距：1024px 视口 26px；1280px 40px；1440px 48—58px；2048px 最大内容宽 1500px 后居中。
- 触控/指针目标：桌面最低 32px；核心行动优先 36px 以上。

## 5. 三张主视图

### 5.1 主页

- 任务：让用户在 5 秒内知道“今天学什么、进度如何、从哪里继续”。
- 主视觉：大标题 + 今日学习台；右侧使用单块纵向动量面板，不做多卡片统计墙。
- 继续学习区域用横向账目行，资料编号、标题、状态和时间形成固定扫描顺序。

### 5.2 资料索引

- 任务：筛选、判断处理状态、预览并进入资料。
- 桌面三列：集合 / 资料工作区 / 选中项检查器；1180px 以下隐藏检查器，920px 以下隐藏集合列。
- 列表行是内容行而非卡片；选中使用淡蓝平面，不使用硬影。
- 过滤控件继承 07 Inputs；分页和状态严格继承 #29/#30。

### 5.3 资料编辑器

- 任务：连续阅读与编辑，同时保留大纲和边注上下文。
- 桌面三列：大纲 / 中央纸面 / 边注；1180px 以下先隐藏边注，920px 以下再隐藏大纲。
- 编辑正文不放入浮起卡片；中央白纸以排版和留白建立层级。
- 菜单栏是扁平工具条，继承 11 Menus 的密度与激活蓝底，但不复用旧 Tab 外观。

## 6. 状态冻结

- 搜索：`Ctrl/Cmd + K` 打开英雄级搜索面板；`Esc` 关闭；结果行可进入编辑器。
- 菜单：更多操作打开实体菜单；hover 使用 pressed 暖灰；危险动作红色。
- Dialog：删除动作必须二次确认；遮罩无模糊；取消获得首个键盘焦点。
- 加载：三点方形脉冲 + 具体文案，不做骨架屏。
- 空：说明原因并给出单一恢复动作。
- 错误：红色图标/标题 + 影响说明 + 重试动作；不整屏染红。
- 禁用：1px 灰边、灰字、无阴影、无位移，必须保留 `disabled` 语义。

## 7. 响应式阈值

| 阈值 | 规则 |
| --- | --- |
| `>= 1181px` | 三列工作区完整显示 |
| `921—1180px` | 索引检查器与编辑器边注收起；保留主任务与一层辅助导航 |
| `<= 920px` | 进入桌面窄窗/200% 缩放等效布局；仅保留主工作区，侧栏通过后续抽屉/Popover 实现 |
| 内容最大宽 | 1500px，2048px 下居中，避免超宽行长 |

V4-00.5 冻结的是视觉优先级与重排规则；精确 200% 缩放、Milkdown 实际工具栏溢出与侧栏抽屉交互允许在 V4-07 实测修订。

## 8. V3 不得继承的视觉清单

1. 不继承 V3 的整页 DOM 结构、class 命名和全局 CSS 级联。
2. 不继承“所有内容都装进有边有影卡片”的卡片墙倾向。
3. 不继承多层侧栏同时常驻且无法按宽度逐级收起的布局。
4. 不继承用颜色大面积填充状态容器的做法；状态颜色只落在点、图标和关键文案。
5. 不继承圆角、胶囊、渐变、柔光、模糊阴影与玻璃拟态。
6. 不继承骨架屏；加载必须是点阵脉冲 + 文案。
7. 不继承仅靠 hover 才可发现的核心动作。
8. 不继承视觉 class 驱动行为；交互契约使用 React 状态、语义属性和稳定 data hook。
9. 不继承未区分阅读平面和操作实体的统一重边框。
10. 不继承固定像素大画布导致 1024px 或 200% 缩放不可达的布局。
11. 不继承表意不清的装饰图标；图标必须来自统一图标库并有可访问名称。
12. 不继承将“知识库 / 训练场”等未完成入口伪装成可用功能的视觉状态。

## 9. 后续实现约束

- V4-04 把本文件 Token 转为 CSS Variables，并由 CSS Modules 消费。
- React Aria Components 只负责语义、焦点、键盘和集合行为，默认样式全部清空。
- 页面和 feature 不直接 import React Aria Components；统一经 `components/ui` 封装。
- 所有适用组件需覆盖 default / hover / active / focus-visible / disabled / loading / empty / error。
- 动效时长不超过 200ms，且 `prefers-reduced-motion` 下关闭位移与循环动画。
