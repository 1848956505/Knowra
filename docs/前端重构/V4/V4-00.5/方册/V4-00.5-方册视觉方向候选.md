## 2. 设计命题

方向名为 **方册**：把 Knowra 设计成一张可操作的知识台账。页面不依靠卡片堆叠，而由明确的坐标、分栏、登记线和可按压控件组织。8×8 蓝色方点是当前位置标记，与状态徽标和加载方点使用同一几何母题。

### 视觉签名：坐标方点

- 蓝色实心方点：当前页面、当前资料、当前编辑落点。
- 黑色空心方点：可进入的资料或知识节点。
- 状态色方点：仅用于状态徽标，必须跟随文字。
- 点阵：仅出现在空态/加载区域，不作为全站背景。

## 4. 三张主视图

### 主页：今日台账

- 左侧为 84px 原创坐标 Rail，不采用印格 `08` 的 208px 分组导航。
- 主区用不对称台账网格组织“继续阅读 / 今日登记 / 最近资料”，不使用印格 `09` 卡片。
- 最近资料以原创登记行呈现，并直接使用 `#30` 状态徽标和 `#29` 分页器。

### 资料索引：目录坐标 + 资料登记簿

- 文件夹列用方点坐标和缩进层级表示，不复制印格目录树视觉。
- 主列表是横向登记簿：编号、标题、状态、时间、操作按固定列对齐。
- 筛选和局部搜索直接使用 `07`；列表页尾直接使用 `29`。
- Inspector 为无影静态分栏，内部状态直接使用 `30`。

### 资料编辑器：文稿台 + 命令带

- 文档切换条采用蓝底当前文稿，不复制印格 `10` Tab。
- 编辑命令带直接沿用 `11` 的方形工具状态语言。
- 正文纸面保持 680–760px 阅读宽度；页边蓝色方点标记边注位置。
- 边注面板为原创登记表结构，不使用印格侧栏示例。

## 5. 关键状态

- 搜索、下拉菜单、Dialog、Toast、Tooltip：遵循 `11/12`。
- 加载：只使用 `13` 三方点脉冲和明确文字；不做骨架屏。
- 空：只在状态容器内部使用 `13` 点阵，提供单一恢复动作。
- 错误：危险色边框/硬影 + 数据安全说明 + 重试动作。
- 禁用：1px 灰边、灰字、无影、无位移，并保留依赖说明。
- 状态徽标：全部使用 `#30` 方点 + 文本，不制作彩色胶囊。
