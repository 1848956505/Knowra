Transformer 注意力机制复盘

待整理学习AI今天 10:32 更新1,248 字

注意力机制的关键，不是让模型“记住所有内容”，而是让它在生成当前表示时，能够动态决定哪些信息更值得被参考。

核心原理

每个 token 产生 Query、Key 和 Value。Query 表示“我正在寻找什么”，Key 表示“我能提供什么线索”，Value 则是最终被汇总的信息。

注意力权重可以理解为：当前位置与上下文中每个位置之间的相关程度。
知

联结提醒：这一过程与信息检索很相似，可以关联到“向量相似度”和“知识库召回”两篇笔记。

计算步骤

  1. 计算 Query 与所有 Key 的相似度。
  2. 使用缩放与 Softmax 得到权重。
  3. 用权重对 Value 做加权求和。
TXT公式
Attention(Q, K, V) = softmax(QKᵀ / √dₖ)V
