## 1. 设计命题

Knowra 的用户是长期伏案的中文学习者：读资料、做批注、整理知识点、训练巩固。三张主视图共同的任务是——**让界面退到内容后面，让“当前该做什么”自然浮现**。

方向名为 **澄明**：一张收拾干净的书桌。纸张在中央，工具在手边但不出声。它不像“方册”那样用坐标和硬边强调台账感，而是用 Notion 式的安静层级、Craft 式的纸面精致度和 Linear 式的密度纪律，支撑每天数小时的阅读与编辑。

与前两轮的关系：

- 相对“雾青”（未采用）：放弃脉络线叙事，改用更朴素的发丝线 + 留白组织信息。
- 相对“方册”：零圆角硬影的台账美学换成暖纸 + 发丝线 + 单层浮层阴影的文书美学；两者 Token 体系互不兼容，最终均未采用。

## 2. 品牌与视觉原则

1. **内容即界面**：标题、正文、摘要是第一层。列表和树依靠留白与发丝线分组，禁止卡片套卡片；一块屏幕上边框容器不超过两层。
2. **暖纸冷墨**：底色是带暖意的纸白，文字是近黑的墨；全站只有一个强调色（黛蓝），只给当前位置、主动作和焦点。
3. **一层深度**：固定面板一律无阴影，只用 1px 发丝线分隔；阴影是浮层（Menu / Dialog / Popover / 悬浮工具条）的专属语言，用户凭阴影即可识别“这是临时层”。
4. **字体系双轨**：界面用系统黑体，文档标题与阅读正文用宋体。用户一眼区分“这是产品界面”与“这是我的内容”。
5. **密度纪律**：树行 28px、列表行 40px、控件 32px、关键动作 36px；不以缩小文字换取密度，正文字号不低于 14px。
6. **状态必须说话**：加载、空、错误、保存、禁用全部有文字，不用颜色单独承载语义；破坏性动作永远有二次确认与数据安全说明。

### 视觉签名：绛线

全站唯一的高辨识度元素是一条 **2px 黛蓝标线**（绛线）：

- 侧栏当前导航项 / 当前文件夹左侧的竖标线；
- 文档 Tab 当前项的下标线；
- 正文当前小节页边的锚点线；
- Inspector 当前折叠节标题旁的短标线。

它永远表达“当前位置”，不用于装饰、不用于普通按钮、不与状态色混用。用户在任何页面都能凭这一条线定位自己。

## 3. Token 初稿

### 3.1 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--canvas` | `#F7F6F3` | 应用底色（暖纸） |
| `--surface` | `#FFFFFF` | 内容纸面、输入、浮层 |
| `--subtle` | `#F0EFEB` | hover、次级填充、选中行底 |
| `--ink` | `#1F1E1A` | 主文字 |
| `--ink-2` | `#57544C` | 次级文字 |
| `--ink-3` | `#8A867C` | 辅助文字、占位符 |
| `--line` | `#E7E5DF` | 发丝分隔线 |
| `--line-strong` | `#D8D5CD` | 输入框边、浮层边 |
| `--accent` | `#3E63DD` | 黛蓝：主动作、焦点、绛线 |
| `--accent-soft` | `#EDF1FC` | 选中背景、标签底 |
| `--attention` | `#B45309` | 待整理、警示 |
| `--success` | `#2F7D4F` | 已确认、已保存 |
| `--danger` | `#BE3E2D` | 错误、危险动作 |

对比度要求：`ink` / `ink-2` 在 `surface` 与 `canvas` 上、白字在 `accent` 上均须过 WCAG AA；`ink-3` 只用于非必要信息。V4-04 必须用自动化测试验证实际组合态。

### 3.2 字体

- UI：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`，基础 13px，正文交互区 14px。
- 文书：`"Songti SC", "Noto Serif CJK SC", "Source Han Serif SC", serif`，只用于文档标题、阅读正文、主页继续阅读卡标题。
- 等宽：`ui-monospace, "SF Mono", Consolas, monospace`，用于字数统计、快捷键、编号、代码。
- 字阶：`11 / 12 / 13 / 14 / 16 / 20 / 28 / 36px`；行高 UI 1.45、阅读 1.75。
- 不依赖网络字体完成首屏。

### 3.3 间距、圆角、阴影

- 间距基数 4px：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48px`。
- 控件高度：紧凑 28px（树行、表格行内）、默认 32px（按钮/输入）、关键 36px（主按钮/搜索）。
- 圆角：控件 6px、面板/卡片 8px、Menu/Dialog 10px；不使用胶囊形（标签除外，标签 4px 方角）。
- 阴影仅浮层：`0 1px 2px rgba(31,30,26,.05), 0 8px 24px rgba(31,30,26,.12)`；固定面板 0 阴影。
- 图标：16/18px 线性 SVG、1.5px 笔触；图标按钮命中区 ≥32px。

## 4. 三张主视图

### 4.1 主页：今日书桌

布局：左侧 248px 导航侧栏（可收为 56px 图标轨）+ 弹性主区 + 右侧 300px「本周」栏（≥1440 停靠）。

- **侧栏**：顶部品牌位（知境 · Knowra）；工作域导航五项（主页 / 资料库 / 知识点 / 训练 / 学习档案），当前项左侧 2px 绛线 + `accent-soft` 底；下方“收藏”“最近打开”两个安静分组，各列 3–5 条 13px 条目。
- **主区首屏**：一行 20px 宋体问候（“晚上好，今日宜温故” + 日期），不做大号营销式标题。
- **继续阅读**：一张通栏纸面卡（`surface` + 发丝线，无阴影），宋体 28px 资料标题、上次停留章节、阅读进度细条（2px 绛线语法）、主按钮“继续阅读”。它是首屏唯一的高强调元素。
- **今日概览**：四个无容器统计项横向排开（本周阅读 X 篇 / 待整理知识点 X / 待巩固题目 X / 连续学习 X 天），等宽数字 + 辅助文字，不套卡片。
- **最近资料**：安静列表，行高 44px，列：类型小图标、标题（14px）、所在文件夹、更新时间；hover 出 `subtle` 底，行尾淡入“打开”。
- **右侧本周栏**：待办式清单（待整理知识点、待巩固训练），每条一个可勾选框 + 来源资料回链；无数据时给“去整理”动作，不虚构内容。

### 4.2 资料索引：目录 — 列表 — 详情

布局：导航侧栏 248 + 目录树列 232 + 弹性列表区 + 详情 Inspector 300（≥1440 停靠，1280–1439 收窄为 280，<1280 覆盖）。

- **目录树列**：顶部“资料库”标题 + 新建按钮；树行 28px，展开三角 + 文件夹图标 + 名称 + 计数（辅助色）；当前文件夹左侧绛线；回收站固定在列底。
- **列表区标题行**：当前文件夹名（20px）+ 资料计数；其下工具行：局部搜索框（左，240px）、类型/状态筛选 Select、排序；“新建资料”主按钮居右。
- **资料列表**：Notion 数据库式行，行高 40px：勾选框（hover 显现）、状态点（8px 圆点：已确认绿 / 待整理琥珀 / 草稿灰）、标题、标签（最多 2 枚，4px 方角 `accent-soft` 底）、更新时间；单击选中（`subtle` 底 + 左侧绛线）、双击打开。列之间无竖线，靠对齐与留白分组。
- **分页**：行高 32px 的安静分页器（‹ 1 2 3 … ›），等宽数字，当前页 `accent` 文字加粗，不做方册式硬影方块。
- **Inspector**：分组折叠节（信息 / 标签 / 关联 / 大纲 / 附件），节标题 12px 辅助色大写感（中文则为加字距小字），当前展开的节标题旁短绛线；危险动作（删除）收在节末独立菜单，红色文字、不预置红按钮。

### 4.3 资料编辑器：书桌中央

布局：顶部文档 Tab 带 + 命令工具条 + 中央阅读列 + 右侧边注面板（可关）+ 底部状态条。

- **文档 Tab 带**：高 36px，Tab 为 13px 文字 + 关闭 ×（hover 显现），当前 Tab 底部 2px 绛线 + 纸面白底（与下方编辑区连成一张纸），未保存点在标题后；溢出进“更多”菜单。
- **命令工具条**：高 40px，左侧“返回索引”、文件/编辑/段落/格式/视图文字菜单；右侧查找、源码、阅读预览、边注、专注五个图标开关。全部 32px 命中区，无填充按钮墙。
- **文档区**：阅读列 720px 居中（双侧栏时 ≥560px，不足则侧栏转覆盖）。文档标题宋体 36px；正文宋体 16px/1.75；H2 20px 宋体加粗；段落间距 12px。页边（阅读列左缘外 24px）用短绛线标出重点/边注锚点。
- **选中浮动格式条**：选中文本时浮起 36px 高黑底（`ink`）工具条——B/I/U/链接/重点/转为边注，是编辑器里唯一允许的反色元素。
- **边注面板**：300px，Tab 四枚（信息 / 大纲 / 重点 / AI），28px 高文字 Tab + 当前绛线；内容为登记表式条目，边注卡片引用原文片段（左侧 2px 琥珀线标示待整理、黛蓝线标示已确认）。
- **底部状态条**：高 28px，12px 辅助文字：保存状态（已保存 HH:MM / 保存中… / 保存失败·重试）、字数、行数、链接数；右侧源码/边注/专注开关与连接状态点。

## 5. 关键状态

| 状态 | 视觉与交互基线 |
| --- | --- |
| 全局搜索 | ⌘K 居中命令面板（宽 560px，10px 圆角，浮层阴影）：大输入框、分组结果（资料/知识点/训练）、右侧快捷键提示、无结果时给“新建资料”动作 |
| Menu | `surface` + `line-strong` 边 + 浮层阴影，10px 圆角，最小宽 200px；项高 32px，图标 16px；危险项独立分组、红色文字；打开聚焦首项，关闭焦点回触发器 |
| Dialog | 居中 420px，标题 16px + 说明 13px 辅助色 + 动作区右对齐；遮罩 `rgba(31,30,26,.32)` 无模糊；破坏性确认说明数据去向，不用浏览器原生弹窗 |
| Toast | 底部居中，36px 高 `ink` 底白字，成功带状态点，失败带“重试”按钮 |
| Tooltip | `ink` 底白字 12px，6px 圆角，延迟 400ms |
| 加载 | 列表/面板用骨架条（`subtle` 底、呼吸 1.2s），骨架只模拟结构不伪造文本；整页加载用 16px 转环 + “正在载入工作区…” |
| 空 | 居中：32px 线性插图位、14px 说明“为什么空”、一个主恢复动作（新建/清除筛选）；不放多个平级按钮 |
| 错误 | 区块内：`danger` 左竖线 + 标题“加载失败”+ 数据安全说明 + 重试按钮；编辑保存失败绝不显示“已保存” |
| 禁用 | `ink-3` 文字 + `subtle` 底，无边框强调；保留原生 disabled 语义，依赖未就绪时附说明（如学习档案门禁） |
| 状态徽标 | 8px 状态圆点 + 13px 文字（已确认绿/待整理琥珀/草稿灰），不做彩色胶囊 |

## 6. 响应式候选

| 有效宽度 | 策略 |
| --- | --- |
| `≥ 1440px` | 侧栏 + 双辅助栏全停靠，编辑器 720px 阅读列 |
| `1280–1439px` | 侧栏保留；Inspector 收窄 280px；编辑器低频命令进“更多”菜单 |
| `1024–1279px` | 侧栏收为 56px 图标轨；目录停靠、Inspector 覆盖；编辑器命令条紧凑 |
| `< 1024px` | 主区单列；所有辅助栏为带遮罩覆盖层，关闭后焦点回触发器 |
| `200% zoom` | 按有效 CSS 宽度落入覆盖策略，不挤压正文、不单设 zoom 特判 |

精确阈值允许 V4-04/V4-07 按 React Aria 控件固有宽度与真实 Milkdown 实测修订，但布局策略不得退回“挤压正文”。

## 7. V3 不得继承的视觉清单

1. `knowra-production-shell` / InkGrid 的粗黑外壳线、硬阴影与点阵背景。
2. 全大写英文眉题作为区块默认标题。
3. 超大衬线页标题与重复的中英双标题。
4. 同层叠加边框 + 底色 + 阴影 + 切角的多重强调。
5. 高特异性作用域覆盖旧 CSS 的实现方式。
6. 窄屏下多栏继续占位、把正文压到不可读宽度。
7. 文本链接伪装主按钮、图标按钮无稳定命中区。
8. 蓝色同时承担品牌/标题/选中/链接/焦点/状态的单色语义。
9. 装饰点阵、大图标、框线替代真实信息层级。
10. 用 CSS class 或 DOM 层级承载行为与业务状态。
