工作记忆与认知负荷

认知科学 / 记忆原理 已确认 更新于 昨天 21:40

工作记忆是认知系统的中转台：所有进入意识层面的加工——理解一句话、心算一道题、比较两个概念——都要先在这里占据一席之地。它的容量之小，常常超出学习者的直觉估计。

工作记忆的容量限制

Miller 在 1956 年提出的「7±2」广为人知，但后续研究（Cowan, 2001）将更可靠的估计修正为 4±1 个组块。这意味着当新材料包含的陌生元素超过四个时，理解就会开始崩塌，学习者表现为「每个字都认识，连起来看不懂」。

组块化是唯一的出路：容量限制针对的是「元素个数」而非「信息量」。一个象棋大师看棋局时看到的不是二十个棋子，而是三四个有意义的阵型。

认知负荷的三种类型

Sweller 将学习过程中占用工作记忆的负荷区分为三类，教学设计的几乎所有策略都可以归入对这三类负荷的调节：

  • 内在认知负荷——由材料本身的元素交互性决定，无法削减，只能拆分；
  • 外在认知负荷——由不当的呈现方式引入，是教学设计首先要消灭的对象；
  • 相关认知负荷——投入到图式建构与自动化中的负荷，应当被鼓励和引导。

以「分裂注意效应」为例：当图表与说明文字分离排版时，学习者不得不在两者之间反复切换视线，这部分开销纯属外在负荷。把标注直接嵌入图内，即可把省下的工作记忆让给真正的理解。

    if interactions > 4:

    return "可学：配合样例与变式"

教学设计的三条推论

从认知负荷理论可以直接推出三条可操作的结论：先降外在负荷，再拆内在负荷，最后用变式练习把腾出来的容量引向图式建构。它们将在下一章结合具体笔记实例展开。

「容量限制针对的是元素个数而非信息量……象棋大师看到的是三四个有意义的阵型。」

这条可以用来解释为什么「先搭框架再填细节」对数学同样有效——组块先于容量。
