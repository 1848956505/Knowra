## 1. 设计命题

Knowra 服务于需要长期阅读、整理和建立知识关联的中文用户。三张主视图的共同任务是：让用户在高密度资料中始终知道“我在哪里、这份内容从哪里来、下一步可以做什么”。

视觉方向命名为 **知识地形**。它不把知识表现为卡片堆叠，而把目录、来源、关联和阅读进度表现为一条连续的“认知脉络”。主页用地形线概览近期学习现场，索引用连续选择轨迹串联目录—资料—详情，编辑器用页边脉络节点连接标题、重点和边注。

## 2. 品牌与视觉原则

1. **内容先于容器**：标题、摘要、正文和关系是第一层；容器只在需要表达可操作边界时出现。
2. **安静但不苍白**：雾白与深松墨建立长时间阅读底色，湖绿色只表达当前位置和主要动作，琥珀色只表达需要关注的状态。
3. **密度可读**：桌面工作区采用 36px 紧凑控件、44px 关键动作、8px 基础节奏；不以缩小文字换取密度。
4. **关系可见**：路径、来源、关联、边注使用同一脉络线语法；装饰性线条不得伪装成数据。
5. **状态有文字**：加载、空、错误、保存和禁用均有文字/图标/语义，不只依赖颜色。
6. **动效服务定位**：仅使用 120–220ms 的显隐、选中轨迹和覆盖层过渡；减少动态时直接显示终态。

### 视觉签名

**认知脉络线**是唯一高辨识度元素：一条 1.5px 的湖绿色路径和实心/空心节点，分别表示当前落点、可追溯来源与未完成连接。它用于主页近期轨迹、索引当前选择和编辑器页边注锚点；不用于普通按钮和无关系内容。

## 3. Token 初稿

### 3.1 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-canvas` | `#EEF3F0` | 应用背景 |
| `--color-surface` | `#FBFDFB` | 主工作面、弹层 |
| `--color-surface-muted` | `#F4F8F5` | 次级面板、hover |
| `--color-ink` | `#17231F` | 主文字 |
| `--color-ink-muted` | `#5F6F68` | 次级文字 |
| `--color-line` | `#D6E0DA` | 结构分隔 |
| `--color-primary` | `#1F6B59` | 主动作、选中、脉络线 |
| `--color-primary-soft` | `#DCEBE4` | 选中背景、标签 |
| `--color-attention` | `#9B541F` | 待处理、警示 |
| `--color-danger` | `#A84440` | 错误、危险动作 |
| `--color-focus` | `#1769AA` | 键盘焦点环 |

主文字在 `surface` 上、白字在 `primary` 上均按 WCAG AA 正文标准校验；后续 V4-04 必须用自动化测试再次验证实际组合态。

### 3.2 字体

- UI：`"Avenir Next", "PingFang SC", "Microsoft YaHei", sans-serif`，正文 14px/1.55，标签不低于 12px。
- 中文内容标题：`"Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", serif`，只用于文章标题和阅读内容。
- 数字与快捷键：`"SFMono-Regular", Consolas, monospace`。
- 不依赖网络字体完成首屏；若 V4-04 引入字体文件，必须自托管并保留上述系统回退。

### 3.3 间距、圆角与层级

- 间距：`4 / 8 / 12 / 16 / 24 / 32 / 48px`。
- 控件高度：紧凑 `32px`，默认 `36px`，关键动作 `44px`。
- 圆角：小控件 `8px`，面板 `12px`，大型聚合卡 `18px`；不使用满屏漂浮胶囊。
- 阴影：只给 Menu/Dialog/Popover；固定工作区面板依靠背景层级和 1px 分隔线。
- 图标：统一 1.75px 线性 SVG，视觉尺寸 16/18/20px；图标按钮命中区至少 36px，窄屏关键入口至少 44px。

## 4. 三张主视图

### 4.1 主页：今天的学习现场

- 顶部保留全局搜索和工作域切换；主区不再重复所有导航入口。
- 首屏主卡显示“继续阅读”的真实资料、上次停留位置与直接动作。
- 右侧“本周脉络”用节点轨迹展示资料—知识点—训练的真实连接；无数据时显示建立连接的动作。
- 最近资料采用安静列表，不使用四张等权大卡。

### 4.2 资料索引：目录—结果—详情

- 桌面为 `导航 208 / 目录 248 / 弹性主区 / 详情 320`；选中轨迹从目录节点延伸到资料行和详情标题。
- 筛选器与局部搜索属于索引标题区，不与全局搜索混用。
- 资料列表默认 44–56px 行高，摘要按空间逐级隐藏，不压缩主标题。
- 详情栏优先展示来源、标签、关联和大纲；危险动作放在独立菜单末组。

### 4.3 资料编辑器：沉浸但可追溯

- 文档 Tab、菜单/工具条、文档头、正文、边注、Footer 分层明确。
- 正文最佳阅读宽度 `720px`；双侧栏存在时不低于 `560px`，再窄则侧栏改覆盖层。
- 页边脉络节点对应重点/边注锚点，点击后聚焦正文位置；颜色不是唯一选中信号。
- 标题控制在 32–40px，不继承 V3 的超大蓝色衬线标题。

## 5. 关键状态

| 状态 | 视觉与交互基线 |
| --- | --- |
| 搜索 | 居中 Command Dialog，结果分组为资料/知识/训练；显示快捷键、范围和无结果动作 |
| Menu | 8px 圆角、最小 220px；危险动作独立分组；打开聚焦首项，关闭返回触发器 |
| Dialog | 标题、说明、正文、动作区完整；破坏性确认不使用浏览器原生弹窗 |
| 侧栏 | ≥1280 停靠；1024–1279 按任务保留一侧、另一侧覆盖；<1024 两侧均覆盖且有明确关闭入口 |
| 加载 | 保留标题与面板骨架，骨架不模拟不可确定的文本；状态区使用 `aria-live` |
| 空 | 说明为什么为空，并提供唯一主恢复动作，如“清除筛选”或“新建资料” |
| 错误 | 标明失败对象和数据是否安全，提供“重试”；编辑失败不得显示已保存 |
| 禁用 | 降低强调但保持文字可读，保留原生 disabled 语义；必要时说明依赖条件 |

## 6. 响应式冻结候选

| 有效宽度 | 布局策略 |
| --- | --- |
| `≥ 1536px` | 完整功能导航、双侧栏停靠、编辑器 720px 阅读列 |
| `1280–1535px` | 导航收窄，双侧栏可停靠；低频工具进入更多菜单 |
| `1024–1279px` | 功能导航变图标 Rail；目录停靠，Inspector/边注覆盖；编辑器菜单紧凑 |
| `< 1024px` | 原型只定义工作区重排：侧栏均为覆盖层，主区单列；正式支持范围由后续产品决策确认 |
| `200% zoom` | 按有效 CSS 宽度落入覆盖策略；不建立单独 zoom 特判 |

精确阈值允许 V4-04/V4-07 根据 React Aria 控件固有宽度与真实 Milkdown 测量修订，但布局策略不得退回“挤压正文”。

## 7. V3 不得继承的视觉清单

1. `knowra-production-shell` / InkGrid 的粗黑外壳线、硬阴影和点阵背景。
2. 全大写英文眉题作为每个区块的默认标题方式。
3. 超大黑/蓝衬线页标题和重复的中英双标题。
4. 同一层级同时使用边框、底色、阴影、切角表达强调。
5. 依赖高特异性作用域覆盖旧 CSS 的视觉实现。
6. 208/232px 多栏在窄屏继续占位、把正文压到不可读宽度。
7. 把普通文本链接伪装成主按钮，或让图标按钮缺少稳定命中区。
8. 将蓝色同时用于品牌、标题、选中、链接、焦点和状态的单色语义。
9. 以装饰点阵、书本大图标和框线替代真实的信息层级。
10. 使用 CSS class 或 DOM 层级承载行为和业务状态。
