## 1. 中断任务接续结论

接手时工作区已有一版未提交实现：Shell、主页、搜索、Store 工作域状态和部分基础组件扩展均已写入，但尚未完成浏览器验收与文档收口。静态检查和单元测试能够通过，但审计发现以下阻塞项：

1. Shell Grid 把 `StatusBar` 与主工作面放在同一行，移动端 `MobileTabs` 也占错行；
2. “新建资料”实际打开全局搜索，通知/设置呈现为可用按钮但没有行为；
3. 搜索缺少清空入口和中文输入法 composing 保护，选择资料后没有可感知反馈；
4. 最近资料行只支持鼠标点击；
5. 组件展台仍进入首页主包，生产构建保留超过 500 kB 的 chunk 警告；
6. 缺少 V4-05 专项 Playwright、多视口证据、执行报告与路线图登记。

本轮保留可用的中断成果，逐项补齐上述缺口，没有重写已通过的 V4-04 基础组件。

## 2. 交付内容

### 2.1 公共 Shell

| 模块 | 文件 | 结果 |
| --- | --- | --- |
| AppShell / FeatureStage | `apps/web-v4/src/shell/AppShell.tsx` | 提供 skip link、桌面 Rail、TopBar、唯一主工作面、StatusBar、移动 Tab 与全局 live region |
| ModuleRail | `apps/web-v4/src/shell/ModuleRail.tsx` | 资料工作域可用；知识、试题、执行、个人、设置按真实能力禁用；活动项只使用蓝色定位 |
| TopBar | `apps/web-v4/src/shell/TopBar.tsx` | 提供工作区定位、全局搜索、主操作与通知槽；未实现动作使用原生 disabled 语义 |
| StatusBar | `apps/web-v4/src/shell/StatusBar.tsx` | 展示页面上下文和 API / 缓存 / 本地恢复 / 加载状态，不伪造保存或同步数据 |
| MobileTabs | `apps/web-v4/src/shell/MobileTabs.tsx` | ≤767px 切换为 5 项底部工作域导航，保留安全区并隐藏桌面 Rail |

Shell 使用 3 行桌面 Grid 与 4 行移动 Grid；状态栏和移动 Tab 均占据独立行，主内容滚动不会被底部固定区域遮挡。

### 2.2 全局搜索与快捷键

- TopBar 点击或 `Meta/Ctrl+K` 打开 640px 印格命令面板；`Escape` 关闭并归还触发器焦点。
- 搜索资料标题、标签和“返回资料主页”动作；支持输入过滤、清空、↑/↓ 高亮、Enter 选择。
- composing 期间不拦截 Enter，避免中文输入法误提交。
- 搜索输入补 `name`、`autocomplete="off"`、combobox/listbox 关系和 active descendant。
- 选择资料或标签后写入真实 Store 状态并通过 live region 宣告；资料索引/编辑器未上线前明确说明后续阶段，不伪装已打开编辑器。
- `Meta/Ctrl+/` 返回主页；工作域循环快捷键只在真实可用域之间切换，当前只有资料域时给出可感知说明。

### 2.3 主页真实数据与状态

- `HomeView` 从 Zustand `serverData` 派生最近资料、未删除资料数、目录数、标签数、收藏数和数据模式。
- 提供 ready / loading / empty / error / cache-error 五条稳定路径；错误状态带重试动作，缓存错误保留只读内容。
- 最近资料使用语义化 table；资料标题是原生 button，可 Tab 聚焦和 Enter 激活。
- 主页沿用 V4-00.5 印格冻结稿的三张核心工作域卡、暖纸点阵、零圆角、方点状态和硬阴影；移除统计卡片墙，计数收敛为账页式摘要。
- 未上线工作域既可从导航看见真实 disabled 状态，也可通过 URL 进入说明原因和返回路径的门禁页。

### 2.4 性能与基础组件支持

- `/showcase` 改为 `React.lazy + Suspense` 路由级加载：生产构建主包从中断版约 542 kB 降为 223 kB，组件展台独立为约 148 kB，500 kB 警告消失。
- `Dialog` 增加受控 `isOpen / onOpenChange` 与 `sm / md` 尺寸，供全局搜索复用 React Aria 焦点管理。
- `TagGroup` 补 tone、可见组名、计数、方点与 remove 契约，并同步展台和测试；仍由 `components/ui` 统一封装 React Aria。
- 路由切换时把焦点移到 `FeatureStage`；全局补 `touch-action: manipulation`，Dialog 补 overscroll containment，日期与时间改用 `Intl.DateTimeFormat`。
