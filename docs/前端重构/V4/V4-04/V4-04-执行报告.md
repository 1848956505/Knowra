### 1.2 `components/ui` 公共入口与 React Aria 封装约定（任务 2）

- `apps/web-v4/src/components/ui/index.ts` 单一公共入口，业务代码只能从此处 import。
- `react-aria-components` 仅由 `src/components/ui/**` 内的具体模块 import；`scripts/check-v4-boundaries.mjs` 继续门禁此约束。
- 业务代码禁止接触 React Aria 语义层，封装 API 与默认视觉解耦：
  - `<Dialog>` 暴露 `DialogTrigger` / `DialogBody` / `DialogFooter`；用户不写 `role="dialog"`。
  - `<Menu>` 暴露 `MenuTrigger` / `MenuItem` / `MenuSeparator` / `MenuHeader` + `<MenuPopover>`；用户不复写 `role="menu"`。
  - `<Tree>` / `<GridList>` / `<TagGroup>` 等集合组件的焦点与键盘完全由 React Aria 提供。
  - 视觉签名（颜色/字号/阴影/圆角/动效）一律引用 `var(--…)`；CSS Module 中禁止硬编码。

### 1.4 Tabs / Menu / Dialog / Popover / Tooltip（任务 4）

- `<Tabs items renderTab>`：底部 2px 蓝激活条；左侧 / 右侧键切换；Home/End 跳到首末；aria-label 落到 TabList。
- `<Menu>`：使用 `<MenuTrigger>` + `<MenuPopover>` + `<MenuItem>` + `<MenuSeparator>` + `<MenuHeader>`；danger 项用 `--ink-danger`，hover 翻转；aria-haspopup 与 focus 由 RAC 提供。
- `<Dialog title description isPending isDismissable>`：使用 React Aria `ModalOverlay`（自动焦点陷阱 + 背景 inert + Esc 关闭 + 关闭后焦点归还）；支持 `isPending` 提交中遮罩与 `isDismissable=false` 强提交。
- `<Popover>`：与 Menu 视觉一致；不接管非菜单用途（Quick Look、工具说明等）。
- `<Tooltip>`：hover/focus 触发，Esc 关闭，默认 250ms 延迟。

### 1.5 Tree / GridList / TagGroup 最小 Knowra 接口（任务 5）

- `<Tree items renderExtras>`：递归 `Collection` 注册嵌套子节点；`slot="chevron"` 给 RAC 展开按钮（满足其可访问性要求）；左侧缩进每层 14px，hover 暖纸底，selected 蓝软填，disabled 灰化。
- `<GridList items columns getKey>`：CSS Grid 模板；空数据通过 `renderEmptyState` 注入；支持 single / multiple selection。
- `<TagGroup label items renderRemove>`：22px 高、方点 6–7px；selected 翻转；可选移除按钮。

### 1.6 Badge / EmptyState / LoadingState / Panel（任务 6）

- `<Badge tone hideDot>`：5 种 tone（neutral/accent/success/warning/danger）+ 方点；2px 硬阴影。
- `<EmptyState title description primaryAction secondaryAction escapeAction>`：主+次+逃生三段；默认 `role="status"`、`aria-live="polite"`。
- `<LoadingState variant="bar"\|"dots">`：1.4s 行内进度条 / 方点脉冲；`role="status" aria-busy="true"`；`prefers-reduced-motion` 下冻结动画。
- `<Panel title headerActions footer flush>`：白纸底、1px var(--ink)、shadow-1；flush 模式给表格类子内容用。

## 4. 变更与风险说明

- V4-04 在 `apps/web-v4` 内增加了 24 个 `.tsx` 文件、6 个 CSS Module、3 份全局样式、9 个 RTL 测试文件、1 个 Playwright e2e 文件，未触碰 V3 runtime。
- `index.html` 追加 `color-scheme` / `theme-color`；`package.json` 追加 `test:e2e` 脚本；`vitest.config.ts` 显式限定 vitest 收集 `src/**`，避免把 `e2e/**/*.spec.ts` 误跑。
- `src/app/router.tsx` 是 V4 自己的最小 hash 路由器（仅 `/` 与 `/showcase`），不引入 react-router-dom；`useLocation` 在无 Provider 时退化静态 `/`，所以 V4-02 的现有 App 测试无需任何修改即可继续运行。
- Tree 的展开按钮必须以 RAC `Button` 配 `slot="chevron"` 渲染，否则 React Aria 会在开发模式输出 `Expandable tree items must contain a expand button` 警告；本任务在 `Tree.tsx` 内统一处理。
- Menu 触发器的 popover 由调用方通过 `<MenuPopover>` 显式包裹 `Menu`，避免 RAC 在 MenuTrigger 内同时挂载 trigger + popover + menu 导致焦点管理混乱。
