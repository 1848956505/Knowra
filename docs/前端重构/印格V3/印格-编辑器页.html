Transformer 架构精读
标签
多模态 注意力机制 添加标签

Transformer 由 Vaswani 等人在 2017 年提出，其核心是self-attention机制，完全摒弃了循环与卷积结构，使得序列建模可以高度并行。

1. 整体结构

模型由编码器（Encoder）与解码器（Decoder）两部分堆叠而成，每一层都包含多头注意力子层与前馈网络子层，并辅以残差连接与层归一化。

关键直觉：注意力让每个位置都能直接"看到"序列中的任意其他位置，路径长度为 O(1)，因此长程依赖比 RNN 更易学习。
阅读提示先理解数据流，再对照下面的 Q · K · V 实现；蓝色线条只标记结构，正文仍保持安静。

1.1 多头自注意力

注意力的计算基于查询（Q）、键（K）、值（V）三组向量，缩放点积注意力的公式如下：

# scaled dot-product attention
def attention(Q, K, V, d_k):
    scores = (Q @ K.transpose(-2, -1)) / sqrt(d_k)
    weights = softmax(scores, dim=-1)
    return weights @ V   # 加权求和

1.2 位置编码

由于注意力本身对顺序不敏感，需要注入位置信息。原论文采用正弦位置编码：

  • 偶数维度使用 sin，奇数维度使用 cos；
  • 不同频率的正弦波叠加，使模型能学习相对位置关系；
  • 后续工作多改用可学习位置编码或旋转位置编码（RoPE）。
