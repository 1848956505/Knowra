NAVIGATION / STATE SYSTEM 规则
· 宽度：全局功能栏固定 208px，与资料库索引页外壳对齐
· 分组：上下间距 22px；小标题为 11px / 800 / 大写字距，与功能项间距 8px
· 激活态：白底 + 左 4px 蓝条 + 700 字重
· 悬停：sunken 暖灰底
· 图标：Remix line 系（激活项可用 fill）
· 快捷键：等宽 KBD 右对齐（10px）
· 目录树图标（§六）：16px 跟随主文字色，Line 为主，激活节点用 Fill
· 底部固定「新建空间」主按钮；设置入口只在顶栏，侧栏不重复
· 功能栏与目录栏分离（方案 C）：功能导航栏不含目录树；资料等功能页的文件夹目录树独立成一栏（右侧 .catalog，232px、纸底、Level 2 右结构线、Tier D 树节点），全局功能栏保持纯功能
· 目录栏标题头：52px 高，16px 左右内边距，13px / 700 标题，使用文件夹图标 + 「资料目录」
· 目录栏动作：28px 紧凑方形按钮（蓝底新建 + 白底折叠），沿用顶栏 icon-btn 物理按压、硬影减档
· 树层级三级递减：根 700 / 文件夹 500 / 文件 400 且次级文字色——文件节点比文件夹再弱一级
辅助侧栏家族（Auxiliary Sidebar · InspectorWide）

辅助侧栏与宽版检查器归为同一家族：共用 4px 蓝色定位线、56px 标题头、图标方章、浅结构线与分组卡片；区别只在宽度和内容密度。
