# 知境 UI 风格设计文档

## 设计语言命名：「印格」InkGrid

> 取"墨印成格"之意——以粗黑边框为刻刀，以硬影为印泥，在暖白纸上压出一格格清晰有力的信息模块。

---

## 一、风格定位

「印格」是一套 **新粗野主义（Neo-Brutalism）** 界面设计语言，核心气质：

| 维度 | 关键词 |
|------|--------|
| 力量 | 粗边框、硬阴影、零圆角 |
| 秩序 | 网格、点阵背景、模块化卡片 |
| 温度 | 暖白底色、柔和强调色、纸感 |
| 交互感 | 物理位移、阴影坍塌、"按下去"的触感 |
| 目标印象 | 有态度的专业工具，兼具力量感与可信赖感 |

它区别于：
- **柔和 SaaS**（Notion / Linear）：印格拒绝圆角和模糊阴影，用硬边和实影建立存在感——但**布局范式向它们看齐**（顶栏 + 侧栏 + 检查器的成熟企业级三栏结构）。
- **纯粗野主义**（早期 Brutalism Web）：印格保留了暖色底、精致排版和克制的色彩，不是"丑酷"而是"力酷"。
- **Material / Fluent**：印格没有海拔系统、没有涟漪动效，用位移 + 硬影模拟物理世界。

### 1.1 强度分级总原则（v2.1 新增，核心哲学）

印格的力量感**只在框架层发力，不侵入内容层**：

| 层 | 范围 | 允许梯度（见 §四） |
|----|------|------------------|
| 外壳层 | 顶栏、侧栏分界、主页卡片、弹窗、主操作按钮 | Tier A / B 全量印格 |
| 工作面层 | 列表、树、编辑纸面、检查器内容 | 仅 Tier C / D，保持安静 |

验收硬指标：编辑纸面视野内（不含外壳）2px 黑边元素不超过 2 处。

## 二、色彩体系

### 2.1 基础色

| Token | 色值 | 用途 |
|-------|------|------|
| `--ink-bg` | `#F9F7F2` | 页面大背景（暖白纸感） |
| `--ink-surface` | `#FFFFFF` | 卡片/面板/输入框表面 |
| `--ink-surface-sunken` | `#F4F1EA` | 无边框内嵌层底色（Tier D）、行 hover |
| `--ink-border` | `#1A1A1A` | 边框、硬阴影、Logo 底色 |
| `--ink-text` | `#1A1A1A` | 主文字 |
| `--ink-text-secondary` | `#666666` | 次级文字、描述 |
| `--ink-dot-grid` | `#D1D1D1` | 背景点阵 |

### 2.2 强调色与语义色

黑与白是主角，彩色只做状态点缀。语义色**只允许**出现在下表位置，禁止用于装饰、图标常态、标题：

| Token | 主色 | Hover | 浅底 | 允许出现的位置 |
|-------|------|-------|------|---------------|
| `--ink-accent` | `#2563EB` | `#1D4ED8` | `#E0F2FE` | 主操作按钮、激活指示、focus 硬影 |
| `--ink-success` | `#16A34A` | `#15803D` | `#DCFCE7` | 保存成功 Toast、自动保存状态点、云端已连接 |
| `--ink-warning` | `#EA580C` | `#C2410C` | `#FFEDD5` | 未保存提示、「待整理」状态徽标、风险提示 |
| `--ink-danger` | `#DC2626` | `#B91C1C` | `#FEE2E2` | 删除按钮、错误 Toast、回收站操作 |

语义反馈块统一形态：**浅底 + 2px 同主色边框 + 3px 同主色硬影**（阴影用主色而非黑色，与 focus 蓝影同一套逻辑）。

### 2.3 分类色（标签）

| 变体 | 背景 | 边框 | 文字 |
|------|------|------|------|
| Blue | `#E0F2FE` | `#7DD3FC` | `#0369A1` |
| Green | `#DCFCE7` | `#86EFAC` | `#15803D` |
| Purple | `#F3E8FF` | `#D8B4FE` | `#7E22CE` |

**分类色与语义色物理隔离**：分类色永远是 1px 边框、无阴影的 tag 形态，不做按钮、不做反馈块。

### 2.4 暗色模式预案（v2.1 仅 token 验证，不交付完整暗色）

```css
[data-theme="dark"] {
  --ink-bg: #171512;              /* 暖黑，延续纸感色温 */
  --ink-surface: #211E1A;
  --ink-surface-sunken: #2A2621;
  --ink-border: #E8E4DC;          /* 边框反转为暖白 */
  --ink-text: #F2EFE9;
  --ink-text-secondary: #9C968C;
  --ink-dot-grid: #35312B;
  /* 硬影基因保留：实色、零模糊，降不透明度避免刺眼 */
  --ink-shadow-3: 4px 4px 0 rgba(232, 228, 220, 0.22);
}
```

约束：暗色下允许调整影的 alpha，但**禁止引入 blur**。

## 三、字体与排印

### 3.1 字体栈

| 角色 | 字体栈 |
|------|--------|
| UI 正文 | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` |
| 等宽（快捷键/Meta/统计） | `"SF Mono", "Menlo", monospace` |

### 3.2 字号梯度

| 层级 | 字号 | 字重 | 字距 | 备注 |
|------|------|------|------|------|
| Display | 42px | 800 | -1px | 仅设计系统展示页与营销页 |
| H1（页面标题） | 28px | 800 | -0.5px（仅 Latin） | 中文标题不加负字距 |
| H2（区块标题） | 16px | 700 | 0 | |
| Body | 14px | 400 | 0 | |
| Small / Meta | 13px | 400–600 | 0 | |
| Nav Label（全大写） | 11px | 800 | +1px | |
| KBD / 辅助说明 | 11px | 400 | 0 | **全局字号下限 11px，禁用 9/10px** |

### 3.3 排印规则

- 标题使用 800 字重营造力量感——这是印格的排印签名（Latin 生效）。
- **中文字重策略**：中文标题实际渲染依赖 PingFang SC Semibold（系统无 800 档），力量感由字号、黑边框环境与留白共同构成，不虚标；中文标题**不使用负字距**。
- 全部无衬线；全大写 Nav Label + 宽字距形成"分区标牌"效果；等宽字体用于快捷键、时间戳与统计数字。

## 四、边框与阴影（核心特征）

### 4.1 视觉层级四梯度

| 梯度 | 边框 | 阴影 | 适用 |
|------|------|------|------|
| **Tier A 浮起层** | 2px `--ink-border` | `--ink-shadow-3`（4px；弹窗用 `--ink-shadow-hero` 6px） | 一级卡片、弹窗、主按钮、拖拽中元素 |
| **Tier B 操作层** | 2px `--ink-border` | `--ink-shadow-1`（2px） | 次级按钮、图标按钮、输入框、页码 |
| **Tier C 结构层** | 1px `--ink-border` | 无 | 容器内子分区、Tab 边框、检查器分区、菜单栏分隔 |
| **Tier D 平面层** | 无 | 无 | 列表行、树节点、编辑纸面、代码块——仅用 `--ink-surface-sunken` 底色或留白区分 |

不使用 1.5px（亚像素渲染不稳定）。

### 4.2 硬阴影 Token

```css
--ink-shadow-1: 2px 2px 0 var(--ink-border);   /* Tier B */
--ink-shadow-2: 3px 3px 0 var(--ink-border);   /* 图标容器 */
--ink-shadow-3: 4px 4px 0 var(--ink-border);   /* Tier A 卡片 */
--ink-shadow-hero: 6px 6px 0 var(--ink-border);/* 弹窗 / Hero */
```

- 无模糊（blur = 0），纯色实影，方向固定右下 45°。
- 圆角全局 **0px**。
- **滚动容器补偿**：带硬影元素所在的滚动容器须预留 8px 内边距，防止右下影被 `overflow` 裁切。

### 4.3 线条层级系统（2026-08-03 定稿）

线条按「公共外壳 > 功能结构 > 轻分割」分为三级；线条只表达空间关系，不替代控件边界和状态指示。

| 层级 | Token | 规格 | 适用范围 |
|------|-------|------|----------|
| Level 1 外壳线 | `--ink-line-shell` | `2px solid #1A1A1A` | 顶栏底线、全局功能导航边界等公共框架 |
| Level 2 功能结构线 | `--ink-line-panel` | `1px solid #E5E2DC` | 目录栏/检查器边界、辅助侧栏头部下边界、Tab 容器底线 |
| Level 3 轻分割线 | `--ink-line-soft` | `1px solid #F0EEE9` | 用户操作区短分隔、列表行、详情分组和内容组内分隔 |

实现约束：

- Level 1 的颜色与尺寸固定，不随工作面降噪策略变化。
- Level 2 / Level 3 使用低对比度暖灰，避免与正文和主操作争夺注意力。
- 按钮、输入框、卡片等交互或实体容器可继续使用 `2px #1A1A1A` 黑边；它们属于控件/容器 affordance，不归入页面结构线。
- 不使用 `1.5px`；所有分隔线均为 1px 或 2px，保证渲染稳定。

### 4.4 可折叠辅助侧栏

辅助侧栏是跟随当前工作面提供目录、资料详情、检查器、筛选或上下文操作的区域，不承担全局导航职责。

| 属性 | 规格 |
|------|------|
| 默认宽度 | `232px` |
| 头部高度 | `52px` |
| 折叠按钮 | `28 × 28px` 方块按钮，保留按压反馈 |
| 展开态 | 图标 + 标题 + 可选动作，内容区独立滚动 |
| 折叠态 | 内容隐藏，保留方块按钮作为重新打开入口 |
| 线条 | 外侧边界/头部下边界用 Level 2；内部 section 用 Level 3 |
| 镜像 | 可作为左侧目录或右侧详情使用，同一套状态和尺寸规则 |

## 六、图标

- **图标库**：Remix Icon；常规 16px（导航/行内）、24px（模块卡片）。
- **图标容器**：48×48 方形，2px 黑边框 + 3px 硬阴影，暖白底色。
- **颜色**：默认跟随 `--ink-text`，无彩色图标；Line 风格为主，Fill 仅用于激活态。
- Logo 位不再使用 `ri-brain-line`（见 §八 #31 品牌 Mark）。

## 七、交互与动效

| 场景 | 表现 | 时长 |
|------|------|------|
| 按钮 hover | `translate(-1px, -1px)` + 阴影扩大 1px | 0.1s ease |
| 按钮 active | `translate(2px, 2px)` + 阴影归零（"按进去"） | 0.1s ease |
| 卡片 hover | `translateY(-4px)` 上浮 + **阴影 4px → 6px**（浮得越高影子越远） | 0.2s |
| 导航/行 hover | 背景 `--ink-surface-sunken` | 0.1s |
| focus-visible | 全局 `outline: none; box-shadow: 3px 3px 0 var(--ink-accent)` | 即时 |
| Toast 入场 | `translateY(-8px) → 0` | 0.15s，无淡入淡出 |

核心原则：物理隐喻（悬停浮起、按下塌入）；时长 ≤ 0.2s；无渐变、无弹跳、无模糊过渡。
**禁止 `* { outline: none }`**；focus 可见性由蓝色硬影统一承担。

## 九、页面结构规格

### 9.1 全局外壳（三页共用，Notion/Craft 式企业级三栏）

```
┌──────────────────────────────────────────────────────┐
│ 顶栏 60px：Mark+品牌名 ｜ 全局搜索(⌘K)居中 ｜ 动作区    │  2px 黑下边框
├─────────┬────────────────────────────────┬───────────┤
│ 功能栏   │ 主区（随页面变化）              │ 辅助栏     │
│ 208px   │                                │ 232px     │
│ 纯功能   │                                │ 可折叠     │
│ 导航     │                                │           │
│（轻模块  │                                │           │
│ 重功能） │                                │           │
│ 底：新建 │                                │           │
│ 空间     │                                │           │
├──────────────────────────────────────────────────────┤
│ 底部状态栏 32px：当前功能页状态内容（全宽 Shell Footer） │  2px 黑上边框
└─────────┴────────────────────────────────┴───────────┘
```

- **功能栏 = 纯功能导航**：按「轻模块、重功能」组织——工作台 / 资料库 / 知识库 / 训练场 / 学习档案等小标题分组，直接罗列成熟命名的功能项，不做「01/02」模块切换器；占位模块也作为功能组常驻。激活 = 白底 + 左 4px 蓝条 + 700 字重。
- **底部固定「新建空间」主按钮**；设置入口只在顶栏，功能栏不重复。
- **功能栏不承载目录树**（见 §9.5 功能栏与目录栏分离原则）。
- 三栏各自独立滚动；1280px / 1440px 视口不得横向溢出；
- **Shell Footer 与三栏主体同级**：固定在页面最底部、占满整行，外壳高度为 32px；侧栏必须在 Footer 上方结束，不得覆盖 Footer；页面只提供内容，不改变宿主位置。
- 「专注」模式隐藏顶栏并收起功能栏、目录栏与检查器，Footer 保留并显示编辑器状态。

### 9.5 功能栏与目录栏分离原则（方案 C）

**全局功能栏与功能页目录栏物理分离，各占一栏，职责不混。**

| 栏 | 归属 | 内容 | 规格 |
|----|------|------|------|
| 功能栏 `.sidebar` | 全局（三页共用） | 跨模块功能导航（轻模块重功能） | 208px，见 §9.1 |
| 目录栏 `.catalog` | 功能页专属（如资料库） | 该模块的文件夹/条目目录树 | 232px，纸底 Tier A 外框、Tier D 树节点，排在功能栏右侧 |

- 目录树**只出现在需要它的功能页**（资料库索引页/编辑器页），以独立列形式插在功能栏与主区之间；主页等无目录需求的页面不出现目录栏。
- 目录栏头部：分区标牌小标题 + 新建动作图标；树节点激活 = 白底 + 左 4px 蓝条。
- 禁止把目录树塞进全局功能栏（那样会让功能栏在不同页面语义漂移）。

### 9.2 资料库索引页

四栏布局：功能栏（§9.1）｜ 目录栏 `.catalog`（§9.5 文件夹树）｜ 主区 ｜ `IndexInspector` 资料预览检查器。主区自上而下：H1 标题区（无边框）→ 视图 Tab（#23）→ 过滤栏（#22 ×3 + 局部搜索）→ 列表容器（Tier A 外框 + Tier D 行，行内含 44px 缩略方章 `.doc-thumb`）→ 分页器（#29）。右栏 `IndexInspector` 使用 232px 紧凑辅助栏；需要宽版预览卡时才使用 #25 `InspectorWide` 的 300px 变体。

### 9.3 编辑器页

编辑器页与索引页共用固定顶部栏和 208px 功能导航；编辑器工作面为「可折叠目录栏（232px）｜主区｜边注辅助侧栏（232px）」三栏结构。主区自上而下：文档 Tab 条（#27）→ 菜单栏（#28）→ 面包屑 + 状态徽标行 → 标题区（左 4px 蓝条，仅覆盖文档类型/标题）→ 编辑纸面（纯 Tier D，白底无边框无点阵，最大行宽 760px 居中）。底部状态栏（#24）是全局 Shell Footer，横跨整个视口并位于三栏主体之外；编辑器只提供保存状态、字数、视图开关等内容，侧栏不得覆盖；专注模式隐藏顶部栏并收起两侧栏。

### 9.4 主页（低保真）

全局外壳（无检查器）+ 欢迎区（H1 + 摘要行）+ 工作域 4 卡（1 激活 Tier A + 3 禁用 Tier C +「即将开放」tag）+ 最近编辑表。网格 `repeat(auto-fill, minmax(260px, 1fr))`。

## 十、可访问性规则

1. focus 可见性：全局 `:focus-visible` 蓝色硬影（§七），禁止裸删 outline；
2. 字号下限 11px；
3. 次级文字 `#666` 不用于 12px 以下正文场景；
4. 装饰性图标 `aria-hidden="true"`，可访问名称由外层按钮/label 提供；
5. 所有交互元素可键盘到达，Tab 顺序与视觉顺序一致。

## 十一、迁移风险控制（面向主工程）

1. **data-\* 事件钩子契约**：demo 中对应现有交互的元素标注现有钩子名（以 `apps/web/lib/` 渲染器实际代码为准）；迁移只重写渲染器模板与 CSS，控制器与状态层不动。
2. **分阶段路线**：① 外壳先行 → ② 索引页 → ③ 编辑器页；每步独立回退、独立测试。
3. **功能对等验收**：以《印格InkGrid-v2.1-打磨方案.md》§2.8 对等清单逐项核对；任何暂缓/删除必须回方案书记录。

## 十二、设计哲学总结

1. **边框即结构**：2px 黑线是最强的视觉组织工具。
2. **硬影即层级**：无模糊实影模拟纸片叠放。
3. **零圆角 = 态度**：直角传达精确、果断、不讨好。
4. **暖底中和冷硬**：#F9F7F2 + 点阵，让粗野不冰冷。
5. **按压即反馈**：translate + 阴影坍塌，无需学习成本。
6. **框架有力，内容安静**（v2.1）：印格的拳头只打在外壳上，工作面永远让位给内容。
