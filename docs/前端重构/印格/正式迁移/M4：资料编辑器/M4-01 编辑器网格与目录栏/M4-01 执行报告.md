## 任务范围

依据 M4-01 任务书，建立正式 Vanilla JS 编辑器的“目录栏｜EditorMain｜边注栏”布局，并将编辑工作面接入命名 `inline-size` 容器查询状态，覆盖 Full、Compact、Protected、Overlay 四档模式及目录/边注四种组合。

## 主要实现

- 新增 `apps/web/lib/editor/layout-state.js`，集中维护 `1120 / 900 / 720px` 冻结断点、232px 目录栏/边注栏保留宽度和四档模式解析。
- `shell-controller` 在编辑器工作面渲染时写入 `data-editor-layout`，并通过窗口尺寸变化的下一帧调度同步状态，避免布局写回发生在浏览器 ResizeObserver 通知阶段。
- `editor-workspace-view` 接入 `container-type: inline-size` 与 `container-name: editor-main`；菜单间距、紧凑字体和源码分栏规则改由 `@container editor-main` 驱动。
- Full 模式保留目录栏、EditorMain 和边注栏三列停靠；Compact 模式允许双侧栏停靠并收紧菜单间距；Protected 模式保留目录栏停靠、边注栏覆盖；Overlay 模式将目录栏与边注栏同时移入覆盖层，正文不继续压缩。
- 边注栏固定使用 `--ink-marginalia-w` 的 232px，不再受通用 `--aside-width` 漂移影响；边注重开入口改为绝对定位，避免折叠后形成额外网格行。
- 修复功能导航与目录栏同时隐藏时 ShellBody 遗留 208px 空列的问题，专注/无侧栏状态下 EditorMain 回到完整可用宽度。
- 按 AppShell 总宽度扣除当前应占用的 208px 功能导航与 232px 目录栏轨道，再解析 EditorMain 模式；相同侧栏组合不再受上一轮 `data-editor-layout` 或切换历史影响。
- Overlay 目录栏让出编辑器文档 Tab/菜单首层，菜单打开时临时清除目录栏的视觉与命中层，保证可通过“视图 → 隐藏左侧目录区”关闭目录栏，同时保留目录内容可交互。
- 边注栏补齐命名区域、`aria-expanded`、`aria-controls` 和动态隐藏语义；关闭后焦点回收到“展开资料边注”，重开后焦点返回关闭触发器。

### 1280×720 四种侧栏组合

| 组合 | `left / right` | 模式 | 目录栏 | 边注栏 | 页面横向溢出 |

## A-023 驳回问题修复记录（执行侧）

### 1280×720 组合路径复验

以真实 API 资料 `Transformer` 进行 UI 操作，分别从不同历史进入同一组合：

| 操作路径 | 最终组合 | 模式 | EditorMain 工作面 | 结果 |
| --- | --- | --- | --- | --- |
| 双侧栏关闭边注 | `true / false` | Protected | x=440，w=840 | 通过 |
| 无侧栏打开目录 | `true / false` | Protected | x=440，w=840 | 与上一行一致 |
| 双侧栏关闭目录 | `false / true` | Compact | x=0，w=1280 | 通过 |

两条进入 `showLeft=true / showRight=false` 的路径均稳定解析为 Protected，目录栏均为 `relative` 停靠，不再出现 Overlay 分叉；页面 `document.body.scrollWidth` 保持 1280。

### Overlay 菜单与边注焦点复验

- Overlay 目录栏从 ShellBody 顶部让出文档 Tab/菜单行；“视图”按钮中心点命中编辑器菜单。
- 打开“视图”菜单后，目录栏暂时 `visibility:hidden; pointer-events:none`，可以点击“隐藏左侧目录区”，操作后目录栏隐藏且布局进入仅边注栏状态。
- 点击“收起资料边注”后，`#editor-aside-reopen` 可见并成为 `document.activeElement`；边注栏 `hidden=true`、`aria-hidden=true`，两侧触发器均保持 `aria-controls="kb-aside"`、`aria-expanded="false"`。
- 点击“展开资料边注”后，`#editor-aside-toggle` 恢复焦点；边注栏重新可见，关闭触发器 `aria-expanded="true"`，重开按钮隐藏。
