## 发现

### M4-05-P1-1 标签编辑重绘后焦点丢失

- 路径：信息 → 添加标签；以及展开后点击“收起”。
- 实测：操作后输入框或恢复后的“添加标签”按钮已渲染，但 `document.activeElement === BODY`。
- 原因：`data-note-tag-toggle` 分支切换状态并直接 `renderSidebar()`，没有在重绘后把焦点移入标签输入框，或在关闭后返回触发按钮。
- 影响：键盘用户激活标签编辑后丢失当前位置，无法连续完成标签添加/收起路径；违反焦点始终可见与重绘后恢复合理焦点的契约。
- 优先级：P1。

### M4-05-P1-2 附件重命名取消/提交后没有焦点返回目标

- 静态证据：`startAttachmentRename()` 会聚焦新输入框，但 `cancelAttachmentRename()` 与成功提交路径只清空状态并 `renderSidebar()`，没有聚焦恢复后的附件条目或重命名触发器。
- Escape 取消也复用该路径，原输入框会从 DOM 中移除，因此浏览器焦点回落到 `BODY`。
- 影响：附件重命名的取消、Escape 和成功提交均中断键盘链路；违反 M4-05 的附件动作与焦点管理验收项。
- 优先级：P1。
