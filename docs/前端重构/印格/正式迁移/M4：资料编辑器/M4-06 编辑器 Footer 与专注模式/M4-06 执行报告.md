5. 资料边注按“资料 ID + 边注 Tab”保存内部滚动位置，重绘、进入专注与退出专注后恢复当前 Tab 及其滚动偏好；正文继续复用既有逐资料滚动恢复机制。
6. 补齐源码输入/预览/自动保存和源码手动保存的直接事件测试，并扩展专注恢复、Footer 保存失败、ARIA、Shell 隐藏边界与边注滚动回归。
