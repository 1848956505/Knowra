## 复验发现

### P1-1 溢出菜单仍无法切换隐藏标签

- 场景：1280×720、10 个打开标签；打开“显示其余 2 个标签页”，点击隐藏项“讲义生成prompt”。
- 结果：溢出菜单关闭，但活动标签仍为“Transformer”，未切换到被点击的隐藏资料。
- 影响：隐藏文档仍无法通过溢出入口访问，违反 M4-02 的溢出菜单功能要求。

### P1-2 未保存修改仍不显示 Tab 脏点

- 场景：编辑真实资料 `Transformer` 的标题为临时值 `验收临时标题-M4-02`，在保存状态为 `pending` 时读取运行态。
- 结果：活动 Tab 仍为 `data-dirty="false"`，`.note-tab-dirty` 为空，Tab 可访问名称没有“有未保存修改”后缀。
- 复验后已恢复标题 `Transformer`，并确认状态回到 `saved`，未保留验收临时修改。
- 影响：用户无法从文档 Tab 识别当前资料存在未保存修改，违反任务书要求保留脏点。

### P2-1 Tab/tabpanel 关系与焦点连续性仍不完整

- `#note-tabs` 的直接子节点仍包含无角色的 `.note-tab` 容器和无角色的溢出按钮；溢出入口仍位于 `tablist` 内。
- Tab 没有唯一 `id`，均指向同一个 `aria-controls="editor-scroll-region"`；`#editor-scroll-region` 没有 `aria-labelledby`；溢出菜单没有明确的 `role`。
- 点击可见 Tab `CLIP` 触发重渲染后，活动 Tab 已切换但 `document.activeElement` 落到 `BODY`，焦点未保持在活动 Tab 或编辑面板。
