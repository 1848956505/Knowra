## 发现的问题

### P1-1 溢出菜单无法切换隐藏标签

- 场景：1024×768、6 个可见 Tab/4 个隐藏 Tab；打开 `#note-tab-overflow-menu` 后点击隐藏项“Untitled Note 2”。
- 结果：菜单关闭，但活动 Tab 仍为“Untitled Note 3”，没有切换到被点击的隐藏资料。
- 影响：9+ 标签场景下隐藏文档不可通过溢出入口访问，直接违反 M4-02 的溢出菜单功能要求。

### P1-2 未保存修改不显示 Tab 脏点

- 场景：对 M4-02 长标题真实资料修改标题，立即读取运行态。
- 结果：保存状态为 `pending`，但活动 Tab 仍为 `data-dirty="false"`，`.note-tab-dirty` 隐藏，Tab 可访问名称也没有“有未保存修改”后缀。
- 影响：用户无法从文档 Tab 识别未保存状态，违反任务书要求保留脏点。
- 复测后已将该临时标题恢复为原值，未保留验收文本修改。

### P2-1 Tab/tabpanel 关系与焦点连续性不完整

- `#note-tabs` 虽有 `role="tablist"`，但溢出按钮作为无角色的直接子节点仍位于 tablist/Tab 宿主内；溢出入口没有移到滚动区外。
- `role="tab"` 没有唯一 `id`，`#editor-scroll-region[role="tabpanel"]` 没有 `aria-labelledby`，当前关系只能依赖所有 Tab 共用的 `aria-controls`。
- 点击 Tab 触发重渲染后，焦点落到 `BODY`，没有保持在活动 Tab 或编辑面板；焦点连续性不满足 03-验收与回归方案的要求。
