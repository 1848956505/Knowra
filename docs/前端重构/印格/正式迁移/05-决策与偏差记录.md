# 正式 UI 迁移决策与偏差记录

本文件由规划与验收方维护。执行模型只能提出决策请求，不能直接修改结论。

## 已冻结决策

### D-001 正式迁移目标

- 状态：已冻结
- 决策：迁移目标为当前 Vanilla JS SPA；不接入 React/Next JSX 探索目录。
- 原因：现有控制器、事件、状态、API 和测试均围绕当前运行时建立。

### D-002 唯一 Token 来源

- 状态：已冻结
- 决策：`apps/web/styles/components/knowra-theme-tokens.css` 继续作为唯一来源；InkGrid Token 在该文件内落地，并通过别名兼容旧样式。

### D-003 图标策略

- 状态：已冻结
- 决策：目标视觉使用 Remix Icon 语义，但正式运行资源必须本地化；禁止 CDN。
- 约束：替换必须有语义映射和回归测试。

### D-004 Shell Footer 归属

- 状态：已冻结
- 决策：Footer 的位置、尺寸和全局状态属于 AppShell；保存、统计、源码、边注等由当前功能注入。

### D-005 侧栏归属

- 状态：已冻结
- 决策：208px 功能导航属于 AppShell；232px 资料目录和 232px 资料边注属于资料功能工作面。

### D-006 响应式判断基准

- 状态：已冻结
- 决策：编辑器降级依据 `EditorMain` 容器宽度，不依据浏览器总宽度。

### D-007 未提供设计稿的工作域

- 状态：已冻结
- 决策：知识、训练、学习档案只做新外壳兼容，不在本轮擅自重设计内部页面。

## 暂定决策

### D-008 初始容器阈值

- 状态：暂定，M0 实测后冻结
- 决策：1120px Full、900px Compact、720px Protected，低于 720px 使用 Overlay。
- 变更条件：必须提供工具栏固有宽度测量和四种侧栏截图。
