# M1-02 图标本地化与映射执行报告

## 任务状态

`执行完成 / 待验收方复验`

本报告只记录 M1-02 的执行结果，不替代正式验收方的结论。

## 结果概述

已完成正式 Vanilla JS SPA 的图标本地化与语义映射：64 个语义图标名称统一由一个映射模块解析到本地 Remix SVG 资源，目标 Shell、目录树、索引、搜索、侧栏、编辑器及 Milkdown 表格/图片交互均已接入。运行时代码不引入 CDN，不在页面渲染器内复制图标 SVG path。

## 实现内容

### 1. 本地资源与中央映射

- 新增 `apps/web/styles/icons/remix/`，固化正式运行时使用的 SVG 文件。
- 新增 `apps/web/lib/icons/icon-map.js`，集中维护 64 个语义名称与本地资源路径。
- `renderIcon()` 输出统一的 `.semantic-icon` 节点，通过 CSS mask 使用本地资源并继承 `currentColor`。
- 未知语义名称返回空字符串，避免产生无效资源请求。
- 未新增 Remix npm 运行时依赖；编辑器 bundle 仍由现有 `build:editor-bundle` 脚本生成。

### 2. 正式页面接入

- Shell：品牌标记、创建、返回、更多操作。
- 资料索引与目录树：索引标记、文件夹/文件类型、折叠箭头、筛选、检查器和分组图标。
- 搜索与侧栏：搜索、标签移除、附件重命名/确认/取消、信息面板折叠。
- 编辑器：上下文菜单、子菜单箭头、快捷工具、查找面板关闭、文档 Tab 关闭/溢出菜单。
- Milkdown：表格增删行列、插入前后行列、对齐、拖拽手柄，以及图片确认按钮。

### 3. 语义与无障碍

- 装饰性图标统一由 `renderIcon()` 输出 `aria-hidden="true"`。
- 交互按钮继续保留中文可访问名称；附件确认/取消和编辑器关闭等按钮补齐了 `aria-label`。
- 交互状态仍由既有 `data-*` 属性承载，图标替换没有改变事件选择器或控制器状态。

## 禁止项复核

- CDN：未发现图标运行时 HTTP/CDN 资源引用。
- 手绘替代 SVG：迁移的图标渲染器不再包含 `<svg>`/`<path>` 图标内容。
- 页面内复制路径：目标渲染器只使用语义名称，资源路径仅保留在中央映射模块。
- 例外说明：`apps/web/lib/editor/milkdown/host/image-paste-controller.js` 中保留的是用户图片占位内容 SVG，不是 UI 图标；它不属于 M1-02 图标清单。
