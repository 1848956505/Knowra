## 2. 自动化验证证据

`apps/web/test/icon-mapping.test.js` 覆盖：

- 语义清单数量、映射冻结和未知名称行为。

- 渲染结果包含语义名、本地资源路径、`aria-hidden` 和 `data-*` 状态属性。

## 3. 资源离线证据

- 运行时图标 URL 不含 `http://` 或 `https://`。
- 资源目录由正式静态资源服务直接提供，不依赖第三方网络请求。
- CSS 使用本地 SVG 作为 mask source，图标颜色继承当前语义文本色。
- 受控 editor bundle 已由现有构建脚本重建，Milkdown 表格和图片确认按钮引用同一语义映射。

## 4. 验收边界

本任务只替换图标资源与渲染表达，不改变既有业务事件、控制器、状态、API 或编辑器宿主逻辑。用户图片占位 SVG 属于内容渲染，不作为 UI 图标纳入本任务；后续如需清理该内容，应单独建立资源/内容渲染任务。
