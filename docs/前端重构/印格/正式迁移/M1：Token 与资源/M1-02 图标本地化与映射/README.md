# M1-02 图标本地化与映射

## 任务状态

`PASS / 已通过验收（2026-08-04）`

本目录只记录 M1-02 的实现、测试与证据，不替代正式验收记录。

## 任务范围

- 确定正式运行时需要的 Remix 图标清单。
- 将 SVG 资源固化到 `apps/web/styles/icons/remix/`。
- 通过 `apps/web/lib/icons/icon-map.js` 建立语义名称到本地资源路径的唯一映射。
- 将 Shell、资料索引、目录树、搜索、侧栏、编辑器和 Milkdown 表格/图片交互图标接入映射。

## 验收契约落实

- 正式运行时不依赖 CDN；图标路径均指向本地静态资源。
- 图标渲染器不再复制页面内 SVG path；统一输出语义图标节点。
- 装饰性图标带 `aria-hidden="true"`；图标按钮保留中文 `aria-label`/`title`。
- 未改变控制器、状态、API 或 Milkdown 宿主边界；编辑器 bundle 继续由现有构建脚本生成。
