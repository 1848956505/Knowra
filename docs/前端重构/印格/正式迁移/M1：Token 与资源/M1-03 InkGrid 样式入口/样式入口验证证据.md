## 作用域门禁

五个 canonical `knowra-inkgrid-*` 职责模块的规则均以 `.knowra-production-shell` 开始；唯一的基础页面例外是 `body:has(.knowra-production-shell)`，用于在正式 Shell 存在时应用页面基础色和最小宽度。

`inkgrid-style-entry.test.js` 会逐个解析新模块的规则前导选择器，禁止未进入正式 Shell 作用域的选择器。

## 复修：1180px 响应式变量作用域

退回报告指出，媒体查询曾写成 `.knowra-production-shell :root`。由于 `:root` 代表文档根 `html`，而 `html` 不可能是 `.knowra-production-shell` 的后代，该规则在 1180px 以下不会匹配。

已修正为媒体查询内的 Shell 自身声明：

```css
@media (max-width: 1180px) {
  .knowra-production-shell {
    --rail-width: 240px;
    --aside-width: var(--rail-width);
    --index-inspector-width: var(--rail-width);
  }
}
```

入口回归测试同时断言：

- `.knowra-production-shell` 的媒体查询块必须声明上述三个变量。
- 不得重新引入 `.knowra-production-shell :root` 这一不可匹配选择器。

复修后 `node apps/web/test/inkgrid-style-entry.test.js` 通过；导入图仍为 29 个样式文件，无缺失、无循环。
