# M2-01 AppShell 网格执行报告

## 任务状态

`执行侧完成 / 待规划与验收方复审`

本报告只记录 M2-01 的执行结果，不替代正式迁移规划和验收方的结论。

## 结果概述

已将正式 Vanilla JS SPA Shell 从“左侧导航 + 主体内 Footer”的复合结构调整为三行 AppShell：

```text
AppShell
├── TopBar
├── ShellBody
│   ├── FunctionNavigation（沿用现有资料导航，M2-03 再拆分）
│   └── FeatureStage（沿用现有索引、编辑器和工作域容器）
└── StatusBarHost
```

TopBar 当前只建立结构槽位；搜索、品牌 Mark、通知、设置和用户区仍留给 M2-02，避免扩大本任务范围。

## 修改文件

- `apps/web/src/server/shell-html.js`
  - 为正式根节点补充 `app-shell` 语义类。
  - 新增 `data-ui-topbar` 的 TopBar 槽位。
  - 新增 `shell-body` / `data-ui-shell-body`，收纳现有资料导航和 FeatureStage。
  - 将 Footer 移出 FeatureStage，保留原有 `status-indicators`、`status-meta` ID。
  - 保留上下文菜单宿主、`markdown-import-input`、SSR 初始脚本和所有既有业务节点 ID。
- `apps/web/styles/components/knowra-inkgrid-shell.css`
  - AppShell 使用 `--ink-topbar-h`、`--ink-statusbar-h` 建立三行网格。
  - ShellBody 负责主体两列和 `min-height: 0` / `overflow: hidden` 滚动边界。
  - StatusBarHost 在主体之外固定 32px 高度并建立独立 z-index。
  - 移除索引页隐藏全局 Footer 的旧规则。
- `apps/web/test/app-shell-grid.test.js`
  - 增加 SSR 结构、顺序、宿主保留项、三行网格、高度、层级和溢出边界断言。

## 保留的正式契约

- `#workspace-shell`、`#kb-sidebar`、`#kb-workspace`、`#editor-scroll-region` 等现有 ID 未改变。
- 既有 `data-*` 事件属性、控制器查询、状态语义、API envelope、Milkdown 宿主和工作区启动流程未改变。
- `data-ui-*` 仅承担新外壳结构和视觉测试语义，不替代控制器使用的正式 action selector。
- Footer 仍由现有状态渲染器注入，未新增并行状态栏。
- M2-02/M2-03 的内容和宽度迁移未提前实现。
