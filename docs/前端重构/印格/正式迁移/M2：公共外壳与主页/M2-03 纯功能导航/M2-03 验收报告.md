### 4.2 功能路径

1. 资料库 → 知识库：PASS。主体切换为知识库，`knowledge` 入口带 `aria-current="page"`，功能导航保留，资料目录隐藏。
2. 知识库 → 训练场：PASS。主体切换为训练场，`training` 入口激活，资料目录隐藏。
3. 训练场 → 学习档案：PASS。主体切换为学习档案，`learning` 入口激活；学习档案继续展示真实依赖门禁，不伪造掌握度。
4. 学习档案 → 资料库：PASS。返回资料索引，`materials` 入口激活，资料目录重新显示。
5. 占位入口：PASS。共 15 个占位项，均为原生 `disabled` 且 `aria-disabled="true"`，不带 `data-module-key`，不产生业务切换。
6. 设置入口：PASS。功能导航不含设置；TopBar 保留 1 个设置占位，点击前后仍为资料索引且无业务状态变化。
7. 专注模式边界：PASS。资料库编辑器进入专注模式后，功能导航和资料目录同时隐藏，退出后恢复；页面无横向溢出。

### 4.3 可访问性与结构

- 功能导航使用原生 `nav`、`section`、`h2` 和 `button`，五组均有中文可访问名称。
- 当前工作域使用 `aria-current="page"` 和 `data-active="true"` 双重状态。
- 占位入口使用原生禁用按钮、`aria-disabled="true"`、中文 `aria-label` 和 `title`。
- 图标为装饰内容并使用 `aria-hidden="true"`；交互入口没有复制 SVG path 或 Unicode 图标。
- 设置未重复挂载到功能导航，资料库目录保留独立的 `aria-label="资料库目录"`。
- 本任务未单独完成屏幕阅读器和 200% 缩放审计；截图不替代该类门禁。
