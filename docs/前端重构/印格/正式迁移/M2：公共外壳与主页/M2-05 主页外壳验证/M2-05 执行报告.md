## 结果概述

已将正式 Vanilla JS SPA 的默认落点切换为独立主页工作台。主页继续位于既有 AppShell FeatureStage 内，使用全局 TopBar、208px 功能导航和 32px StatusBarHost；主页不创建目录栏或编辑器边注栏。

主页欢迎区、资料摘要和最近编辑表均来自现有 workspace 状态。真实 API 运行态显示 17 条资料、6 个文件夹和 5 条最近编辑；没有写入原型中的待办、掌握度、复习计划或同步演示数字。

工作域卡片按当前真实能力分层：资料工作台是唯一提供主页主入口的激活卡；知识、训练卡片明确标记“已接入”，引导从左侧功能导航进入；学习档案保持“依赖未就绪”门禁。最近编辑资料使用现有 `selectNote()` 链路打开编辑器，未新增平行数据源。

## 保留的正式行为契约

- API、缓存、mock 的加载优先级和 workspace 数据模型不变。
- 资料入口复用 `data-library-home` / `returnToLibraryIndex()`，最近编辑复用 `data-home-note-open` / `selectNote()`；未绕过离开保护、草稿保存和资料详情加载。
- 工作域入口继续使用 `data-module-key`、`selectWorkDomain()` 和现有知识/训练/学习档案 controller/state。
- Footer 仍是 AppShell 唯一宿主；主页仅显示当前工作台消息和全局编码/连接状态，不挂载编辑器专属 action。
- 图标继续通过语义 `renderIcon()` 映射本地 Remix SVG，不引入原型 `data-hook`、CDN 或静态演示数据。
