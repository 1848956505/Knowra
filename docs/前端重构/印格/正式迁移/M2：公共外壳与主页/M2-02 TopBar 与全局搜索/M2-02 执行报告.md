# M2-02 TopBar 与全局搜索执行报告

## 任务状态

`执行侧完成 / 待规划与验收方复审`

本报告只记录 M2-02 的执行结果，不替代正式迁移规划、契约或验收方结论。

## 结果概述

已在 M2-01 三行 AppShell 基础上完成 TopBar 内容迁移：品牌 Mark 与品牌名位于左侧，全局搜索固定在顶栏水平中心，通知/设置/用户中心以明确占位语义位于右侧。原有 `#global-search-shell` 只保留一份并迁入 SSR TopBar，搜索状态和交互仍由正式搜索 controller 与事件 binder 驱动。

## 保留的正式行为契约

- `#global-search-shell`、`#global-search`、`data-search-input` 和既有搜索 selector 保持稳定。
- 点击搜索、关键词输入、标签筛选、中文输入法组合态、Escape 关闭、Enter 选择首个结果均继续走原有 controller/event/state 链路。
- `Meta+K` 与 `Ctrl+K` 只打开现有搜索，不创建新的搜索状态或 API 路径。
- 搜索面板仍复用既有标签筛选结果；没有结果时 Enter 不会伪造选择。
- 通知、设置、用户中心按钮没有 action selector、controller 或 state，不产生假业务状态；点击占位后页面状态保持不变。
- SSR 初始脚本、API/cache/mock 加载顺序、工作域、Footer 宿主、上下文菜单和 Markdown 导入入口未改变。
