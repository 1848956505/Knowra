## 4. 浏览器运行态验收

本次使用当前工作区启动真实 API/Web，并用临时验收数据验证分页、目录继承筛选和长内容。临时数据包含 1 个长目录和 12 条资料，验收结束后已通过 API 永久清理；API 复核恢复为原始 2 条资料、0 个验收目录。

### 4.1 功能检查

- Tab 切换：PASS。`全部条目`、`最近`、`已收藏`、`回收站` 使用 `role=tab`；选中 Tab 的 `aria-selected`、`tabindex` 与 `tabpanel` 的 `aria-labelledby`、`data-index-tab` 同步。
- 真实分页：PASS。14 条资料、默认每页 10 条时进入第 2 页显示 4 条且当前页带 `aria-current="page"`；切换每页 5 条后回到第 1 页，共 3 页，页大小按钮带 `aria-pressed="true"`。
- 收藏与回收站视图：PASS。收藏视图显示 1 条临时收藏资料；回收站视图显示空结果反馈和清除操作。
- 父目录后代筛选：PASS。选择长目录后，索引范围显示 1 条资料，仅展示该目录内的后代资料。
- 长标题与长路径：PASS。长标题在列表和预览标题中使用截断承载，长目录路径在详情信息中换行；未产生页面级横向溢出。
- 打开动作：PASS。列表打开按钮可进入编辑器，返回资料索引按钮可返回索引页。编辑器内部业务不纳入 M3-02 结论。
- 空结果清除筛选：**FAIL，P1-1**。选择不存在匹配项的 `PDF 导入` 类型后，列表进入 0 条结果状态并显示清除按钮；点击“清除筛选”后，按钮仍显示 `类型 PDF 导入`，结果仍为 0 条，未恢复全部资料。该问题可由真实浏览器稳定复现，属于功能回归。

### 4.3 可访问性与结构

- Tab/tabpanel 关系：PASS。Tab 控制目标为 `#library-index-content`，面板反向标注当前 Tab。
- 打开态筛选菜单：PASS。筛选器打开时 `aria-expanded="true"`，`aria-controls` 目标存在且为 `role="menu"`，菜单项使用 `role="menuitemradio"` 和 `aria-checked`。
- 闭合态筛选器控制目标：**FAIL，P2-1**。筛选器闭合时仍保留 `aria-controls="library-index-filter-menu-{kind}"`，但对应菜单节点不存在；重新打开时目标才被渲染。该问题与 M3-01 已关闭的“保留控制目标避免 ARIA 引用断裂”规则不一致，属于未登记的可访问性偏差。

- P2：1 项。P2-1 筛选器闭合态 `aria-controls` 指向不存在的 DOM 目标。
- 偏差记录：无新增、无已批准或未批准 D-xxx；P2-1 未获批准，不适用 `CONDITIONAL PASS`。
