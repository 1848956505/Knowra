# M3-02 索引主区

## 任务状态

`执行侧完成 / 待正式验收`

## 前置条件

- M3-01 已完成目录栏宿主与树交互边界收口；本任务继续使用现有 208px 功能导航、232px 目录栏和 FeatureStage。
- M2 阶段已有资料索引的数据、事件和详情渲染入口；本任务在其上完成主区语义与窄工作区布局收口，不重复创建数据层。

## 任务范围

- 固化索引主区宿主、标题区、Tab、过滤区和结果区的稳定边界。
- 为资料 Tab 建立 `tablist`、`tab`、`tabpanel` 关系，并保持既有筛选、分页和打开资料事件。
- 目录选择支持选中目录及其后代目录中的资料，和目录导航的可见性语义一致。
- 让窄 FeatureStage 下的长标题、长路径、分页控件和空结果保持可达且不制造页面级横向溢出。

## 不在本任务范围

- 不重写资料详情栏的打开、标签、关联、大纲或附件业务；详情栏仍由现有宿主承载，M3-03 再独立验收。
- 不修改正式验收报告、正式验收记录或偏差记录。
- 不以隐藏详情功能替代主区布局收口。

## 输出

- [M3-02 执行报告](<M3-02 执行报告.md>)

正式验收结论由验收方写入正式验收记录，本目录不预先声明 `PASS`。
