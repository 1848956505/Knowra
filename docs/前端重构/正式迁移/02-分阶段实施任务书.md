# 分阶段实施任务书

每个任务由一个执行模型独立完成。执行模型只能领取一个处于“可执行”状态的任务；规划与验收方确认 PASS 后才能解锁后继任务。

## M0：契约与基线

### M0-01 规格消歧

- 输入：设计文档、三个页面原型、组件库、本目录决策记录。
- 工作：统一 208/232/300px 等冲突，确认 Tab 激活线、专注模式、Footer 显示规则。
- 产出：向规划与验收方提交规格冲突报告、建议值与视觉证据，不改正式代码和规划文档。
- 验收：设计文档、组件库、页面原型和迁移契约无相互矛盾的硬规格。

### M0-02 正式事件与状态映射

- 输入：`apps/web/src/`、`apps/web/lib/`、现有 Web 测试。
- 工作：补全每个视觉控件对应的正式 selector、controller、state 和 test。
- 产出：向规划与验收方提交完整映射报告；列出确实需要新增的 selector，不直接修改迁移契约。
- 验收：不存在依赖原型 `data-hook` 的正式任务。

### M0-03 迁移前基线证据

- 工作：启动正式 API/Web，使用真实数据捕获首页/资料索引/编辑器/知识/训练的现状截图与控制台状态。
- 视口：2048×1024、1440×1024、1280×720。
- 产出：`正式迁移/验收证据/M0/` 截图和基线报告。
- 验收：`npm run test:web` 通过，截图可复现，控制台无未解释错误。

## M1：Token 与资源

### M1-01 InkGrid Token 接入

- 允许修改：正式 Token 文件、必要的 Token 形状测试。
- 禁止修改：页面结构、控制器和 API。
- 工作：加入 `--ink-*`，建立旧变量兼容别名，补充线条、阴影、尺寸和语义色。
- 验收：没有新增硬编码视觉值；旧 UI 不破版；Token 测试通过。

### M1-02 图标本地化与映射

- 工作：确定所需 Remix 图标清单，本地化资源，建立语义名到资源路径的映射。
- 禁止：运行时 CDN、手绘替代 SVG、页面内复制图标路径。
- 验收：断网仍显示图标；装饰图标和交互图标语义正确。

### M1-03 InkGrid 样式入口

- 工作：创建按职责拆分的 `knowra-inkgrid-*` CSS 模块，并接入既有 `components.css` 聚合入口。
- 验收：导入图无循环、无缺失文件；选择器限定在迁移 Shell 标识下。

## M2：公共外壳与主页

### M2-01 AppShell 网格

- 工作：将正式 Shell 调整为 TopBar、ShellBody、StatusBarHost 三行结构。
- 保留：SSR 脚本、工作区启动、上下文菜单宿主、导入 input。
- 验收：主体滚动、Footer 高度和 z-index 正确；页面无额外滚动条。

### M2-02 TopBar 与全局搜索

- 工作：迁移品牌 Mark、居中搜索、通知/设置/用户区；复用正式搜索控制器。
- 验收：鼠标、键盘、IME、Escape 和 Enter 路径通过。

### M2-03 纯功能导航

- 工作：渲染 208px 分组功能导航，将资料目录移出全局导航。
- 验收：所有工作域可进入；当前项、占位项和设置入口语义正确。

### M2-04 StatusBarHost

- 工作：把位置与全局状态留在 Shell，把功能状态通过现有渲染入口注入。
- 验收：首页、索引、编辑器和其他工作域切换时内容正确且无重复监听器。

### M2-05 主页外壳验证

- 工作：按低保真目标迁移主页，不虚构尚未实现的待办、掌握度或同步数据。
- 验收：1 个可用资料入口，其余工作域按真实状态展示。

## M3：资料库索引

### M3-01 目录栏拆分

- 工作：将 `#folder-tree` 迁入 232px 功能目录栏，保留全部导航事件和内联编辑宿主。
- 验收：选择、增删改、拖拽、右键和折叠均通过。

### M3-02 索引主区

- 工作：迁移标题、Tab、过滤、列表、分页和空状态。
- 验收：真实筛选和分页；长标题、长路径和空结果不破版。

### M3-03 资料详情栏

- 工作：迁移 232px 详情栏并保留打开、标签、关联、大纲和附件信息。
- 验收：折叠/重开、滚动和选择同步通过。

### M3-04 索引视觉与回归

- 工作：同视口对比原型，修正可见差异；不得以隐藏功能换取视觉一致。
- 验收：M3 验收矩阵全部通过。

## M4：资料编辑器

### M4-01 编辑器网格与目录栏

- 工作：建立“目录栏｜EditorMain｜边注栏”布局，接入容器查询状态。
- 验收：四种侧栏组合和断点模式通过。

### M4-02 文档 Tab

- 工作：迁移标签视觉，保留拖拽、右键、关闭、脏点和溢出菜单。
- 验收：至少 9 个标签和长标题场景通过。

### M4-03 菜单栏与快捷工具

- 工作：迁移完整/紧凑/更多菜单，复用现有命令控制器。
- 验收：所有现有命令仍可达；工具不换行、不竖排、不被无入口隐藏。

### M4-04 文档头与编辑纸面

- 工作：迁移面包屑、状态、时间、标题、标签和 760px 阅读行宽；保留 Milkdown 宿主。
- 验收：输入、IME、撤销、粘贴、代码块、表格、图片和滚动位置通过。

### M4-05 资料边注

- 工作：迁移信息/大纲/重点/AI Tab、标签和附件区域。
- 验收：Tab、跳转、折叠、附件动作和焦点管理通过。

### M4-06 编辑器 Footer 与专注模式

- 工作：注入保存、统计、源码、边注、专注、编码和连接状态。
- 验收：保存失败、源码分栏、专注进入/退出和面板偏好恢复通过。

### M4-07 编辑器视觉与回归

- 工作：在所有视口和侧栏状态下完成同输入对比。
- 验收：M4 验收矩阵全部通过，控制台无错误。

## M5：其他工作域兼容

### M5-01 知识工作域适配

- 验收：概览、列表、检查器、编辑入口和资料回链通过。

### M5-02 训练工作域适配

- 验收：概览、题目库、题目编辑、来源与目标绑定通过。

### M5-03 学习档案门禁适配

- 验收：依赖未完成时继续展示真实门禁，不新增虚构数据。

## M6：清理与发布

### M6-01 废弃资产审计

- 工作：用引用搜索和测试证明旧选择器、旧图标和兼容 Token 可删除。
- 验收：删除清单由规划与验收方批准后才能执行。

### M6-02 文档与版本维护

- 工作：更新样式导航、架构说明、工程变更日志和三个 `package.json` 版本。
- 验收：版本号一致，文档链接有效，变更日志结构正确。

### M6-03 最终发布门禁

- 工作：运行全仓测试、多视口视觉、关键交互、可访问性和断网资源验证。
- 验收：最终报告为 PASS 后，才能建议用户创建 tag。
