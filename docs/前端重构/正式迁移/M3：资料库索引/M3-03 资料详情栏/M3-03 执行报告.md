# M3-03「资料详情栏」执行报告

- 对应任务：M3-03「资料详情栏」。
- 领取依据：M3-02 最新复验已关闭 P1-2，并允许解锁 M3-03；本报告不修改 M3-02 验收结论。

- 本次范围：在资料库索引页补齐 232px 资料详情栏的真实信息、折叠/重开、滚动、选择同步和紧凑视口行为；未扩展 API 契约，未修改正式验收记录。

## 2. 实现内容与规格差异

### 2.1 详情栏结构与内容

- 详情栏宽度改为独立使用 `--ink-index-inspector-w`，稳定为 232px，不再跟随 260px 的通用 rail 宽度漂移。
- 保留并渲染资料标题、类型、路径、字符数、更新时间、收藏状态、标签、关联资料、大纲和附件信息。
- 类型使用资料真实 `sourceType` 映射；关联资料改为可聚焦按钮，附件行保留既有打开附件事件入口。
- 详情正文单独成为纵向滚动容器，长大纲不会把折叠按钮推离可视区域。

### 2.2 折叠、重开与状态同步

- 展开态和折叠态均保留 `aria-controls`、`aria-expanded` 与可读 `aria-label`。
- 折叠态提供“展开详情”按钮；展开态提供“收起详情”按钮，按钮不再被详情滚动内容裁切。
- 索引行选择后，详情栏标题与内容跟随当前资料同步更新；关闭后可重开并保留当前资料上下文。

### 2.3 紧凑视口

- `<=1180px` 时详情栏仍保持 232px 固定宽度，并改为工作区右侧覆盖层，避免三栏最小宽度造成页面横向溢出。
- `>1180px` 继续使用索引主区、目录栏和详情栏的并列结构。
- 该覆盖层仅是响应式布局适配，未改变详情栏宽度、内容契约或折叠行为。

## 4. 保留的行为契约

- 详情栏继续由索引页当前选中资料驱动，不新增第二份资料选择状态。
- 目录/索引行的既有打开资料事件、标签筛选、分页和 M3-02 Tab 语义保持不变。
- 关联资料和附件动作通过现有索引事件委托进入 controller/service 边界；没有在渲染器中引入 API 请求。
- 真实资料没有附件时不伪造附件项；附件信息仅使用当前侧数据或资料对象已有数组。
