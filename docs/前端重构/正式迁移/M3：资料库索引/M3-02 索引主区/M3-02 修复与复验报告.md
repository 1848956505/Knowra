### P2-1 闭合筛选器控制目标不存在

- 为类型、状态、时间筛选器建立稳定的 `library-index-filter-menu-{kind}` 菜单 `id`。

- 菜单闭合时保留 DOM 节点并使用 `hidden`，打开时恢复可见；避免 ARIA 引用断裂。

## 5. 本轮继续修复：P2-2 / P2-3

### P2-2 Tab/tabpanel 语义缺失

- 索引 Tab 宿主固定为 `role="tablist"`。
- 每个资料范围 Tab 增加稳定 `id`、`role="tab"`、动态 `aria-selected`、`aria-controls="library-index-content"` 和 roving `tabindex`。
- 索引内容宿主固定为 `role="tabpanel"`，并在 Tab 切换后动态同步 `aria-labelledby`，保留键盘可聚焦的 `tabindex="0"`。

### P2-3 分页选中状态缺少 ARIA 状态

- 当前页按钮在渲染时增加 `aria-current="page"`，非当前页不输出该属性。
- 每页数量按钮增加 `aria-pressed="true|false"` 及对应 `aria-label`，保留原有 `data-active` 视觉状态钩子。
- 为 Tab、tabpanel、当前页和每页数量状态补充 Web 回归断言。
