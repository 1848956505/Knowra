# M1-03 InkGrid 样式入口执行报告

## 任务状态

`执行侧完成 / 待规划与验收方复审`

本报告只记录 M1-03 的执行结果，不替代正式迁移规划与验收方的结论。

## 结果概述

- 新增 `knowra-inkgrid.css` 正式聚合入口，并由既有 `apps/web/styles/components.css` 直接加载。
- 将 InkGrid 视觉层按职责拆分为 Shell、资料索引、编辑器、菜单和排版五个 `knowra-inkgrid-*` 模块。
- 新模块的规则统一限定在 `.knowra-production-shell` 下；Shell 的 `body` 基础规则使用 `body:has(.knowra-production-shell)`，只在正式迁移 Shell 存在时生效。
- 旧 `knowra-redesign.css` 与旧职责文件保留为单行兼容代理，直接引用方无需同时迁移；正式主入口不会重复加载旧代理。
- 根据退回意见复修了 1180px 以下的响应式变量作用域：`--rail-width`、`--aside-width` 和 `--index-inspector-width` 现在声明在 `.knowra-production-shell` 自身，确保 Shell 及其后代实际继承紧凑宽度。
- 未修改页面结构、控制器、状态语义、API、事件 selector、Milkdown 宿主或图标资源。

## 保留的行为契约

- `src/styles.css`、`components.css` 仍是主应用样式入口，未新增前端子项目。
- 既有 DOM class、`data-*` 事件属性、controller 查询、状态语义、API envelope 和编辑器行为均未改变。
- 旧样式路径继续可直接导入，但不再作为主聚合入口，避免同一套规则重复输出。
- Token 仍只由 `knowra-theme-tokens.css` 提供，职责模块没有新增视觉字面量。

## 与目标视觉的已知差异

M1-03 只重构样式入口与作用域，不执行 M2 的 Shell 网格结构迁移。运行态继续保留当前 `260px 1020px` 复合 Shell 网格；文档 Tab 左侧蓝线、边注 Tab 下方黑线等既有冻结规则保持不变。

1180px 以下的宽度 Token 已在正式 Shell 自身生效；1024×768 的 `240px` 计算值与无横向滚动已通过浏览器运行态复验。<=1040px 下编辑器与左侧资料导航的排列仍沿用 M0-03 既有基线，不在本任务中调整布局结构。
