## 交互核对

| 路径 | 结果 | 证据/说明 |
| --- | --- | --- |
| 鼠标点击搜索 | PASS | 搜索面板打开，`data-open=true`，`#global-search` 获得焦点。 |
| `⌘K` / `Ctrl+K` | PASS | 捕获阶段打开现有搜索并调用现有 `focusSearchInput()`；专项行为测试覆盖两种修饰键。 |
| Escape | PASS | 面板关闭，`data-open=false`，焦点仍在 `#global-search`。 |
| 中文输入法组合态 | PASS | 既有 `isComposingEvent()` 路径保留；`events/search-events.test.js` 验证组合态 Enter 不选择结果，document 键盘测试验证组合事件不被全局快捷键劫持。 |
| 关键词输入 | PASS | 输入“知识点”后沿用既有 `state.search.keyword` 和筛选渲染。 |
| Enter | PASS | 有结果时选择首个资料并进入 editor screen；无结果路径仍不选择。 |
| 通知/设置/用户占位 | PASS | 点击设置前后仍为 index、搜索保持关闭，没有伪造业务状态。 |
