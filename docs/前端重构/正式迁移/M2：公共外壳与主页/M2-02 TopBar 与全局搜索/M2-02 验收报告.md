## 5. P1 缺陷

### P1-1：关闭搜索后，活动关键词使面板继续覆盖编辑器

- 复现步骤：在资料索引打开全局搜索 → 输入“知识点” → 按 Enter → 进入编辑器 → 观察 TopBar 下方。
- 实际结果：页面已切换到 `data-screen="editor"`，但 `#global-search-shell[data-open="false"]` 内的 `.search-panel` 仍实际可见；随后按 Escape 仍然可见。
- 期望结果：Enter 选择资料并切换工作域后，搜索面板应关闭；Escape 应能关闭搜索面板，同时保留可见的关键词/chip 状态或仅保留输入框，不应遮挡编辑器。
- 影响：主编辑路径被搜索面板遮挡，Escape 键盘关闭门禁失效，属于功能回归/主路径遮挡，按 `03-验收与回归方案.md` 归为 P1。
- 代码线索：`apps/web/src/controllers/search-controller.js:195-197` 使用 `state.search.isOpen || hasFilters` 重新渲染面板；Enter/Escape 只将 `state.search.isOpen` 设为 `false`，活动关键词仍使面板重新生成。
- 证据：[Enter 截图](<浏览器证据/M2-02-acceptance-07-enter-editor-1440x1024.png>)、[Escape 截图](<浏览器证据/M2-02-acceptance-08-escape-after-enter-regression-1440x1024.png>)。
