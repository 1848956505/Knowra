# M2-01 AppShell 网格修复与复验报告

## 任务状态

`修复完成 / 待验收方复验`

本报告对应[M2-01 验收报告.md](<M2-01 验收报告.md>)中的 P1-1 及补充验收指出的编辑器宽度 P1，不修改原验收报告的历史结论。

## 验收问题（P1-1）

验收报告指出，1024×768 最小支持视口下 ShellBody 子项顺序与宽度错误：

- `apps/web/styles/components/responsive.css:93-94` 在 `max-width: 1040px` 下设置 `.kb-sidebar { order: 2; }`（旧 flex 单列布局规则）。
- M2-01 将 ShellBody 改为两列 CSS Grid 后，`order` 同样作用于 Grid 子项，导致 `#kb-sidebar` 被排到第二列、FeatureStage 落到第一列仅 240px 宽，右侧留下大块空白。
- 该问题在资料索引、编辑器和知识域页面均可复现，属主布局破坏（P1）。

## 追加验收问题（编辑器宽度 P1）

补充验收报告指出，1024×768 下 ShellBody 可用宽度约为 784px，但编辑器内部仍按 `700px + 240px = 940px` 计算：

- `knowra-inkgrid-editor.css` 中更高特异性的 canonical `.kb-workspace` 网格规则覆盖了 `responsive.css` 的紧凑布局规则。
- 编辑区从约 `x=940` 开始，正文、活动 Tab 和大部分编辑控件被裁出视口，违反“控件可达、活动标签可见”的验收要求。

## 修复内容

- `apps/web/styles/components/knowra-inkgrid-shell.css`
  - 新增 `.knowra-production-shell .shell-body .kb-sidebar { order: 0; }`，在 ShellBody Grid 语境下显式覆盖旧响应式 `order: 2`。
  - 选择器特异性（0,3,0）高于 `responsive.css` 的 `.kb-sidebar`（0,1,0），不依赖加载顺序即可生效。
  - 未改动 DOM 结构、事件属性、控制器、状态或 API。
- `apps/web/test/app-shell-grid.test.js`
  - 新增 P1-1 回归断言组：
    - 断言 `responsive.css` 仍携带 `max-width: 1040px` 下的 `.kb-sidebar { order: 2 }` 触发规则（问题场景锚点）。
    - 断言 ShellBody Grid 语境下存在 `order: 0` 覆盖规则。
    - 断言 SSR DOM 顺序中 `#kb-sidebar` 位于 FeatureStage 之前（Grid 默认按 DOM 顺序放置，order 归零后导航必然在第一列）。
    - 断言资料索引、编辑器、知识域三种工作域容器仍由 FeatureStage 承载。
- `apps/web/styles/components/knowra-inkgrid-editor.css`
  - 在 `max-width: 1040px` 下为 canonical `.kb-workspace` 增加单列覆盖规则，使 784px 的 FeatureStage 不再强行容纳编辑内容最小宽度与 240px 边栏。
  - 同一断点下将源码编辑区收敛为单列，避免紧凑视口继续产生内部双列溢出。
  - 保留 1040px 以上视口的原有 `minmax(var(--editor-content-min-width), 1fr) var(--aside-width)` 布局。
- `apps/web/test/app-shell-grid.test.js`
  - 增加编辑器 canonical 规则的断言，并修正此前被连续注释吞掉的追加断言，确保该 P1 场景实际参与回归测试。

## 复验边界

- 本报告提供 1024×768 ShellBody 顺序与编辑器单列布局的静态回归断言（P1 修复的静态证据）；运行态浏览器截图与其余视口复核仍由验收方按 `03-验收与回归方案.md` 执行。
- 已知风险（供验收方评估）：`responsive.css` 在 `max-width: 1040px` 下对 `.workspace-shell` 设置的 `height: 100vh` 与 `.knowra-production-shell` 的 `height: 100%` 特异性相同，当前依赖 `components.css` 中 `knowra-inkgrid.css` 晚于 `responsive.css` 加载取胜；实测 1024×768 无滚动条异常。M1-03 契约要求 InkGrid 模块选择器以 `.knowra-production-shell` 开头，未通过加前缀方式提升特异性，避免破坏该契约；如需消除该依赖，建议在 M6 清理阶段统一收敛旧 `responsive.css` 规则。
