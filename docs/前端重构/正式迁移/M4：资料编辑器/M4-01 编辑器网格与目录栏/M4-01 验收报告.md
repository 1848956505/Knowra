### 发现的问题

#### P1-1：同一侧栏组合会因切换历史得到不同布局模式

在 1280×720 下，最终状态均为 `showLeft=true / showRight=false` 时：

- 从“双侧栏”关闭右侧边注栏，结果为 `Protected`，目录栏 relative 停靠，EditorMain 为 x=440、w=840；
- 从“无侧栏”打开左侧目录栏，结果为 `Overlay`，目录栏 absolute 覆盖，EditorMain 为 x=208、w=1072。

同一状态不应依赖此前的 `data-editor-layout`。该结果违反“按 EditorMain 容器宽度决定断点模式”的契约，也会使“仅目录栏”组合无法稳定保持 Protected 布局。

#### P1-2：Overlay 下左侧目录覆盖编辑器视图菜单，鼠标无法关闭目录栏

1280×720 双侧栏 Overlay 时，目录栏覆盖 x=208–440 区域；编辑器“视图”按钮位于该覆盖层下方，中心点命中的是目录栏的“显示导航入口菜单”控件。编辑器内 `[data-index-directory-toggle]` 在非索引页被隐藏，也没有可见的编辑器目录栏关闭/重开入口。因此用户无法通过可见鼠标路径关闭 Overlay 目录栏，侧栏组合的核心恢复路径被遮挡。

#### P2-1：边注栏折叠缺少 ARIA 状态和焦点恢复

真实点击 `[data-editor-aside-toggle]` 折叠边注栏后，焦点落到 `BODY`，未返回可见的 `#editor-aside-reopen`；重开后同样未恢复到触发器。折叠按钮只有 `aria-label="收起资料边注"`，缺少 `aria-expanded` / `aria-controls`；重开按钮文本为“侧栏”，缺少 `aria-label`、`aria-expanded` 和 `aria-controls`。这不满足侧栏折叠语义及 Overlay 关闭后的焦点恢复要求。
