## 任务范围

依据 M4-03 任务书、迁移契约和 InkGrid 编辑器原型，将正式编辑器菜单栏迁移为 Full、Compact、Protected、Overlay 四档呈现，并为紧凑宽度提供键盘可达的“更多”入口。所有命令继续复用现有文件、编辑、段落、格式和视图 command controller，不新增平行事件链路。

## 主要实现

- `menu-renderers.js` 为菜单组增加稳定的 `data-editor-menu-group` 标识，并新增 `更多` 菜单触发器；“更多”复用现有 `data-file-menu-action`、`data-edit-menu-action`、`data-paragraph-menu-action`、`data-format-menu-action` 和 `data-view-menu-action`，一次性提供 43 个正式命令入口。
- 文件、编辑、段落、格式、视图菜单补齐 `role="menu"`、`role="menuitem"`、`aria-haspopup`、`aria-expanded` 和 `aria-controls`；快捷工具保留正式 `data-format` 事件属性，并增加 `data-quick-action` 供响应式收纳使用。
- Full 模式保留五组完整文字菜单和全部快捷工具；Compact 模式保留文件/编辑/视图，将段落/格式及列表、引用、行内代码快捷工具迁入“更多”；Protected 模式保留文件/视图与少量高频工具；Overlay 模式保留文件与“更多”，所有低频命令仍可从滚动菜单访问。
- `knowra-inkgrid-editor.css` 使用 `data-editor-layout` 作为基于真实 EditorMain 宽度的权威可见性层，保留现有 `@container editor-main` 间距规则；菜单行固定单行、禁止中文竖排，不以 `overflow:hidden` 静默丢失命令。
- “更多”弹层在窄宽度下以左侧对齐、在有余量的模式下以右侧对齐，并限制在视口内；弹层内容采用纵向滚动，命令不会因为菜单高度不足而失去入口。
- Protected 模式将菜单行置于边注覆盖层之上，并将边注内容起点移到菜单行之后，确保“更多”按钮与弹层均可通过鼠标命中。
- `shell-controller.js` 在布局模式切换时同步已打开菜单：被隐藏的完整菜单自动迁移到“更多”，Full 模式关闭不可见的“更多”，避免窗口缩放后焦点或命令落入不可见 DOM。

## 命令可达性

- Full 五组菜单逐组打开并读取正式动作属性：文件 10、段落 12、编辑 8、格式 7、视图 6。
- Compact、Protected、Overlay 的“更多”菜单均读取到 43 个动作属性，覆盖文件、编辑、段落、格式、视图五类命令。
- “更多”触发器使用既有 `[data-editor-menu-toggle]` 事件分发，不增加新的 command controller 或绕过正式 state 的事件入口。
- 所有按钮保持原生 `button`，菜单弹层可滚动但不隐藏未迁移命令；快捷工具与菜单均保持单行布局。
