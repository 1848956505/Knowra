## 任务范围

依据 M4-02 任务书，将正式 Vanilla JS 编辑器的文档 Tab 视觉与交互契约接入 InkGrid 工作面，同时保留既有 Tab 的选择、关闭、右键菜单、拖拽排序、未保存状态和溢出菜单行为。

## 主要实现

- `tab-renderers.js` 将文档 Tab 拆为可拖拽的外层 Tab 容器、原生 `button[role="tab"]` 选择控件和独立关闭按钮；保留正式 `data-tab-note-id`、拖拽/落点状态和路径提示。
- 补充 `aria-selected`、`aria-controls`、未保存修改文案、文件类型本地图标和关闭按钮 `aria-label`，长标题通过 `text-overflow: ellipsis` 截断。
- `shell-html.js` 为文档 Tab 宿主补齐 `role="tablist"`，为编辑内容区补齐 `role="tabpanel"` 与键盘可聚焦语义。
- `knowra-inkgrid-editor.css` 使用正式 Token 约束 Tab 最小/最大宽度、标签行收缩、溢出按钮、焦点轮廓、脏状态方点、关闭按钮和右键菜单样式；Tab 宿主保留纵向溢出菜单绘制空间。
- 修复 Grid 子项按内容最小宽度撑开的问题，并让 Protected/Overlay 模式的边注从文档 Tab 行下方开始，避免遮挡溢出按钮和菜单命中层。
- 新增 M4-02 结构/渲染回归测试，覆盖 9 Tab 分组、当前 Tab 保持可见、长标题、脏状态、拖拽状态、本地图标、Tab/tabpanel 语义和 InkGrid CSS 契约。
