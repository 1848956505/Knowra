## A-026 修复内容

### P1-1：溢出菜单切换隐藏标签

- `shell-html.js` 为溢出按钮与菜单增加独立宿主，`#note-tabs` 只承载文档 Tab，菜单明确使用 `role="menu"`。
- `note-tab-events.js` 为独立宿主补充点击绑定；隐藏项使用 `role="menuitemradio"`，点击后复用正式 Tab 选择链路，确保隐藏资料先加入可见 Tab 再完成切换。
- `knowra-inkgrid-editor.css` 提升文档 Tab 层级，并在溢出菜单打开时暂时关闭边注覆盖层的指针命中，避免菜单区域被编辑菜单栏或边注栏拦截。
- 选择完成后关闭菜单、同步 `aria-expanded`/`data-open`，并将焦点交接到新活动 Tab。

### P1-2：未保存修改 Tab 脏点

- `draft-controller.js` 在进入 `pending` 状态的同一调用栈立即重绘 Tab；`pending`、`saving`、`error` 均显示脏点。
- 活动 Tab 同步 `data-dirty="true"`、脏点字符和“有未保存修改”可访问名称后缀；保存完成后恢复干净状态。

### P2-1：Tab/tabpanel 语义与焦点

- `tab-renderers.js` 为每个可见 Tab 生成稳定唯一 `id`，补齐 `role="tab"`、`aria-selected`、`aria-controls` 和 roving `tabindex`；外层拖拽容器标记为 presentation。
- `tab-controller.js` 在重绘后以活动 Tab ID 回链 `#editor-scroll-region[role="tabpanel"]` 的 `aria-labelledby`。
- `note-tab-events.js` 增加 ArrowLeft/Right、ArrowUp/Down、Home、End 导航；可见 Tab、隐藏 Tab、关闭相邻 Tab 后均恢复活动控件焦点。
- `overflow-controller.js` 适配独立宿主，关闭菜单时同步按钮的 `aria-expanded` 与 `data-open`。
