## 2. 修复内容

### M4-05-P1-1 标签编辑重绘后焦点丢失

1. 展开“添加标签”后，焦点进入 `data-note-tag-input`。
2. 收起标签编辑器后，焦点返回 `data-note-tag-toggle`。
3. 添加、移除、创建或匹配已有标签后，展开态恢复标签输入焦点；闭合态恢复“添加标签”触发器。
4. 标签输入导致的重绘使用统一的边注焦点请求，并将光标恢复到草稿末尾，不再从全局 `document` 查找节点。

### M4-05-P1-2 附件重命名取消/提交后焦点丢失

1. 进入重命名态后，聚焦并选中文件名主体。
2. Escape、取消按钮和成功提交后，焦点返回对应附件的 `data-attachment-open` 按钮。
3. 焦点恢复前自动展开目标所属的附件 `<details>`，确保焦点目标可见、可交互。
4. 恢复动作在当前点击/提交事件结束后执行，并以边注渲染序号丢弃过期请求，避免新界面被旧焦点请求覆盖。
