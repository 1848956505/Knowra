# 印格五库融合 · 主页与编辑器 Demo

一个独立、可交互的视觉原型：以知境官方设计语言「印格 InkGrid」（新粗野主义）为基底，融合 5 个开源笔记 UI 库的交互范式与结构，目标是 **优雅但有辨识度** 的主页 + 编辑器。

## 查看方式

直接用浏览器打开 `index.html`，或在仓库根目录启动静态服务器：

```bash
python3 -m http.server 4175 -d "docs/前端重构/印格五库融合"
```

访问 `http://127.0.0.1:4175/`。

> 页面零外部依赖：无 CDN、无图标包、无字体加载，纯 HTML + CSS + JS。离线可用。

## 五库贡献映射

| 库 | 借鉴的元素 | 本 Demo 中的落点 |
|----|-----------|-----------------|
| **Novel** | Slash 命令面板、选区气泡菜单、块拖拽手柄、"已保存"状态胶囊 | 编辑器斜杠命令菜单、选中文本气泡工具栏、每块左侧 `+`/`⠿` 手柄、顶栏保存状态 |
| **Shadcn/ui** | 语义化 CSS 变量、Sidebar、Command(cmdk) 全局命令面板、Card/Badge | `--ink-*` token 体系（含暗色）、功能栏/目录栏、`⌘K` 命令面板、标签 Badge |
| **Outline** | 文档树 DocumentTree、面包屑导航、阅读排版、反向链接 | 目录栏文档树（可折叠、emoji 图标）、编辑器面包屑、居中窄阅读列、边注栏反向链接 |
| **Aceternity / Magic UI** | Bento Grid、Spotlight、Aurora、Typing 动画 | 主页 Bento 网格仪表盘、Hero 聚光灯、回响卡极光底、写作卡打字占位 |
| **BlockNote** | 块级编辑器侧边悬浮菜单、块拖拽动画 | 每块的 `+` 插入与 `⠿` 拖拽手柄（HTML5 drag 排序） |

## 设计融合策略

「印格」的拳头只打在外壳：顶栏/功能栏/卡片用 **2px 墨黑边框 + 硬影 + 零圆角**；工作面的编辑纸面保持 **安静 Tier D**（白底无边框，最大行宽 760px，行高 1.85），让内容呼吸——这正是设计文档 §1.1「框架有力，内容安静」的强度分级，也是"优雅"的来源；辨识度则来自暖白纸底 + 点阵 + 黑框内的蓝色强调。

魔法元素（聚光灯/极光/打字）只出现在主页 Hero 与回响卡，克制使用，全部收进印格的硬边框内。

## 已实现的交互

- 主页 ↔ 编辑器 单页切换；点击最近卡片/文档表行进入编辑器
- `⌘/Ctrl + K` 全局命令面板（搜索过滤 + 方向键导航 + Enter 打开）
- 编辑区输入 `/` 唤起 Slash 命令面板，插入正文/标题/待办/引用/图片/代码/AI 续写
- 选中文本弹出气泡格式工具栏（B/I/U/引用/链接/高亮）
- 每块左侧 `+` 插入手柄与 `⠿` 拖拽手柄（可拖动排序）
- 待办复选框切换与计数；目录树展开/折叠；目录栏与边注栏独立折叠
- 编辑输入自动保存状态（保存中… → 已保存）；暗色模式切换（`--ink-*` 暗色 token）
- 底部 Shell Footer 随视图切换状态：主页显示本地同步/统计，编辑器显示保存状态/字数/视图开关

## 设计边界

- 前端重构阶段的独立原型，不改动 `apps/web` 正式 SPA。
- 编辑能力用浏览器原生 `contenteditable` + `execCommand` 模拟；正式接入应映射到 Milkdown/Tiptap 的 schema、command 与持久化协议。
- 图标为页面内联 SVG（Remix 风格），不依赖图标包。
