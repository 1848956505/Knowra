# 知境 · 柔光（五库统一版）主页与编辑器 Demo

以 5 个开源笔记 UI 库融合出的**一套统一艺术风格**「柔光 Soft Light」为基底的独立视觉原型。本版**不使用印格新粗野主义**，完全采用五库的设计语言。

## 查看方式

用浏览器打开 `index.html`，或在仓库根目录：

```bash
python3 -m http.server 4176 -d "docs/前端重构/五库融合-柔光"
```

访问 `http://127.0.0.1:4176/`。零外部依赖，离线可用。

## 统一风格：柔光 Soft Light

五库归于一套语言——**纸感 + 玻璃 + 单强调色 + 克制的光**：

| 维度 | 取值 | 来源 |
|------|------|------|
| 纸感底色 | 暖中性 `#FAFAF9` / `#F6F5F3` 侧栏，干净无点阵 | Notion / Novel / Outline |
| 玻璃浮层 | Slash、气泡、命令面板 `backdrop-blur` 半透明 | Novel / BlockNote 签名 |
| 单强调色 | 靛蓝 `#4F46E5`（唯一主色）；琥珀仅作高亮标记；绿=成功 | Shadcn 语义 token |
| 圆角与软影 | 卡片 14px / 控件 10px / 标签 pill；分层柔和阴影 | Shadcn / BlockNote |
| 克制的光 | Hero 聚光灯、Bento 渐变卡盖、回响卡极光（仅点缀 1–2 处） | Aceternity / Magic UI |
| 信息架构 | 文档树收进单侧栏 + 阅读列 + 右检查器；无功能栏/底部状态栏 | Outline / Novel |
| 块编辑 | 斜杠命令、气泡工具栏、块 `+`/`⠿` 拖拽、Callout/待办/引用 | BlockNote + Novel |

## 已实现的交互

- 主页 ↔ 编辑器单页切换；点击文档卡/树/命令进入编辑器
- `⌘/Ctrl + K` 全局命令面板（搜索过滤 + 方向键 + Enter）
- 编辑区输入 `/` 唤起 Slash 命令面板（鼠标/键盘均可用），插入正文/标题/待办/引用/图片/代码/AI
- 选中文本弹出气泡工具栏（B/I/U/引用/双向链接/高亮标记）
- 每块 `+` 插入与 `⠿` 拖拽排序；待办复选框切换与计数
- 文档树展开/折叠；侧栏与右检查器独立折叠；专注模式隐藏外壳
- 编辑自动保存状态（保存中… → 已保存）；明暗主题切换

## 设计边界

- 前端重构阶段独立原型，不改动 `apps/web` 正式 SPA。
- 编辑用浏览器原生 `contenteditable` 模拟；正式接入映射到 Milkdown/Tiptap schema。
- 图标为内联 SVG（Remix 风格），不依赖图标包。
