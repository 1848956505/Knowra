# 阶段 4 与阶段 5：完整同步与发布验收

> 2026-09-10：阶段 0–5 的工程实现与本机验收已完成。基于 f59185a 工作区，修改尚未提交；未部署生产、未生成或签名 Mac 安装包。本文替代阶段 2/3 文档中的传输范围限制，不代表生产环境或所有操作系统已经验收。

## 当前行为

- 目录、标签分组、标签、笔记、附件、正文版本、重点标注及修订按关联事务同步。附件先传输并校验 SHA-256，再发布引用；另一设备按哈希校验下载。
- 离线重点创建、取消、恢复与正文修改同步保留来源关系。来源失效时知识证据降级为待检查或不足，不删除已经确认的知识。
- 冻结请求、设备序号和幂等回执防止丢响应重复提交。关联组发生冲突时保留共同基线、本机、云端及恢复记录；其他独立笔记继续同步。解决冲突不会回退其他已经确认的修改。
- 两种驱动均将业务、副作用、修订、变更日志与回执原子提交。网页的条件更新参与同一修订链。
- 状态面板提供连接、暂停、重试、冲突处理、恢复记录导出及完整本机备份。凭据只存于内存；本地库绑定服务地址和 owner。

## 协议与运行边界

基础状态接口仍兼容协议 1，通过 `atomic-entities-v2` 能力协商完整批次协议 2；实体 schema 为 5，本地 SQLite schema 为 3。旧库升级前备份，未来 schema 拒绝写入并提供独立救援导出。

单附件上限 6 MiB；完整事务批次最多 1,000 个实体、12 MiB。变更组保留上限 512 组或 16 MiB；固定快照最多 8 个、24 小时过期，并支持主动释放。完整协议回执上限 512 条或 16 MiB，裁剪后设备序号仍阻止旧请求重放；旧协议回执沿用其兼容策略。游标过期重新引导，保留本地未确认内容。

附件目前整文件重试，未实现分块续传。知识和训练资产不是本轮新增离线编辑范围；本轮处理的是资料同步及其来源副作用。

## 启动、灰度与恢复

云端须升级到本轮代码；PostgreSQL 先执行 `npm run prisma:migrate:deploy`。使用独立本地资料目录：

```bash
npm run build:web
npm run start:desktop -- --data-dir /absolute/path/to/local-library
```

在本机页面连接云端。公网要求 HTTPS，回环测试允许 HTTP。云端 `KNOWRA_SYNC_PUSH_ENABLED=false` 暂停接收提交；`KNOWRA_SYNC_ALLOWED_DEVICE_IDS` 可填逗号分隔的设备 ID 做灰度准入。暂停或拒绝提交不影响本地保存。

在同步面板生成完整本机备份后，保留界面返回的目录。停止运行服务，恢复到尚不存在的新资料目录：

```bash
npm run start:desktop -- --data-dir /absolute/path/to/new-library --restore-from /absolute/path/to/backup
```

无法启动新版库时，先关闭服务，执行不依赖应用 schema 的只读救援导出：

```bash
node scripts/export-local-recovery.mjs --data-dir /absolute/path/to/local-library --output-dir /absolute/path/to/new-recovery
```

导出包含 SQLite、可读取的实体与队列、附件和校验清单。不要用旧程序强行写新版库。云端恢复旧备份后按照阶段 2/3 文档执行 `scripts/reset-sync-epoch.mjs`，重建同步世代后再开放提交。

## 验收证据与实际范围

验收证据仅保存在本机，不随公开源码仓库发布。最终检查记录及截图位于 [验收证据](验收证据/阶段4与阶段5/验证记录.json)，性能原始数据见 [容量测量](验收证据/阶段4与阶段5/容量测量.json)。测试环境为 macOS / Apple M5，本机 Node 26 及独立缓存的 Node 24.21.0，真实 PostgreSQL 17.11 和 local-json，浏览器使用 Chromium 回环连接。CI 已补入 Node 24、PostgreSQL 17 和页面测试配置，尚未在远程 CI 执行。

容量测量为 100 / 1,000 / 10,000 篇短笔记，每档连续保存 20 次。1,000 篇本地保存 p95：JSON 11.23 ms、PostgreSQL 10.14 ms；10,000 篇：125.96 ms、126.60 ms，分别通过 100 / 250 ms 门槛。10,000 篇首次下载约 4.05 / 15.64 秒，增量约 3.11 / 3.60 秒。附件测量覆盖 100 KiB、1 MiB、5 MiB 并读回校验。
