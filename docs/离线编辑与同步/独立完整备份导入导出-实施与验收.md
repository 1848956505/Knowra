# 独立完整备份导入导出：实施与验收

本批基于 `1f23c09a6918c5483a7ebf61c6d455408e6770b8` 的当前源码，新增桌面完整备份目录的独立导出与导入。默认备份仍在本机资料目录中；用户可自行保存独立目录或介质副本。导入只加入内部备份列表，继续沿用检查、勾选和明确确认整库恢复，不自动切换资料。SQLite schema 保持 7，不发版或打 tag。

## 实现边界

- V4 复用现有 Button、Dialog、Select 和 Checkbox。页面只向原生桥传动作、当前 datasetId 和备份 ID；浏览器显示暂不支持目录传输。目录选择和在途 IPC 注册到现有桌面任务集合，正常退出保存与整库恢复屏障都会等待结果。
- Shell 验证受信主 frame、来源、当前页面资料集及退出状态；原生选择器取得路径后记录目录 dev/ino。选择前后、私有回执后再次检查资料集和关闭状态，并拒绝并行目录操作。
- Runtime 的目录传输仅由程序装配的私有 RPC 调用，恢复或关闭期间拒绝；HTTP 不接收任意目录。复制是同步有限流程，不能与本运行时的恢复切换交错。
- 原目录及祖先、文件 FD、dev/ino、大小、mtime、nlink 和前后完整树检查防止链接与替换；只复制清单支持文件。拒绝资料目录及其父目录、符号链接、硬链接、特殊文件、traversal 和已有目标。
- 隐藏 staging 复制后检查，最终目录和文件独占创建，打开后、资料写入前复检 FD、owned 祖先及实际路径绑定，清单最后写入并再次检查；不使用可替换已有空目录的 rename，也不依赖硬链接提交。没有跨平台整目录原子性承诺。清理逐项确认本次 ownership；写入前绑定失败只条件清理仍属本次的新建空文件，替换目录的整树清理仍放弃，报告中断并保留现场。
- 完整检查验证声明的逐项大小和每份正文、知识与归档草稿；兼容实际旧草稿及旧 CLI 清单缺少 `size`。旧 WAL 救援 SQLite 经哈希绑定复制到私有 TMP 后检查，原目录不生成 sidecar。CLI 原始损坏字节救援出口保留。
