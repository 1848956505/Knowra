# 桌面同步省电改造与验收

日期：2026-09-30。范围：桌面本地运行时与 V4 桌面同步控件；不改变云端协议、数据库 schema 或真实资料。

## 交付行为

- 本地成功提交可同步修改后，500ms 防抖触发上传，连续保存最多等待 2 秒。运行中产生的修改合并为后继轮次，单轮达到上传上限后继续处理。
- 完成一轮后安排下一次检查，连续空闲间隔为 15、30、60 秒。聚焦、恢复可见和联网通过本地 `/api/local-runtime/sync/wake` 合并唤醒，不清除阻塞记录。
- 自动入口遵守退避与 `Retry-After`，一次网络恢复允许额外探测；认证/协议错误停止自动重试，手动暂停停止云端调度。立即同步仍保留 `/retry`。
- 空拉取复用实体基线及差异缓存；有本地新修改时仍进行版本别名规范化、引用校验和冲突计算。校验失败的游标不能推进。
- 元数据事务只接收数据库，避免业务集合复制和校验。同值元数据不写入，常规基线按差异写入。事务成功后才更新缓存版本；失败修改不污染缓存快照。
- `generation` 只随同步实际改变本地资料而递增，包括附件修复。`lastSyncedAt` 表示成功收敛/完成资料任务，`lastCheckedAt` 仅驻内存，表示本次运行最近一次成功检查。
- 同步面板打开或有任务时每 2 秒查询；正常空闲每 10 秒；隐藏时停止。查询串行，旧版本响应不回退已接受版本。没有资料变化不重载工作区，草稿保护拒绝刷新时继续重试。

## 同机 10 分钟对照

环境：Apple M5、macOS arm64、Node v26.4.0。改造前源码基点为 `99b55f7`，对照为本次工作区改动。独立 SQLite 测试库包含 3,600 篇笔记、3,600 个历史版本和 1 个空间，共 7,201 条同步基线。正文使用固定合成内容，均在预热后计量。

两组都关闭自动调度，用相同驱动每轮完成后等待 15 秒再同步，每次查询完成后等待 2 秒再查询状态。因此本对照验证每轮工作量的下降，未把新的 60 秒退避和 10 秒界面查询计入收益。

| 指标 | 改造前 | 改造后 |
| --- | ---: | ---: |
| 测量时长 | 600.006 秒 | 600.002 秒 |
| 进程累计 CPU 时间 | 235.164 秒 | 0.545 秒 |
| 同步轮次 | 29 | 39 |
| 状态查询次数 | 207 | 299 |
| 模拟云端请求数 | 116 | 156 |
| SQLite 行变更数 | 836,273 | 0 |
| 资料 generation 增量 | 58 | 0 |
| 采样 RSS 峰值 | 884.14 MiB | 349.66 MiB |

CPU 时间下降约 **99.77%**，达到至少 80% 的目标。改造前同步会阻塞事件循环，所以同样的等待策略实际完成轮次更少。改造后采样 RSS 未呈持续增长，初次采样约 349.66 MiB，末次约 24.92 MiB；RSS 受系统回收影响，不能当作固定内存承诺。

边界：云端响应为进程内模拟，以上数据只度量本机同步运行时，不包含真实网络或 Electron 界面。不能换算为电池电量百分比。`resourceUsage.fsWrite` 在两组均为 0，未用于判断磁盘写入；表中的写入指标来自 SQLite `total_changes()`。

复现命令（仓库根目录，每次自动创建并清理独立测试目录）：

```sh
KNOWRA_IDLE_OUTPUT=/tmp/knowra-idle.json node apps/desktop-runtime/test/sync-idle-benchmark.mjs
```

可用 `KNOWRA_IDLE_NOTES` 调整规模，`KNOWRA_IDLE_DURATION_MS` 调整时长，`KNOWRA_IDLE_CYCLE_MS` / `KNOWRA_IDLE_POLL_MS` 调整驱动间隔。复现旧版本应在独立源码副本中放入同一基准脚本，不能用真实数据库运行。

## 回归记录

- `npm run test:desktop`：103 项通过，4 项真实 PostgreSQL 测试因未配置测试数据库跳过。
- 大基线专项：7,201 与 14,401 条基线，预热后各执行 20 轮同步和 200 次查询；对业务集合迭代和全基线读取设置断言，结果均为零扫描、零行写入、零资料刷新版本变化。
- 覆盖空页、重复实体、仅修订变化、冲突空页、本地后续编辑、无效依赖游标保护、事务回滚缓存、差异确认及并发编辑；附件缺失后在空页中恢复并通知界面。
- 调度测试覆盖 15/30/60 秒、500ms/2s 防抖、运行中唤醒、批次续传、退避、单次联网探测、暂停与关闭。
- `npm run check:web:v4`：类型与架构边界通过，413 项 Vitest 和 4 项生产服务器测试通过；随后补充旧响应保护，相关组件 6 项测试及生产构建通过。
- `npm run test:e2e -w @study-accelerator/desktop-runtime`：15 项通过。同步页面新增连续空同步不重新加载工作区、聚焦使用 `/wake` 的断言。知识页面等待窗口按 10 秒查询周期更新为 15 秒。
- Mac 构建与签名验证通过；打包应用常规测试 10 项通过，包括立即退出保存、保存失败草稿恢复、知识草稿、备份恢复和标题栏。

## 打包版与发布边界

```sh
KNOWRA_SYNC_ENERGY_CHECK=1 KNOWRA_PACKAGED_ENERGY_OUTPUT=/tmp/knowra-packaged-energy.json node --test apps/desktop-shell/test/packaged-sync-idle.test.mjs
```
