# 迁移契约与功能对等清单

本文件冻结“原型长什么样”与“正式前端如何工作”之间的映射。执行模型不得直接使用原型中的 `data-hook`。

## 1. 正式实现边界

| 区域 | 当前正式落点 | 必须保留的行为 | 目标变化 |
| --- | --- | --- | --- |
| Shell 静态结构 | `apps/web/src/server/shell-html.js` | SSR 首屏、元素 ID、静态资源加载 | 加入 TopBar、纯功能导航、FeatureStage、全局 Footer 宿主 |
| Shell 状态 | `shell-controller.js`、`lib/shell/view-state.js` | 页面切换、焦点模式、模块可见性 | 增加新外壳布局状态，不改业务语义 |
| 全局搜索 | `search-controller.js`、`lib/events/search-events.js` | 搜索、标签筛选、键盘操作、IME | 视觉入口移入 TopBar，事件和状态复用 |
| 功能导航 | `lib/shell/rail-renderers.js` | 工作域切换、设置入口、当前状态 | 改为 208px 分组导航 |
| 资料目录 | navigation controllers/renderers/events | 文件夹展开、选择、增删改、拖拽、右键菜单 | 从全局 Rail 拆为功能页 232px 目录栏 |
| Shell Footer | `lib/status/renderers.js`、document action events | 保存、源码、边注、专注、连接状态 | 宿主全局化，内容按功能注入 |
| 资料索引 | `lib/library-index/`、library index events | Tab、过滤、分页、选择、双击打开 | 按 InkGrid 四栏结构重排 |
| 文档 Tab | tab controller/renderers/events | 选择、关闭、拖拽、右键、溢出 | 保持正式属性契约，替换视觉 |
| 编辑菜单 | editor menu renderers/events/commands | 文件、段落、编辑、格式、视图、快捷格式 | 增加紧凑/溢出状态，不删除命令 |
| 编辑器正文 | editor controllers、Milkdown bundle | 输入、历史、粘贴、图片、表格、草稿保存 | 只改变容器、排版和视觉 |
| 资料边注 | sidebar controller/renderers/events | 信息、大纲、重点、AI、标签、附件、关联 | 迁移为 232px 可折叠辅助栏 |
| 其他工作域 | work-domain/knowledge/training controllers | 页面切换、只读查询、编辑入口、资料回链 | 适配外壳，不重新设计业务页面 |

## 2. 正式事件属性

以下是迁移时必须优先保留的正式契约；具体清单由 M0-02 从代码生成并补充：

- 导航：`data-nav-section`、`data-folder-toggle`、`data-folder-id`、`data-note-id`。
- 文档标签：`data-tab-note-id`、`data-tab-close`、`data-tab-overflow-toggle`、`data-tab-menu-action`。
- 编辑菜单：`data-editor-menu-toggle`、`data-view-menu-action`、文件/格式菜单 action。
- 状态栏：`data-save-now`、`data-status-action`。
- 右侧栏：`data-editor-aside-toggle`、`data-aside-tab`、标签和附件 action。
- 索引页：`data-index-tab`、过滤、分页、新建和打开 action。

规则：视觉容器可以新增 class 和 `data-ui-*`，但不得替换控制器正在查询的正式属性。

## 3. 全局外壳功能对等

- [ ] SSR 初始工作区仍能注入并完成首屏加载。
- [ ] API、缓存、mock 的加载优先级不变。
- [ ] TopBar 搜索支持点击、`⌘K`、Escape、Enter 和中文输入法。
- [ ] 通知、设置、用户中心未实现时有明确占位语义，不伪造业务状态。
- [ ] 资料、知识、训练、学习档案均能从功能导航进入。
- [ ] 返回资料工作域时恢复正确索引或编辑状态。
- [ ] Shell Footer 在页面切换时不重复挂载、不覆盖主体滚动区。
- [ ] 全局连接状态与功能状态具有独立渲染区域。
- [ ] 专注模式只改变布局，不清空已打开标签或草稿。

## 4. 资料索引功能对等

- [ ] 目录树展示真实文件夹和资料数量。
- [ ] 文件夹展开、选择、创建、重命名、删除、拖拽和右键菜单可用。
- [ ] 全部、最近、收藏、回收站 Tab 可用并显示真实计数。
- [ ] 类型、状态、时间和局部搜索过滤可组合使用。
- [ ] 空结果、清除筛选和错误状态有明确反馈。
- [ ] 分页和每页 5/10/20/50 条真实切片，不是装饰控件。
- [ ] 单击选择资料，双击或“打开”进入编辑器。
- [ ] 右侧详情展示真实类型、路径、字数、时间、收藏、标签、关联和附件。
- [ ] 目录栏和详情栏均可折叠、重开并同步可访问状态。
- [ ] 回收站恢复、永久删除和清空回收站入口不丢失。

## 5. 编辑器功能对等

- [ ] 返回索引保留浏览范围和选择状态。
- [ ] 文档 Tab 支持选择、关闭、拖拽、右键菜单和隐藏标签溢出。
- [ ] 文件菜单的新建、复制、导入、导出等现有命令全部保留。
- [ ] H1/H2/H3、粗体、斜体、列表、引用、代码、表格和图片命令可用。
- [ ] Milkdown 输入、撤销重做、Markdown 粘贴和中文输入法正常。
- [ ] 标题编辑与正文第一个标题保持独立。
- [ ] 自动保存、手动保存、失败保护和离开拦截正常。
- [ ] 源码编辑器开关、分栏和保存正常。
- [ ] 信息、大纲、重点、AI 四个边注 Tab 正常。
- [ ] 标签添加/移除、附件打开/重命名/删除、标注跳转正常。
- [ ] 专注模式可进入和退出，不丢失面板偏好与滚动位置。
- [ ] 字数、行数、链接、编码和连接状态来自真实状态。

## 6. 其他工作域功能对等

- [ ] 知识概览、知识单元列表和编辑入口可访问。
- [ ] 训练概览、题目库和题目编辑入口可访问。
- [ ] 学习档案依赖门禁保持真实，不展示虚构掌握度。
- [ ] 各工作域可返回资料，资料回链可打开目标资料。
- [ ] 新外壳不会为工作域保留错误的空列或压缩主区。

## 7. 响应式与侧栏契约

断点依据 `EditorMain` 的容器宽度，而不是浏览器总宽度。以下为首轮冻结值；如实测需要调整，必须先登记决策：

| 编辑器中心列宽度 | 模式 | 行为 |
| --- | --- | --- |
| `>= 1120px` | Full | 允许双侧栏停靠，显示完整菜单和快捷工具 |
| `900–1119px` | Compact | 双侧栏可停靠；菜单收为紧凑入口，低频工具进入“更多” |
| `720–899px` | Protected | 只允许一个侧栏停靠；第二个侧栏使用非破坏性覆盖层 |
| `< 720px` | Overlay | 两侧栏均为覆盖式抽屉，正文不继续压缩 |

共同规则：

- 标签和工具栏均为单行，不允许中文菜单被压成竖排。
- 被移出工具栏的命令必须进入可键盘操作的“更多”菜单。
- 活动文档标签始终可见；新增和溢出入口固定在滚动区外。
- 默认功能导航 208px，目录栏 232px，边注栏 232px。
- 1280px、1440px 和用户参考的 2048px 视口不得产生页面级横向滚动。

## 8. 可访问性契约

- 所有动作使用 `button`、`a`、`input` 等原生交互元素，不以可点击 `div`/`span` 代替。
- Tab 使用正确的 `tablist`、`tab`、`tabpanel` 关系或等价可访问实现。
- 折叠按钮维护 `aria-controls` 与 `aria-expanded`；覆盖式面板关闭后焦点返回触发器。
- 图标按钮具备中文可访问名称；装饰图标使用 `aria-hidden="true"`。
- `:focus-visible` 在所有表面清晰可见，不被 overflow 裁切。
- 200% 缩放时核心路径可用，不以颜色作为唯一状态提示。
- 动效尊重 `prefers-reduced-motion`。

## 9. 数据与安全契约

- API 成功和失败信封保持 `{ data }` / `{ error: { code, message } }`。
- 不绕过 workspace write guard、草稿持久化结果和离开保护。
- 不在原型静态数据基础上实现正式功能。
- 不更改附件 URL、安全检查、缓存恢复和本地优先写入规则。
- 不在 UI 迁移中引入数据库或数据文件迁移。
