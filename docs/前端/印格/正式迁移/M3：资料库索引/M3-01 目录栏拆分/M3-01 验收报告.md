### 4.2 功能检查

- 目录节点选择：PASS。资料和文件夹选中状态能够互斥更新。
- 分组折叠：PASS。资料分组收起时 `aria-expanded=false` 且控制容器 `hidden=true`；重新展开后两者同步恢复。
- 文件夹展开/收起：PASS。有子目录文件夹的 `aria-expanded`、`aria-controls` 和子节点容器隐藏状态同步。
- 右键菜单：PASS。资料根节点和文件夹均能打开对应菜单。
- 增删改与内联编辑：PASS。临时目录创建、子目录创建、重命名、删除和删除确认流程均通过；临时数据已清理。
- 拖拽：PASS（自动化）。`navigation-drag-drop` 与 `folder-tree-events` 由 Web 全套回归覆盖并通过；当前浏览器控制接口不提供原生 `dragTo`，本次不将其表述为鼠标拖放实测。
- 目录头部辅助菜单：PASS。打开/关闭时 `data-open`、`aria-expanded` 和 `#library-section-menu[hidden]` 同步。

### 4.3 可访问性与结构

- `#kb-sidebar` 保留 `aria-label="资料库目录"`；目录宿主和 `#folder-tree` 的正式标识存在。
- 分组按钮和有子内容的文件夹按钮均为原生 `button`，具备 `aria-expanded` 与 `aria-controls`，且控制目标 ID 在 DOM 中存在。
- 折叠状态不再通过删除控制目标表达，而是保留目标容器并使用 `hidden`，避免 ARIA 引用断裂。
- 图标继续使用 `aria-hidden="true"`；本次未发现新的交互语义问题。屏幕阅读器兼容性和完整 200% 缩放审计不由本次运行态替代。
