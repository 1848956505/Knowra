# M3-01 目录栏拆分执行报告

## 1. 执行结论

`执行侧完成 / 待正式验收`

本次执行将现有资料目录宿主补齐为显式的目录栏契约。M2-03 已经完成 Shell 的 208px / 232px / 主体三列物理拆分，因此本任务不再复制一套目录 DOM，而是在保留既有稳定 ID 和事件链的前提下，明确 `#folder-tree` 属于 232px 目录栏。

## 2. 实现内容

### 2.1 SSR 目录宿主

`apps/web/src/server/shell-html.js` 保留以下稳定结构：

- `#module-rail` 与 `#kb-sidebar` 为 ShellBody 的相邻 Grid 子项。
- `#kb-sidebar` 继续保留 `data-ui-library-directory` 和 `aria-label="资料库目录"`，并新增 `data-ui-directory-bar`。
- `.library-directory` 新增 `data-ui-directory-content`。
- `#folder-tree` 保留原 ID，并新增 `data-ui-folder-tree`；内联编辑器仍然在该节点内渲染。

### 2.2 状态与缓存

- `element-cache.js` 新增 `elements.directoryBar`，仍指向 `#kb-sidebar`。
- `shell-controller.js` 的目录显隐优先使用 `directoryBar`，并以 `sidebar` 作为旧调用方兼容回退。
- `folder-tree-events.js`、navigation render/controller 和所有树操作 controller 未改写，继续复用原有事件链。

### 2.3 232px 布局契约

`knowra-inkgrid-shell.css` 为 `data-ui-directory-bar` 固化 `var(--catalog-w)`、`min-width: 0` 和 Grid 顺序，避免目录栏再次被旧的通用侧栏语义或紧凑视口规则挤出三列布局。

## 3. 功能对等保留清单

| 行为 | 保留路径 |
| --- | --- |
| 选择文件夹/资料 | `#folder-tree` click → navigation controller |
| 文件夹展开/收起 | `#folder-tree` click → `toggleFolderOpen` |
| 分组折叠 | `#folder-tree` click → `state.navSections` + `renderFolders` |
| 新建、重命名、删除 | 内联 editor / delete intent selector → navigation controller |
| 拖拽移动 | `dragstart` / `dragover` / `drop` / `dragend` |
| 右键菜单 | `contextmenu` → navigation context menu |
| 内联编辑宿主 | `#folder-tree` 内的 form、input、Escape 和 submit 事件 |
