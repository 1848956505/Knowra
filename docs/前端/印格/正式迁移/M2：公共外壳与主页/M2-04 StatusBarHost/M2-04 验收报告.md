# M2-04 StatusBarHost 验收报告

## 验收结论

**REJECTED**

M2-04 的 Footer 宿主、功能槽/全局槽分离和既有事件属性大部分通过，但编辑器状态控制在 32px Footer 内发生实际裁切，违反“Footer 内容正确”和固定高度边界要求；同时发现离开编辑器后功能状态消息残留旧文档上下文。当前不解锁 M2-05。

## 功能与交互核对

- 功能状态槽与全局连接状态槽独立渲染，索引、知识、训练、学习工作域不渲染编辑器保存/统计/视图 action。
- 编辑器保留 data-save-now 和 3 个 data-status-action；边注按钮单击后状态从显示变为隐藏，再次点击恢复，未观察到双重切换。
- 专注按钮可进入/退出，功能导航和资料目录随布局状态隐藏/恢复。
- 从编辑器切换到知识、训练、学习或返回资料索引后，功能槽仍显示“已切换到：Transformer”，等待 3.2 秒后仍未恢复为当前工作域消息；该状态上下文残留已记录为次级问题。

## 缺陷分级

- P0：无。
- P1：编辑器状态控制的垂直盒模型超过 32px Footer 宿主并被裁切，激活态和边界不可完整呈现；当前通用 status-action 仍继承 10px 垂直 padding，而 InkGrid 编辑器规则只覆盖水平 padding。违反 M2-04 的 Footer 高度/内容正确性门禁。
- P2：跨工作域切换后保留旧编辑器文档状态消息“已切换到：Transformer”，当前工作域反馈不准确。
- 偏差记录：无新增、无已批准或未批准 D-xxx。
