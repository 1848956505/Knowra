## 真实数据与主页运行态

运行环境为当前工作区启动的真实 API/Web（API 3001、Web 3000），后端真实知识库数据为 17 条有效资料、6 个文件夹，最近编辑 5 条。主页显示：

- 资料工作台为唯一 ready 主入口，点击“进入资料库”进入正式资料索引。
- 知识工作台、训练工作台标记为“已接入”，不在主页虚构统计，要求从功能导航进入真实工作域。
- 学习档案显示“依赖未就绪”，保留 LearningEvidence 与 MasteryState 真实依赖门禁，不展示掌握度或复习数字。
- 最近编辑显示 Transformer、test、Test、Vision Transforme、讲义生成prompt，并按真实 updatedAt 倒序排列。

## 运行态与视口矩阵

浏览器现场控制台 error / warning 均为空；页面级横向滚动宽度始终与视口一致。

| 视口/页面 | 实测结果 |
| --- | --- |
| 2048×1024 主页 | screen=home；四张工作域卡均可见；Footer 32px；scrollWidth=2048 |

| 1024×768 主页 | 最小支持布局为双列卡片；主页内部纵向滚动可达全部卡片和最近编辑表；scrollWidth=1024 |
| 1280×720 资料入口 | 点击主入口后 screen=index，232px 资料目录可见，Footer 32px，scrollWidth=1280 |

## 功能与回链检查

- 主页“进入资料库”成功复用正式资料索引入口，资料目录恢复显示。
- 点击最近编辑第一条 Transformer 成功进入编辑器，Footer 功能状态显示“已切换到：Transformer”；从编辑器点击“首页概览”后恢复主页和“当前工作台：主页概览”。
- 知识库、训练场切换后分别显示真实后端查询结果和当前工作域状态消息；从功能导航可返回主页。
- 学习档案切换后显示依赖门禁；“返回资料”成功恢复资料索引和资料目录。
- 主页、索引、知识、训练、学习档案切换后无旧编辑器状态消息残留。
