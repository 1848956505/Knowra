## 交互核对

- 点击主页“进入资料库”：成功进入资料索引，资料目录恢复显示。
- 点击主页最近编辑第一条 Transformer：成功进入编辑器，状态消息显示“已切换到：Transformer”。该消息只在实际资料编辑器上下文出现。
- 从编辑器点击“首页概览”：成功返回主页；主页功能导航激活态正确，状态消息恢复为“当前工作台：主页概览”。
- 从主页进入知识概览、训练概览和学习档案：分别显示真实工作域内容或依赖门禁；Footer 不保留 Transformer 文档消息。
- 从知识、训练、学习档案返回首页：功能导航激活态与当前工作域同步；主页再次显示真实资料摘要。

## 布局核对

- 1280×720 主页：`document.documentElement.scrollWidth=1280`，`document.body.scrollWidth=1280`。
- 1280×720 资料索引入口：`document.documentElement.scrollWidth=1280`。
- Footer 宿主 `getBoundingClientRect().height=32`，位于 ShellBody 之外；主页无目录栏和编辑器边注栏残留。
- 主页工作域卡使用 `repeat(auto-fill, minmax(260px, 1fr))`；1024px 紧凑规则在 `knowra-inkgrid-home.css` 中通过组件入口接入，并由 Web CSS 入口测试覆盖。
