## 5. 初验阻断问题（已关闭）

以下内容保留 A-007 的原始阻断证据；修复结果见第 9 节。

### P1-1：1180px 以下的响应式 Token 覆盖选择器永远不匹配

当前 [knowra-inkgrid-library-index.css](../../../../../apps/web/styles/components/knowra-inkgrid-library-index.css) 第 161 行为：

```css
@media (max-width: 1180px) {
  .knowra-production-shell :root {
    --rail-width: 240px;
    --aside-width: var(--rail-width);
    --index-inspector-width: var(--rail-width);
  }
}
```

基线职责文件中对应规则是 `:root { ... }`。普通文档里的 `:root` 代表文档根 `html`，而 `.knowra-production-shell :root` 要求 `html` 成为 Shell 的后代；该选择器不会匹配任何元素。因此在 1180px 以下，`--rail-width`、`--aside-width` 和 `--index-inspector-width` 仍保持 Token 默认的复合 Shell 宽度，而不是预期的 240px，影响左侧 Shell、编辑器边注和资料索引检查器的紧凑布局。

这属于本次“统一限定在 Shell 作用域”改写引入的实际响应式回归。现有 1280×720 截图不会触发该媒体查询，不能证明 1024×768 最小支持布局仍然有效；问题优先级为 P1。

修复方向：将这些变量声明放到媒体查询内的 `.knowra-production-shell` 自身，使 Shell 及其后代继承覆盖值；同时补充 1024×768 运行态验证和针对该变量覆盖的回归断言。若采用 `:root:has(.knowra-production-shell)`，还必须同步调整作用域门禁测试与兼容性说明。
