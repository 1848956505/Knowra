## 结果概述

- 在正式 Token 文件中建立 `--ink-*` InkGrid 语义令牌，集中管理字体、色彩、线条、硬阴影、间距、字号、圆角和常用尺寸。
- 为现有正式 CSS 变量建立兼容别名，保持现有页面样式入口可用；视觉字面量集中在 Token 文件中，不在组件样式中新增散落值。
- 增加 Token 形状测试，并同步更新既有 UI 规范测试，使断言指向 canonical `--ink-*` 令牌。
- 按当前 InkGrid 设计基线修正字体角色和字号梯度，并为正式字体角色、无衬线约束和关键字号补充值域测试。
- 将 M0-01 已冻结的 Tab 激活线规则接入对应的既有 CSS 消费点；这些改动只替换激活线的 Token/颜色表达，不改变页面结构、控制器、状态语义或事件 selector。
- 未修改页面结构、控制器、状态语义、API、事件 selector 或 M1-02/M1-03 范围内容。

## Token 覆盖范围

- 基础与语义色：纸张背景、表面、正文、次要文本、边框、点阵、强调色、成功/警告/危险色及 focus 状态。
- 线条与阴影：`--ink-line-*`、`--ink-border-*`、`--ink-shadow-*`，包含 1px/2px 线条和黑色硬阴影。
- 尺寸：Shell、目录、知识点辅助侧栏、检查器、菜单、顶部栏、状态栏及编辑器工作区的语义尺寸。
- 排版与间距：设计文档规定的无衬线字体栈、42px Display、28px 页面 H1、16px 区块 H2、行高、字距、`--ink-space-*` 间距和状态圆角。
- 兼容层：`--paper`、`--blue`、`--line`、`--shadow-editorial`、`--space-*`、`--type-*` 等既有入口继续解析到 canonical Token。

## 结构边界说明

M1-01 只接入 Token，不执行 Shell 的结构拆分。虽然已准备 `--ink-shell-nav-w:208px`、`--ink-catalog-w:232px`、`--ink-aux-sidebar-w:232px` 和 `--ink-inspector-wide-w:300px` 等语义尺寸，当前正式运行态仍保留 `--ink-shell-composite-w:260px` 的既有复合 Shell 宽度，待后续阶段按任务书执行结构迁移；本报告不将这些 Token 误报为 M2 的页面结构完成。
