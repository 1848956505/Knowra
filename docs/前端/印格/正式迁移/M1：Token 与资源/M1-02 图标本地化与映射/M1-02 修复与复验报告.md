## 验收问题

验收报告指出，正式运行时仍有 3 处直接输出 Unicode `›`，未使用中央语义图标映射：

1. `apps/web/src/server/shell-html.js` 的资料边注收起按钮。
2. `apps/web/lib/library-index/renderers.js` 的空状态检查器收起按钮。
3. `apps/web/lib/library-index/renderers.js` 的已选资料检查器收起按钮。

同时，原 `icon-mapping.test.js` 没有禁止目标渲染器直接输出 Unicode 图标字符的回归断言。

## 修复内容

- 上述 3 处统一改用 `renderIcon('navigationChevron', ...)`。
- 为 `panel-close-icon` 和 `editor-aside-toggle-icon` 增加本地语义图标尺寸规则。
- 保留原有 `button`、事件 selector、中文 `aria-label` 和交互方向；未改变控制器、状态或 API。
- 在 `icon-mapping.test.js` 中加入目标渲染器 Unicode 图标字符扫描。
- 在索引渲染器和 Shell UI 测试中增加实际输出断言，覆盖有资料、无资料和编辑器边注场景。
