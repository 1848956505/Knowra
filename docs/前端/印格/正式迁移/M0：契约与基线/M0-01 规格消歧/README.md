# M0-01 规格消歧

## 任务状态

`修复与复验材料已完成 / 待规划与验收方复审`

本工作区只承载 M0-01 的规格冲突分析、建议值和证据边界，不承载正式前端实现。

## 任务范围

- 统一功能导航、目录栏、索引详情栏、编辑器边注和宽版检查器的尺寸语义。
- 确认模块 Tab、文档多开 Tab 的激活线规则。
- 确认编辑器专注模式的布局变化、状态保留和退出恢复规则。
- 确认 Shell Footer 的宿主归属、页面注入内容和专注模式显示规则。
- 记录静态源码证据以及浏览器视觉证据的可用性。

## 重要边界

- 本轮仅修改正式前端的 Tab 视觉层、对应回归断言、设计文档和组件库；未修改 API、状态层、事件契约或正式迁移的 `00/01/02/03/05/06` 文件。
- 标签页使用左侧 2px 蓝线；模块、视图或面板 Tab 切换使用下方 2px 黑线。正式决策记录仍需由规划与验收方写入。
- 报告中的“建议冻结”不是正式 `PASS`；需由规划与验收方审阅后落库。
- 本轮通过本地只读 HTTP 服务取得三张目标原型截图和页面控制台结果；截图原件均保存在本工作区 `浏览器证据/`。
