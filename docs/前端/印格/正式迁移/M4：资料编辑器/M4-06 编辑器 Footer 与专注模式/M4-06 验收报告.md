## 发现

### M4-06-P1-1 专注模式进入和退出后焦点落到 `BODY`

- 路径：Footer“进入专注模式” → Footer“退出专注模式”。
- 实测：两次操作均会重绘触发器；重绘完成后 `document.activeElement === BODY`，没有把焦点交接给新渲染的“退出专注模式”或“进入专注模式”按钮。
- 影响：键盘用户触发专注模式后失去当前位置，无法沿当前操作链立即退出或继续操作；违反“焦点始终可见”和重绘后保持合理焦点的正式可访问性门禁。
- 优先级：P1。

### M4-06-P1-2 从阅读模式进入专注后正文变为可编辑

- 路径：“更多” → “阅读模式” → Footer“进入专注模式”。
- 实测：进入前 Shell 为 `data-view-mode="read"` 且不存在 `[contenteditable="true"]`；进入专注后 Shell 为 `data-view-mode="focus"`，正文出现 `[contenteditable="true"]`。退出后才恢复为 `read` 和不可编辑。
- 影响：专注模式不再是纯布局状态；原本处于阅读模式的用户在专注期间获得编辑能力，可能产生非预期草稿或内容变更，违反“专注模式只改变布局”的正式契约。
- 优先级：P1。
