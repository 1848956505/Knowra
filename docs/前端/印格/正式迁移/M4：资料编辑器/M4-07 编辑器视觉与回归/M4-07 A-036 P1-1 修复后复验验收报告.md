## 未通过项

### P1-1 200% 编辑器主路径仍不可完整操作

页面级横向滚动虽然已经消失，但编辑器内部仍存在两个真实阻断：

1. 从已收起两侧面板的资料索引打开资料后，编辑器目录覆盖层会重新出现。当前编辑器 DOM 没有提供索引态的“折叠目录栏”按钮；目录层与 232px 边注栏同时占据 543px 视口，主编辑区仅余狭窄可见带，活动长标题、正文和焦点位置无法被用户正常观察和操作。
2. 200% 下 `.aside-panel-scroll` 实测 `clientHeight=0`，而内容 `scrollHeight` 为 745px（切换“大纲”后为 3154px）。边注内容无法滚动，长附件虽然仍存在于 DOM，但其矩形顶部位于约 1616px，用户无法到达。

附件省略 CSS 本身已生效：长文件名 `clientWidth=106`、`scrollWidth=534`、`overflow=hidden`、`text-overflow=ellipsis`。但元素没有 `title`，且所在滚动区高度为 0，所以既不能看到省略结果，也没有可访问完整文件名的替代路径，不能判定附件长文件名状态通过。
