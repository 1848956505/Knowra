This demo now supports dual themes. Click the moon/sun icon in the top right corner to switch between Dark and Light modes seamlessly.

Implementation Details

  • CSS Variables for instant token swapping
  • Smooth transitions on all color properties
  • Adaptive shadows and glows per theme
// Theme switching logic
const toggle = () => {
  const next = current === 'dark' ? 'light' : 'dark';
  document.documentElement.setAttribute('data-theme', next);
};

The light mode uses a cool grey palette (#F4F5F7) instead of pure white to maintain that premium Linear aesthetic while reducing eye strain.
