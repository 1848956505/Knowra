# V5 第五阶段：命令搜索、路径与元信息

基线为 PR #99 合并提交 `f3d3315b4b57ef74253eb79b416ad6f24252511b`，独立分支 `feat/v5-command-meta`。本阶段只收敛第四阶段全 src 审计中确认的可达旧视觉。

## 变更清单

- `shell/SearchCommand.module.css`：搜索列表采用中性圆角结果卡片与浅色选中背景，移除深黑激活边框、800 字重等宽分组及大写字距；长正文片段自然换行，手机把提示放到第二行，保留正文可读宽度。
- `shell/PathTrail.module.css`：路径元信息采用共享 UI 字体和 500 字重，语义文字令牌与可见焦点。保持路径省略、导航、当前页语义及完整可访问名称。
- `features/editor/EditorInspector.module.css`：只把日期、计数、版本时间/字符数、附件元信息与引用徽章切换为 UI 字体；数字仍使用 tabular-nums，历史正文 Markdown 预览继续等宽。
- `shell/StatusBar.module.css`：字数与保存时间复用 UI 字体与等宽数字，不修改状态内容。

生产改动仅 CSS Modules，不修改搜索查询、异步结果隔离、正文读取、键盘选择、取消、导航、权限、API、Store、编辑器、数据持久化及恢复规则。沿用共享 SearchBox/Dialog，React Aria 继续管理 portal、inert 和焦点。

## 合成验收范围

八个视口使用真实渲染的生产页面与纯合成数据，覆盖 Cmd/Ctrl+K、标题/正文搜索、键盘高亮、Enter 导航、取消与焦点恢复、查询清空、空/加载/失败状态，以及路径和检查器只读元信息。对长命中内容检查可读宽度与可见性，不只检查页面无横向溢出。截图和 manifest 记录精确 PR head、构建 SHA、生产源码 tree、浏览器与网络边界。

整个浏览器 context 拦截外部网络、WebSocket、未知 API 及非 GET 请求。不会调用真实模型、同步、保存、恢复、上传、下载私人资料或改变配置。云环境本地 Chromium socket 限制不以关闭沙箱绕过；浏览器最终结果以精确提交的实际 CI 为准。

## 最终全 src 样式审计

采用两层检查：一是扫描全部 CSS 与生产 TSX 中原始色值、硬偏移阴影、左侧选中条、非代码等宽文字与重字距；二是从 `src/main.tsx` 追踪本地静态 import/export，再人工核对可疑 selector 的组件引用。

本次保守静态图共有 321 个本地源文件、66 个 CSS 文件，其中 65 个被静态引用，无无法解析的本地导入；barrel export 会把未实际渲染的模块计入，因此“被导入”不等同于“用户一定可见”。

| 命中 | 判断与处理 |
| --- | --- |
| `shell/TopBar.module.css` | 不在生产入口导入图，旧硬阴影/等宽大写属于未使用遗留，未当作可见页面。 |
| `App.module.css` 的 `backLink` | 文件用于路由，但该 selector 无生产类引用；旧硬阴影仍属 dead selector。 |
| `global.css` 的 `app-header*` | 全局文件加载，但这组旧容器类没有 TSX 引用；现行通用焦点和滚动条规则仍有效。 |
| 首页 `PixelFace` | 组件保留挂载，首页 `.headerFace` 明确隐藏；不是可见的 V5 像素标识。其后台行为不在本次视觉收尾中删除。 |
| `ink-*` 兼容名 | 已映射 V5 语义令牌，不是独立旧主题。未为追求零命中而机械改名。 |
| 标签、成功、警告、危险、差异增删色 | 业务语义，保留各自颜色；蓝色标签不改品牌橙色。 |
| 树缩进、面板/工具分隔、图标边线 | 不是导航选中左竖线，不删除必要结构与图标笔画。 |
| Markdown/code/source/diff、构建 SHA、连接命令、键盘快捷键 | 内容或键位语义，继续允许等宽；非代码日期/计数已在本批收敛。 |
| 首页/正文大标题 700、强调内容 | 正常层次与内容语义，不等同于旧 UI 800 等宽大写标签。 |

在本次识别的可达表面中，未再发现原始品牌色散落、旧位移硬阴影、深黑选中描边或非内容用途等宽重字距标签。此结论是代码审计与已列举状态的视觉验收，不是所有可能状态穷尽证明。
