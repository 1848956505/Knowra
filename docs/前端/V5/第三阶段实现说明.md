# V5 第三阶段：AI、设置与首页

本阶段从第二阶段合并后的 main 继续，范围为 AI 会话、成果审阅、附件选择、预算提示、设置、首页和空间管理。只更新局部视觉与响应式布局，复用现有共享控件和语义主题令牌。

## 不变边界

- AI 请求、生成和成果应用规则、预算限制、模型配置与凭据读写逻辑均不修改。
- 空间创建、资料操作、设置保存仍使用原组件与 Store；不新增真实付费调用。
- 焦点、弹层、取消草稿及窄屏入口保留；代码片段等真实代码内容继续使用等宽字体。

## 验收

- 前端类型、架构边界、完整组件测试及生产构建。
- 新增 AI/设置领域的8视口合成页面截图，显式模拟接口并阻断未建模网络请求；记录 PR head、构建 commit 和生产源码 tree。
- 真实浏览器证据与独立视觉审查通过后，再由主审决定合并。CSS 视口不等同于实体手机软键盘或系统 WebView 验收。

## 样式残留审计

按 `apps/web-v4/src` 全部 CSS 扫描，不能把所有颜色或边线机械地替换成品牌橙色：

- `styles/tokens.css` 中的原始颜色属于主题定义；标签、警告、成功、错误等状态保留各自语义颜色。
- 本阶段处理首页偏移硬阴影及 AI/设置中的硬编码状态颜色、非代码等宽元信息。
- `shell/TopBar` 当前无组件引用，`App.module.css` 的 `backLink` 无类引用；其中旧硬阴影是未使用遗留，不影响现行外壳，后续可单独清理。
- 同步冲突与备份恢复弹窗仍保留兼容令牌和方形局部容器，留在后续窄批迁移与恢复流程专门验收。
- 编辑器代码块、Markdown 引用边线、实际标签颜色与 keyboard focus 是内容/交互语义，不属于旧选中强调条，不应批量移除。
