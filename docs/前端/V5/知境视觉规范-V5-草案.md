# 知境视觉规范 V5（草案）

状态：草案，2026-10-11。依据：`knowra-layered.html`（可交互原型，是色值与参数的唯一来源）和 `笔记页面设计.md`（文字质感原理）。尚未落地到 `apps/web-v4`，也未与现有「印格」tokens 合并。

## 1. 设计理念

从「印格」的个人风格（硬位移阴影、粗黑边、直角、米色纸面）转向面向通用用户的现代简约风，参考 Linear 的浅色表达。四条原则：

1. **靠明度分层，不靠描边。** 层级由底色明暗、1px 发丝线和柔和阴影表达。禁止同时使用粗黑边和位移阴影。
2. **克制。** 彩色只留给小面积点缀（图标、链接、复选框、列表圆点）。大面积保持冷灰与白。
3. **呼吸感。** 标题收紧字距，正文放宽行高，三级灰阶，拒绝纯黑和纯白。
4. **写作沉浸。** 编辑区没有输入框痕迹：无边框、无背景、无聚焦光环。

## 2. 分层结构

三层，由低到高：

| 层 | 内容 | 底色 | 说明 |
| --- | --- | --- | --- |
| 外壳层 | 顶栏、图标栏，以及面板之间的 8px 间隙 | `#E1E4EA` | 最低最暗，是「全局独立栏」。顶栏放前进后退、笔记标签页和额外操作 |
| 上下文侧栏 | 导航与文件夹树 | `#F7F9FA`（92% 不透明） | 悬浮在外壳层上，四周留 8px 间隙，半透明磨砂 |
| 功能页面 | 笔记、知识库等主内容 | `#FBFCFD` | 最亮，阴影最深。必须比侧栏更白，但不用纯白 |

尺寸：顶栏 46px，图标栏 56px，侧栏 240px，面板外圆角 12px，面板间距 8px。

## 3. 色彩

文字三级灰阶（全局只用这三档，外加一档占位灰）：

| 用途 | 色值 | 备注 |
| --- | --- | --- |
| Primary：标题、焦点 | `#17181B` | 不用纯黑 |
| Secondary：正文 | `#686D76` | 比 Qwen 参考的 `#6E7178` 略深，保证中文正文在冷灰底上的对比度 |
| Tertiary：元数据 | `#8A8F99` | 比参考的 `#9DA1A9` 深，原值在页面底色上对比度约 2.3，过低 |
| 占位 | `#B4B9C6` | 仅用于 placeholder |

强调色：橙色 `#F26B1D`；用于文字的深色版 `#C4510C`（亮橙作为小字对比度不足）。浅色底和描边由强调色与白色按 9% / 24% 混合得出。

线条：发丝线 `rgba(24,30,48,.075)`，较强 `rgba(24,30,48,.12)`。悬停 `rgba(24,30,48,.055)`，按下 `rgba(24,30,48,.085)`。

## 4. 文字

字体：Inter + 苹方 / Noto Sans SC，等宽用 JetBrains Mono。全局开启 `-webkit-font-smoothing: antialiased`、`-moz-osx-font-smoothing: grayscale`、`text-rendering: optimizeLegibility`。

| 元素 | 字号 / 字重 | 字距 / 行高 |
| --- | --- | --- |
| 笔记标题 | 34px / 700 | -0.6px |
| 小标题 | 19px / 600 | -0.3px |
| 导语 | 16px | 行高 1.8 |
| 正文 | 15px | +0.01em，行高 1.75 |
| 元数据 | 12px | — |
| 界面文字 | 13px | — |

## 5. 线条、圆角、阴影

- **圆角：** 面板 12，提示框 10，代码块 8，标签页 8，按钮和导航项 7，标签胶囊全圆。
- **描边：** 圆角元素用 `box-shadow: 0 0 0 1px` 画 1px 轮廓，边缘比 `border` 干净。
- **功能页面阴影（四层）：** 1px 轮廓 → 近处柔影 → 中距离 → 远距离。
- **弹层阴影：** 1px 轮廓 + 两层柔影，最远一层 `0 24px 64px -12px`。
- **禁止：** 位移硬阴影、纯黑描边、模糊半径为 0 的实心阴影。

## 6. 材质

- **玻璃只用在上下文侧栏。** 28px 模糊、饱和度 125%、`inset 1px 1px 0 #ffffffc7` 左上内高光、`rgba(54,60,74,.13)` 细边。
- **功能页面保持不透明。** 原型里试过「两块都用玻璃」和「仅页面用玻璃」，当前定稿是「仅侧栏」。
- 选中的标签页和图标栏高亮是接近实色的白色卡片，不做模糊。

## 7. 状态规则

- **导航项选中：** 白色渐变小卡片 + 细边框 + 内高光，字重 600，图标变强调色。
- **文件夹下的笔记选中：** 中性灰底 `rgba(24,30,48,.075)`，字色 Primary，字重 550。**不用强调色。**
- **标签页选中：** 纯白底 + 1px 轮廓 + 轻阴影，图标变强调色。
- **禁止左侧竖线。** 任何选中态或组件都不使用左侧竖线强调条。树形缩进线不属于此列。
- **聚焦：** 3px 强调色 28% 透明度光圈，不用位移阴影。

## 8. 光晕

笔记页面不加光晕（定稿）。原因：亮底上的彩色光晕会把底色染成发黄发灰的一团，右上角尤其明显。顶部白光和冷蓝两个备选在原型中保留，用于首页、空状态等停留时间短的页面。

## 9. 实现注意

- 带横向滚动的容器（如标签栏）会裁掉子元素的描边和阴影，容器要留内边距，否则圆角四角看起来没画完。
- 强调色同时是「危险」语义的近邻色，删除、报错状态用更深的暗红加图标区分，不要和选中态混用。
- 玻璃效果依赖 `backdrop-filter`，需要为不支持的环境准备实色回退。

已定（2026-10-11）：
