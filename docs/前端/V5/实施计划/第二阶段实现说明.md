# V5 第二阶段：知识、题库与标签管理

本阶段从已合并的第一阶段继续，限制在知识工作区、知识来源对照、题库/学习目标详情与标签管理。AI 主页面、设置和首页留待后续独立迁移。

## 结构与主题

- 复用第一阶段共享控件和分层外壳；业务 CSS 只管理内容布局与局部表面，去除旧的硬偏移阴影、选中侧条和非内容性的等宽字体。
- 状态色补齐 `--color-success/warning/danger/violet` 及柔和背景，旧 `--ink-*` 保持兼容别名。标签蓝色使用 `--color-info`，不与品牌橙色混同。
- 知识列表和详情为独立滚动区，保留窄屏上下分区并补键盘焦点；滚动区域采用中性定位反馈，不套用表单光圈。
- 训练类型筛选可换行，长知识标题按钮只调整布局；标签卡片长名和窄屏排列适配均不改业务规则。

## 不变边界

知识确认/来源复核、历史版本读取、题目答案与评分标准、学习目标、标签排序/合并/撤销删除仍使用原组件逻辑与接口。未改 API、Store、持久化、模型调用、同步或 Milkdown。

## 验收

- 领域 Vitest 与 `check:web:v4`；样式约束在 `scripts/test/v5-domain-styles.test.js`。
- `v5-domain-evidence.spec.ts` 使用只读合成资料，在8视口捕获知识、来源对照、题目列表/详情/来源、学习目标和标签管理/编辑；校验关闭焦点、取消不写入、无横向溢出及无未知网络请求。
- 保留既有知识来源与题目详情完整浏览器回归；截图须对应最终 head/source tree，独立视觉复核通过前保持 Draft。
- CSS视口不代表真实手机软键盘、系统 WebView 或 OriginOS 的设备验收。
