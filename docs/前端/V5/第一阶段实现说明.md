# V5 第一阶段：外壳与笔记

## 范围

本阶段替换共享主题/基础控件、全局外壳与笔记模块。知识库、试题、助手等独有页面的进一步重排留在后续独立变更。已有数据、Milkdown、持久化、附件、AI与同步协议未更换。

## 分层与主题

- `styles/tokens.css` 是主题入口：`surface-*` / `text-*` / `accent-*` / `border-*` / `shadow-*` 负责表现，`space-*` / `radius-*` /尺寸变量负责尺度。
- 旧 `ink-*` / `shadow-*` 是兼容别名，不是平行主题。业务页不复制主题色；标签蓝色通过 `color-info` 保持业务含义。
- 外壳 #E1E4EA；侧栏 #F7F9FA 的92%半透明及28px模糊，无backdrop-filter时回落实色；功能页面 #FBFCFD 不透明，无光晕。
- 46px顶栏、56px轨道、240px侧栏、8px间距、12px外圆角。手机保留独立模块入口和44px触点。
- 主强调色 #F26B1D，正文链接深橙 #C4510C。白字实色按钮使用深橙；浅橙底小字用 `accent-on-tint` #B5480A。元数据使用 #6C727C（页面4.72:1、侧栏4.59:1），外壳小字使用 #60656E（4.60:1）。装饰不冒充可读文本。
- 原产品仅定义浅色主题，本次没有移除既有深色实现，也未虚构深色验收。

## 组件与行为

- `AppShell` 承载不透明内容与磨砂侧栏，`ShellToolbar` 承载全局开关和状态入口；状态详情按需展开，没有全局底部状态栏。
- `DesktopTitlebarContext.host` 为浏览器与桌面提供共享标签挂载点，`enabled`仍仅表示原生桌面能力。窗口安全区、拖拽/非拖拽区保留。
- 编辑器仍负责打开/关闭当前笔记前保存和滚动恢复。跨模块标签沿用store持久状态，键盘方向/Home/End切换、Delete关闭；实际关闭后将焦点归还相邻标签。
- 窄屏导航复用 `ResponsivePanel`，保留跨断点子树、草稿、焦点约束和嵌套浮层。路由跳转后关闭导航。
- `LocalSyncControl`仅增加紧凑表现，常驻顶栏，不随状态弹层卸载，保留原轮询与唤醒监听。
- 正文默认15px/1.75、标题34px；已有15/17/19px用户偏好原样保留。标题和正文通过插入光标反馈焦点，不绘制输入框轮廓；控件使用清晰键盘描边与透明光圈，主区仅在显式跳转链接后显示定位提示。

## 验收要求

单测/类型/架构边界/构建之外，必须对最终提交检查真实截图及行为：长标题、多标签滚动与关闭、侧栏/检查器断点切换、嵌套弹层、保存失败、持续同步、附件与撤销/IME。沿用合成网络隔离，不能将缩短视口等同真机键盘验证。

`playwright.mobile-evidence.config.ts`包含外壳、编辑器、笔记导航/拖拽、跨端与截图场景。截图产出不等于视觉通过；须人工查看最终head对应图片。未完成浏览器验证前保持草稿PR。
