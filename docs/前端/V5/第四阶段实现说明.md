# V5 第四阶段：同步、备份与状态详情

基线为 PR #98 合并提交 `278deeeaf6077247794977898c06e3af3c2d1d67`，独立分支 `feat/v5-status-dialogs`。本阶段承接第三阶段明确留下的可达弹窗，不以全量颜色替换代替视觉迁移。

## 范围与模块边界

- `LocalSyncControl.module.css`：同步入口、登录表单布局、设备信息、错误提示，手机单列；同步成功、警告和失败仍保持各自语义颜色。
- `SyncConflictCards.module.css`：笔记/关联资料冲突卡片、字段表格、正文比较、手动合并表单，长标题可折行，对比表在局部容器内滚动并有键盘焦点。
- `BackupRestoreDialog.module.css`：备份列表、检查结果、恢复确认内容及失败提示。
- `SettingsView.module.css`：长客户端名称验收暴露 768px 侧栏挤压，客户端文案/按钮按实际可用宽度换行，避免只依赖手机断点；不改配对与权限逻辑。
- `StatusBar.module.css`：顶栏状态弹层使用语义文字、状态令牌与可折行明细；兼容 bar 布局不移除。
- 继续使用项目 Dialog/Select/Checkbox/Button 与 React Aria 的 portal、inert、关闭、焦点和只读/禁用行为。无需新业务样式引擎，也不增加平行主题。

## 安全和业务不变项

生产 TSX、Store、API、Milkdown、同步轮询与唤醒、凭据、备份、恢复和持久化代码均不修改。状态入口保持挂载，关闭弹窗不停止后台监听。危险确认文字与恢复禁用门槛不删减。测试不读取真实笔记、用户备份或密钥，不执行真实备份/恢复/清理、配对或配置保存，不调用外部服务与付费模型。

## 合成浏览器证据

新增八个视口的真实页面合成验收，覆盖同步、冲突、状态、备份列表/检查/恢复禁用，并补充第三阶段设置页底部保存按钮可达、长客户端名称和明确假密码遮罩。网络使用整个浏览器 context 隔离：仅同源已建模读取及精确备份检查请求由夹具返回，任何未知请求和写入立即阻断并计入失败。截图记录 PR head、实际构建 SHA、源码 tree、浏览器、横向溢出与焦点断言。

这些证据只证明合成场景的布局/交互，不证明真实文件备份与恢复成功、设备同步可用、账号连接成功或实体手机软键盘表现。生产恢复/迁移正确性仍由既有独立测试承担。

## 全 src 残留审计

检查 `apps/web-v4/src` 的原始色值、硬偏移阴影、左侧强调条、等宽文字及实际引用：

- `styles/tokens.css` 为唯一语义主题色来源；其兼容 `ink-*` 别名已映射 V5，别名存在本身不等于旧视觉。
- `shell/TopBar.tsx` 没有生产导入，`App.module.css` 的 `backLink` 没有类引用。其硬偏移阴影属于未使用遗留，本阶段不做无关删除。
- `styles/global.css` 的 `app-header*` 没有 TSX 类引用，属于旧容器遗留；实际共享焦点与滚动条仍生效。
- `PixelFace` 在首页仍挂载，但 `.headerFace { display: none; }` 已隐藏其视觉。组件独立演示/历史测试不代表现行首页仍显示像素标识。
- 标签蓝/绿/红/紫、diff 新增/删除、错误、警告、保存状态保持原语义颜色；SVG/图标和 Markdown 内容的线条不能当作导航左侧选中条删除。
- `shell/SearchCommand.module.css` 仍有真实可达的旧命令面板视觉：800 字重等宽分组、直角卡片和深色激活边框；`PathTrail.top` 仍使用 700 等宽文字。应单列后续 CmdK/路径迁移和截图验收，不能当作 dead CSS 忽略。
- 编辑器代码块、版本原文预览、设置命令片段保留等宽字体。编辑器部分日期、计数及附件元数据仍使用等宽字体，属于尚未统一的文字细节；本 PR 不扩大至编辑器再次重验。

结论：本阶段覆盖第三阶段留下的同步/备份/状态可达表面；不据此声称所有页面、所有状态或真实端到端路径均验收完毕。CmdK/路径视觉迁移、未使用样式清理、编辑器元信息字体和真实设备验收仍是独立边界。
