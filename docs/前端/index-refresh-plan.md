# 右侧索引界面改版记录

2026-09-05。第二轮已实施整体改版，以下保留设计方向并记录当前验收。

## 本轮基线

- 搜索：暖灰内凹默认态；白底、蓝边、单层蓝色外硬阴影聚焦态。原生输入元素不持有阴影，普通输入框不改。
- 组件中性阴影：浅暖灰，沿右下方向无模糊位移；hover 采用浅蓝阴影和蓝色文字/图标。
- 令牌入口：`apps/web-v4/src/styles/tokens.css`。搜索使用独立 `--shadow-search-*`，不复用普通输入的 `--shadow-input-*`。

## 已实施方向

参考 preview-2.html 和第二轮截图，保留暖纸底、连贯工具栏、行列秩序与底部分页；表头按第二轮要求改为暖灰。

1. 将顶部导航/操作、标题与筛选栏、表格、分页形成一个整体面板；外层仅一处浅色硬阴影，子区使用分隔线，避免 demo 双层阴影叠加。
2. 蓝色集中在索引标识、主操作和选中态；内容行维持白底/轻暖灰，文件夹可用很浅的蓝底。状态徽章保持原有语义色，不把所有元素都变蓝。
3. 复用当前搜索、类型/标签筛选、排序、列表/图标切换、批量管理和右键操作，不引入 demo 的模拟数据、模拟行为。
4. 已拆分头部、列表和卡片、菜单、批量标签及查询 hook；布局和项目样式分别维护。

## 主要入口

- `apps/web-v4/src/features/notes/NotesIndexView.tsx`：组合索引、工具栏、筛选和批量操作。
- `apps/web-v4/src/features/notes/NotesIndexView.module.css`：索引布局、列表/图标与分页样式。
- `apps/web-v4/src/components/ui/`：复用按钮、搜索、菜单与对话框。

## 验收范围

- 全部笔记、根目录、文件夹、最近编辑、收藏、回收站及编辑器返回索引。
- 搜索默认/鼠标聚焦/键盘聚焦/清除，筛选组合、排序、两种视图、分页和右键菜单。
- 空列表、长标题、批量管理、禁用与错误态。
- 桌面、窄屏和移动断点；外壳固定，各区域独立滚动；单层容器阴影不被裁切。

实现补充：面板使用单层 8px 浅暖灰阴影，暖灰粘性表头，固定头尾；列表和图标共用内部滚动区。路径包含全部祖先文件夹，目录/范围使用 URL 的 folder/scope 参数；浏览器前进后退、刷新恢复及状态栏路径保持一致。导入复用原对话框。普通输入框沿用前一轮样式边界。

分页保留服务端每批 30 篇笔记及 `hasNext` 契约：首屏只请求一批，用户显式选择“加载更多”才续取，未载完时显示“已载入”而不伪造总数。列表和图标视图统一按 5/10/20/50 条分页，图标节点不再随服务端总量一次增长。最近编辑仍遵守 6 篇范围上限。状态徽章翻译持久化英文值，未知自定义状态原样保留。

回归：245 项前端测试、2 项静态服务器测试通过；新增路径编码、多级祖先、循环保护、历史回退/前进/分支清除及导入入口覆盖。

浏览器实测：列表内部滚动 388.5px 时主区域 scrollTop 为 0，面板顶边保持 24px；外阴影为单层浅灰 8px。目录前进后退、图标视图通过；390px 窄屏下页面无横向溢出，内容区仍有 248px 可用高度。
