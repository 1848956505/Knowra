# 笔记内部链接与反向引用首版

## 已确认范围

选中文字 → 内部链接 → 搜索当前知识空间内的整篇笔记 → 保留原显示文本 → 点击打开目标。复用检查器链接 tab 的“本页链接”和“引用这篇笔记”。反向引用按来源笔记分组，每个实际引用位置显示短上下文，点击定位来源引用处；同源多引用保留全部位置。

目标改名、目录内移动保持链接；删除显示“目标已删除”，恢复同一 ID 后重新可用。保留现有空间迁移安全限制。不扩展跨空间创建、标题/块级目标或自动发现未链接提及。笔记链接不扩大 AI 读取权限。

## 实现与数据约束

- 新链接使用标准 Markdown 链接，目标 URL 为 `knowra://note/<编码后的稳定笔记ID>#ref=<引用位置ID>`。显示文本独立保存；引用位置 ID 标识来源 occurrence，不是目标章节/块 ID。新建随机 ID，修改目标保留位置 ID；重复 ID 必须判歧义，不能任意选择相同文字。
- 共享 Markdown AST 解析器提取目标、位置、源偏移和短上下文，排除代码示例。正文是事实来源，`internalLinks` 是派生目标集合；反链从完整持久化来源查询，不依赖已加载页面，也不新增需要独立同步的反链实体。
- 保留历史 `[[文本]]`，不按标题猜测转换。新编码通过正文同步、版本恢复和重启恢复；JSON/PostgreSQL 使用同一解析逻辑。
- 弹窗使用项目 Dialog/SearchField/Button，捕获并校验原文档和选区；确认一次事务修改，取消不写正文，移除仅移除链接保留文字，支持撤销重做。只读、选区变化和保存冲突保持已有保护。
- 跳转先保存来源草稿，失败留在来源。复用应用导航前进后退和编辑器位置保存。来源定位同时校验持久化正文哈希、当前解析结果中的唯一位置 ID 与目标；缺失、歧义或版本不一致只打开来源并显示可关闭的持续提示，不使用任意字符串搜索。
- 删除目标保留 URL/原文字与失效状态；恢复后重新解析目标状态。删除来源不计有效反链，恢复后恢复。正文修改、保存、同步及版本恢复后重新查询并防止旧响应串页。
