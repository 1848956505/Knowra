# 知识提炼提示词 A/B 实验结果（第一轮）

> **性质：** 实验记录，不是产品决策。  
> **日期：** 2026-10-15  
> **执行：** 用户本机运行 `scripts/experiments/knowledge-extraction-ab/run.mjs`，Claude 分析结果  
> **模型：** deepseek-chat，temperature 0  
> **样本：** 用户《动手学深度学习》第 1–2 章笔记，按“章.节”切成 10 篇，共约 4 千字  
> **对比：** v1 = 线上 `knowledge-extraction-v1` 提示词原文；v2 = 加入 title 写法指引和“已有知识点标题”上下文的草案，输出契约不变  
> **说明：** 完整报告含笔记原文摘录，留在用户本机，没有提交到仓库。

## 2. 发现

### 2.1 最严重：引文偏移全部不合格，与提示词版本无关

两版共 101 个候选，**没有一个**的 `start/end` 偏移与 `quote` 对得上。按 `validateKnowledgeExtractionResult` 的规则，任一引文不合格即整批拒绝，所以 10 篇笔记会**全部**提炼失败。

但 quote 本身几乎都是对的：103 条引文里有 101 条能在原文中逐字找到，而且每条只出现一次，没有歧义。偏移的误差中位数约 −12 个字符，范围在 −106 到 +56 之间。大模型能准确复制原文，但数不准 UTF-16 下标。

线上提炼目前只跑 Mock（`executionMode: 'mock'`），所以这个问题还没暴露过。一旦接入真实模型，提炼功能会每次都失败。

**建议（与提示词无关，可以单独修）：** 不再让模型输出偏移，改为只输出 `quote`，由服务端在所选片段中定位：唯一匹配就采用；找不到或有多处匹配，则把该候选标为引文无效，而不是整批拒绝。这样，模型不用承担它做不好的事，“引文必须逐字来自来源”的约束也一条都没有放松。

### 2.2 标题：v2 去掉了空泛后缀，但“问题句标题”在 v1 中也没有出现

- v1 有 7 个“机器学习的定义”“范数的定义”这类标题，v2 变成“机器学习”“范数”“梯度”“张量”。
- **两版都没有产生问题句标题。** 用户此前看到的“矩阵和向量如何相乘？”这类结果，在当前线上提示词下用 DeepSeek 没有复现。它们很可能来自另一条路径，比如 Agent / MCP 的知识提议，那条路径用的是另一套提示词；也可能来自别的模型。下一步应该确认来源，而不是假定 v1 提示词是原因。
- 规则判定的“照抄小标题”有误报：v2 的“点积”“范数”本身就是笔记的小标题，同时也是正确的概念名。

### 2.3 粒度：大量 API 用法被当成知识点

2.1、2.2、2.5 节的候选大多是“用 X.sum() 求和”“用 torch.zeros_like 创建张量”这类调用方法。v1 把它们标成 application，v2 按指引改成 process。它们是否应该算作知识点、是否应该挂在概念下，是模型设计问题，这次实验回答不了。

v2 还把“梯度的定义”和“梯度的方向”合成了一条，违反了它自己“一个候选只表达一件事”的规则。

### 2.4 笔记中的错误：一处被悄悄改掉，其余照搬

用户笔记中有几处表述不准确。

| 笔记原话 | v1 | v2 |
| --- | --- | --- |
| 回归：“标签取任意数值时（即标签取离散值）” | 照搬 | **悄悄删掉了括号里的错误部分** |
| `x.require_grad_(True)`（应为 requires_grad_） | 照搬 | **悄悄改成了正确拼写** |
| `x.shape()`（shape 是属性，不是方法） | 照搬 | 照搬 |
| 用 `get_dummies` 处理非数值缺失值，称作“插值法”（实为独热编码） | 照搬 | 照搬 |
| “张量之间叫内积” | 照搬 | 照搬 |

v2 的修改让内容更正确，却违反了跨模型共识第 1.3 条：“保留并标识，不悄悄替换用户原话”。这说明“只使用来源内容”的约束挡不住模型顺手纠错。如果希望保留原话、单独标记存疑，需要在提示词里明确要求，或者在输出契约中增加“存疑说明”字段。

### 2.5 未能验证：去重与复用

这批笔记各节之间重叠很少，v2 的“复用已有知识点”一次都没有触发。要验证去重，需要换一批内容有重叠的笔记，比如同一概念在两章都出现。

## 3. 建议的下一步

| 优先级 | 事项 | 理由 |
| --- | --- | --- |
| 高 | 引文改为服务端按 quote 定位 | 不修，真实模型下提炼必然失败；与知识模型讨论无关，可以立即做 |
| 高 | 确认“问题句标题”的真实来源 | 当前提示词没有复现，避免修错地方 |
| 中 | 采纳 v2 的 title 指引 | 后缀问题被消除，代价是输入 token 增加约 45% |
| 中 | 增加“不纠正原话、单独标记存疑”的规则或字段 | 2.4 节 |
| 低 | 用有重叠的笔记再测一次复用 | 2.5 节 |
