# Concept 粒度三条标准（试行）

> 2026-10-17，Claude。来源：用户与 Claude 讨论“Concept 到底该细到什么程度”，用户同意试行。
> 接续：[Concept 边界与个人粒度评议](2026-10-17_Concept边界与个人粒度评议_Claude.md)。

## 1. 用户的出发点

用户的判断是：一个 Concept 至少要能扩展、能装下多条内容。“非降维求和”有好几条命题，可以单独成为概念；“查阅文档”只有两行代码、一句话就能说清，可以挂到别的概念下面。

Claude 同意这个方向，但做了两处修正：

- **内容多少按命题数算，不按代码行数算。** 很多核心概念一句话就能定义，但能装下很多命题，比如梯度。命题数还会随着笔记增加而增长。
- **不要挂到过于宽泛的概念上。** 例如“查阅文档”不应挂到“Python”下面，否则 Python 会变成杂物抽屉。D2L 那一节讲的是查 PyTorch 的 API，应挂到 PyTorch（或它所操作的对象）下面，作为一条操作类条目。

## 2. 三条标准

1. **能独立命名，含义稳定**：它是一个对象、运算、方法、机制或现象。这一条是前提。
2. **能承载多条独立的知识**：不只是一两句用法。这一条对应用户提出的“可扩展”。
3. **会和其他概念发生关系**：作为前提、组成部分、对比对象，或被其他概念引用。例如保留维度求和（keepdims）存在的意义，就是让结果能和原张量做广播。

AI 默认在满足第 1 条、并且满足第 2、3 条中至少一条时才新建概念；不满足的，作为条目挂到它所描述的概念上。

同时明确三类类型错误：

- 两个概念之间的**关系**不建概念，比如“机器学习与深度学习的关系”。
- 两个概念的**比较**不建概念，比如“向量的维度与张量的维度”。
- **小标题不是概念名**，比如“节省内存”“矩阵与向量的积”。概念名用规范术语，同一主题也不按参数拆成多个概念。

## 3. 配套原则

- **标准只决定 AI 的默认行为，最终由用户决定。** 条目周围积累了几条相关命题后，系统可以提示“要不要升级成概念”；概念也可以降级为条目。升级、降级都要容易做，粒度第一次定得不准也能改。
- **自检问题：** 打开图谱时，你会想去点这个圆点吗？不会的话，它就不该是圆点。
- 这套标准不改变上一篇评议的立场：是不是概念只看语义，用户学不学、关不关注是概念上的个人状态。

## 4. 落地到实验

`scripts/experiments/concept-linking-r2` 做了以下改动：

- 提示词加入三条标准和三类类型错误，仍然不点名任何具体概念。
- 新增 5 篇合成笔记：
  - R10：工具用法，应挂到 PyTorch，不挂到 Python，也不单建概念。
  - R11：两个概念的关系。
  - R12：同一个词在两处含义不同的比较。
  - R13：小标题是“节省内存”，概念名不应照抄。
  - R14：保留维度求和，可以新建概念，但不应拆细。
- 评分新增“类型错误”“名称照抄标题”和 R14 新建概念数。
- 修正一个评分问题：同一篇笔记里几段原文共享代码片段时，一条链接会同时算到多段原文上。现在每条链接只归给重合度最高的那一段。
- 输出不是合法 JSON 时，同一请求重试一次。

验证分两步：先跑 GitHub 上的合成实验（42 次调用），再由用户在本机对真实笔记运行 `run-local.mjs`，看重跑后的概念清单里，上一轮那 5 个类型错误是否消失，原来 20 个合格的概念是否保住。

## 5. 第一次合成运行（Actions 39005096794）

| 用例 | 结果（3 次） |
| --- | --- |
| R11 关系 | 3/3 作为条目挂到“深度学习” |
| R12 比较 | 2/3 作为条目挂到向量/张量，1/3 新建了“维度” |
| R13 小标题 | 3/3 命名为“原地运算”，没有照抄小标题 |
| R14 保留维度求和 | 3/3 没有新建概念，挂到“张量”和“广播” |
| R10 工具用法 | 3/3 挂到 Python，不是预设的 PyTorch |
| **R04 x.grad** | **3/3 挂到数学“梯度”，属于污染（引入规则前为 0）** |

规则修好了类型错误，但矫枉过正：模型把“不满足就挂到别处”理解成了倾向挂靠，在 x.grad 上踩回了最不该踩的污染，模型自述是“含义依附于梯度，未新建”。R14 也偏保守，没有建出用户认为应该独立的“非降维求和”。

调整：

- 提示词补一条判断顺序：先判断有没有同一个概念；粒度标准只决定“建成概念还是作为条目”，不能作为挂靠理由；作为条目时只能挂到它真正描述的那个概念上，候选里没有就新建它。
- R10 的预期改为挂 Python 或 PyTorch 都可接受。dir/help 本身是 Python 内置函数，模型的理由成立，原预期是 Claude 设计的问题。
