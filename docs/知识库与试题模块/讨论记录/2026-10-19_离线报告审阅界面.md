# 离线报告审阅界面（实验）

## 边界

概念图保留合成演示入口，新增“离线报告审阅（实验）”独立弹窗。只接受共享 `@study-accelerator/shared/incremental-review` 的 version 1 envelope，不导入旧实验图格式或审阅草稿。报告标签/快照引用不认证来源，结构与内部一致性检查不代表事实可靠或可写入。

- 文件仅浏览器内存读取，读取前检查文件字节数，读取后再次由共享纯解析完整验证。不接 API、store、localStorage、IndexedDB，不生成知识资产。
- 逐行展示原文、模型响应状态与逐条提案、候选概念/旧条目、原始风险及依赖。风险、无效和 reuse 提案只可待定；只有未被扣留的 itemAction=new 可归属或另建。无候选/多候选不默认选择。
- 完整无提案响应、损坏/不完整响应、模型调用失败分别显示。解释是未核实的模型意见，不称为原生弃权。
- 所有内存决定可撤销，待定与未决定分开。替换/重置/关闭会丢失决定时先确认；取消、解析失败或超限保留旧报告与决定。每次新文件意图、取消读取、关闭/卸载均使旧异步读取失效；重选同文件可重试。
- 下载前提醒包含原文、模型响应和候选旧内容；用共享序列化器再次验证，保存完整未授权草稿，不自动写入或上传。保留已选/待定/未决定，不清空会话，拒绝超限而不截断；固定安全文件名，回收 Blob URL。

## 实现

`graph/report-review/` 按会话编排、行展示、提案决定、异步文件读取、下载和样式拆分。UI 不维护另一份验证算法。采用项目 Dialog/Button/TextField/TextAreaField；原概念图仅增加入口、挂载与 Esc 隔离。

## 验证

单元覆盖共享契约调用、无候选/多候选、风险/依赖/无效/reuse、状态区分、导入/重置/关闭确认、失败保留、下载内容和会话、键盘与焦点、原图 DOM 与选择不变、无网络/持久化、大小前检/后检、慢 A 不覆盖 B、取消/卸载迟到以及重复文件。

`e2e/incremental-report-review.spec.ts` 纳入 mobile-evidence 入口，在 1440 与 390 宽度使用纯合成 fixture（含合法长 ID/名称），检查报告标签/原文/候选/新建/草稿警告截图，以及混合报告的风险、reuse、无效提案只能待定和无提案/响应损坏/调用失败分别展示，覆盖键盘焦点、草稿实际下载、重复导入、失败恢复、关闭确认、原图隔离、零请求/持久化和横向溢出。

当前本地浏览器证据受环境限制：配置要求的 Chrome 不存在；备用系统 Chromium 在保持 sandbox 开启时因 Unix socket `Operation not permitted` 启动失败。没有关闭 sandbox，也没有截图或浏览器行为通过结论；这些 E2E 须由可启动浏览器的后续 CI 补验。
