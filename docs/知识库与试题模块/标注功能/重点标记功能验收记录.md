## 1. 本次落地

- 新增 `packages/content-anchor`，以 Markdown 原文 UTF-16 半开区间、结构路径和 projection version 作为统一定位契约；重复文本只有候选唯一时才自动重定位。
- ContentAnnotation 增加 `scopeType`、五类 `kind`、`importance`、`comment`、`lifecycleStatus`、`anchorStatus`、`revision`、`originSnapshot` 和内容／边界摘要；旧 schema v1 转为待检查，不冒充可靠新坐标。
- local-json 和 PostgreSQL 均增加 AnnotationExclusion、AnnotationRevision、AnalysisScopeSnapshot；写入通过各驱动事务入口执行。
- V4 检查器接通选区、当前块、当前标题章节，以及类型／章节／状态筛选、多选、备注与重要性、取消／恢复、重定位、预览、真实关联数量、章节持久排除和分析范围预览。
- 分析范围在服务端去重、减去持久／单次排除并固定为不可变快照；真实 AI 不可用时只报状态，不生成假候选。

## 5. 未完成与未验证

以当前证据，本次不能宣布开发方案 A→F 全部完成，也不能宣布 FR-M01—M08 端到端验收通过。明确缺口为：

1. 无 `POST /annotations/:id/confirm-range` 与对应新／旧边界确认页面。
2. 无文件夹／标签范围展开清单和真正多笔记选择 UI；无标注时的临时选区／章节发起页面也未完整接入。
3. 无批量取消的项目确认弹窗，也没有标题边栏／大纲直接标记入口。
4. 同会话 transaction mapping、块拆合／复制／移动继承、相邻多块提升边界确认未完整落地。
5. 真实 PostgreSQL 迁移、事务故障注入、并发和重启未验证；不能用 mock repository 代替。
6. 真实 AI 提炼、候选确认／回链和下游知识—试题闭环未接入。
7. 真实 Safari 中文 IME 、实际窄屏长备注／长表格及重叠标记命中交互未验证。

因此本记录的准确结论是：**基础数据契约、三种创建入口、单笔记统一清单、局部排除和分析范围快照已落地；完整 A→F 与真实 AI／PG 验收未完成。**
