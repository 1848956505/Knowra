## 1. 已实现行为

- 普通有序、无序列表使用独立 `scopeType: 'list'`，覆盖当前项全部正文、续段、嵌套内容及所有后代项，不含同级邻项。点击子项以最近列表项为根；任务列表没有新入口。
- 正常正文编辑、首尾追加和新子项自动跟随。编号／类型变化、前面新增同级项不依靠文字、编号或旧下标换绑。
- 既有外部成员归入、子项移出、父项关系变化和不可证明的拆合进入待确认；提供当前完整子树候选，继续编辑保留待确认。确认核对修订、正文哈希及候选摘要。
- 删除根项保留历史并进入原文已删除；同文重输不复活。空项结构仍存在时保留既有重点，重新输入跟随；空项不可新建／分析。退出列表或改成任务项不阻断正文保存，无合法候选时不能确认。
- 验证过的一次性同笔记剪切／粘贴日志保留结构身份；复制获得新身份。归档期间正常编辑后恢复，核对当前结构，不用文字相似恢复已删除根。
- 父、子重点独立管理、定位及分析去重；列表项支持局部排除与恢复。排除内容移出子树后保留冲突，即使确认父范围也不能静默忽略。
- 列表范围保存为 schema v2，服务器生成结构身份，保留原 ID、备注、重要级、不可变来源快照与关联知识证据。导入拒绝伪造根身份；重新选择来源也必须提交完整列表项，不能降为选区。
- V4 菜单捕获并映射操作目标；光标缓存随事务同步更新，避免检查器恢复旧位置。创建重试复用幂等键，保存期间的新输入保留。范围筛选使用共享分段控件，长列表首行滚出视口后入口仍可操作。
