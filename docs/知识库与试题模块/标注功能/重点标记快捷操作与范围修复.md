# 重点标记快捷操作与范围修复

日期：2026-10-04。以本期要求覆盖旧方案的新建默认未评级约定。

- 新建默认 `kind=important`、`importance=normal`。选区工具提供普通、重点、核心三个直接创建入口；块和章节通过共享悬停子菜单选择等级，独立列表项标注入口保留。
- 右侧卡片右键复用更多菜单的预览编辑、知识候选、重选来源、局部排除及取消重点。禁用条件和删除后撤销共用同一实现。
- 历史 `importance=null` 不批量修改，不再显示待评级；详情无未设置选项。只编辑备注保留原值，用户明确切换等级才更新。API 保留显式 null 兼容与幂等请求；建议后续由用户决定是否提供显式历史评级整理。
- 版本化摘录保留首尾空白，创建和重新定位继续检查当前正文 hash、保存版本、完整 anchor 和精确摘录；旧 schema v1 保留原裁剪语义。
- 章节按标题顺序、级别、文本和边界构建锚点，创建和重开复用编辑器规范 Markdown 的共享投影，按准确投影偏移绑定标题顺序并核对完整章节文本及下一标题边界，不再手工累计编辑器字符。Markdown 引用定义被编辑器省略或正文含 HTML 与既有行内标记时，重复同名同文章节仍保持各自身份。编辑器空段和分割线不作为 Markdown 文本；代码内换行保留。同级标题终止章节，不把缺失上级标题的相邻章节合并。

## 验证与边界

合成回归覆盖 Markdown 分隔空白与编辑器空段对照、长纯文本与混合结构对照、七个同级标题与二级父标题对照、引用定义、HTML、既有行内标记与重复章节保存重开、代码首尾/内部空行与重复块、伪造摘录和旧版本拒绝、等级与幂等重试身份、即时编辑、保存重开、撤销重做及菜单焦点变化。代码增行保留标注 ID、备注、等级和知识关联，历史知识依据保留原版本并转为待核对。正式 API runner 注册新用例；生产页面使用临时 JSON 数据目录，不读取用户数据。

## 引用功能待讨论

本期未实现新增引用。现有编辑器 `[[文本]]` 仅是标记；领域从中提取字符串并按笔记 ID 查找，右侧基于已加载笔记计算出链和反向链接。它尚不构成完整目标选择、标题别名、跨空间或缺失目标处理方案。

需要先对齐：链接目标是整篇笔记还是章节/块；以 ID 还是标题/别名展示；重名、改名、删除/恢复和跨空间如何处理；是否新增输入联想、目标选择、点击跳转与新建入口；反向链接展示引用位置还是仅来源笔记。需求确认后再生成计划并开发。
