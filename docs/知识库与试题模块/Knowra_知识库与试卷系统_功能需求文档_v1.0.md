# Knowra 知识库与试卷系统功能需求文档

**版本：v1.0｜日期：2026-09-09｜状态：功能评审建议版，尚非已确认冻结版本**

**目标：把学习资料变成可探索的知识网络，并通过试卷、批改和复习了解自己的掌握情况。**

本文件包含原稿审查结论、建议补充的功能规则、用户操作流程和验收标准。不规定接口、数据库、框架、模型供应商及编程实现，也不判断现有代码已经实现了哪些功能。

## 0. 阅读说明与依据

主要依据为《Knowra 知识与考卷系统领域冻结稿》（下称 **F1**），重点核对其第 1—5、7—10 章。辅助依据为《学习加速器项目总控文档》（**F2**）的产品目标，以及《前端开发规范》（**F3**）的内容优先、渐进展开原则。

本次新增目标来自用户：**同时完成可视化知识库与 AI 试卷—答题—判卷—掌握评估系统。**

全文使用三类结论：**保留**表示原稿已有且建议延续；**细化**表示原稿已有概念但缺少操作与判定规则；**新增／调整**表示本次提出的产品建议，不冒充原稿已经确定的要求。第 4—14 章是建议采用的完整功能规格，其中没有原稿直接支持的具体行为，均属于本次补充设计。

本文件中的示例仅用于说明产品行为，不是经实测的效果证明；掌握状态是能力估计，不是心理测量结论。文末提供原稿章节对照。

## 1. 审查结论：主链路成立，功能规格尚未完整

### 1.1 总体判断

**原稿的领域主线是合理的，应保留，不需要推倒重来；但它还不足以直接充当完整的功能需求文档。** 它较好地解释了“有哪些对象、它们各自负责什么”，尚未充分回答“用户具体如何操作、AI 必须产出什么、异常如何处理、做到什么程度才算完成”。

原稿已明确：标注不是唯一入口；知识点与学习目标分离；考试考点可选；题目关联学习目标；批改先形成学习证据，再影响掌握状态；自评与系统评估分开；历史试卷保持稳定；低置信度批改允许复核。这些是本次保留的核心。[F1 §2.2—2.5、§3.12—3.23、§9]

原稿第 7 章的第一版范围是“快速练习闭环”，明确不做全局知识图谱、复杂组卷等。因此，**原稿第一版完成，不等于本次两个最终目标完成**。本次不把后续能力倒称为原稿第一版已有功能，而是在第 15 章定义新的“目标达标版”。[F1 §7—8]

### 1.2 逐项审查

| 审查项 | 原稿覆盖程度 | 本次结论及需要补齐的内容 |
| --- | --- | --- |
| 主链路 | 已明确知识、目标、训练、证据、复习 | 保留；页面可以简化步骤，但不能跳过可评测目标 |
| 重点标记 | 有标注类型与来源位置 | 细化选区、内容块、标题范围、嵌套、排除与编辑后的变化 |
| AI 提炼 | 有分析范围、候选态、来源关系 | 细化输入、上下文边界、输出质量、去重、冲突、确认和增量更新 |
| 知识点管理 | 有核心陈述、来源、多对多关系 | 细化知识详情、主题组织、合并拆分以及对历史的影响 |
| 学习目标与考点 | 分离关系正确 | 细化可评测程度、默认呈现、考试依据和优先级来源 |
| 知识图谱 | 有知识点与六类关系 | 细化探索与训练操作；笔记节点图谱属于新增范围 |
| AI 组卷 | 有试卷蓝图与题目快照 | 细化覆盖预览、题量不足、替换题、审题与答案泄露问题 |
| 在线答题 | 有训练过程、答案、提示记录 | 细化续答、计时、交卷、空题、重复训练及失败恢复 |
| 批改 | 有评分结果、评分细则与人工复核 | 细化逐目标归因、争议、错题作废与重评联动 |
| 掌握情况 | 有目标级评估和证据权重原则 | 细化未测状态、覆盖范围、证据不足与复习提醒的区别 |
| 复习 | 有复习类型及安排 | 细化错题、原文、变式题、重新评估的实际闭环 |
| 历史与变更 | 有来源失效、快照等保护 | 细化“定位丢失”和“内容错误”不能混为一谈 |

### 1.3 必须优先解决的四个功能风险

**风险一：把知识点标题直接当成考点。** “梯度下降”不是可评分要求；“能根据给定梯度完成一步参数更新”才是。否则题目看似相关，结果却无法解释用户具体会什么。[F1 §2.3、§3.9]

**风险二：一题考多个目标，却把整题得分同时写给所有目标。** 原稿支持一题多目标，但尚未细化得分归因。需要在评分细则中分清各目标对应的证据；无法分开时，不应制造精确掌握结论。

**风险三：用户为审核试卷先看完答案，再被系统当作独立测试。** 原稿已有“查看参考答案”的记录，但还需覆盖生成、审题阶段。默认自测流程应隐藏答案；看过答案的题仍可学习，但不能当作全新独立测试。

**风险四：把所有状态挤进一个掌握标签。** 原稿把“待复习”与“已掌握、薄弱”等并列。建议调整为：能力状态、证据充分度、复习提醒分别显示。一个目标可以同时“基础掌握、证据有限、今天待复习”。[F1 §3.20]

## 2. 产品目标、概念与完整链路

### 2.1 两个最终成果

**成果 A：可视化知识库。** 用户能查看资料和知识之间的联系，理解连接理由，从图中进入原文、知识详情、学习目标和训练。知识列表与图谱使用相同内容，不要求用户再维护一份“图谱专用笔记”。

**成果 B：试卷与掌握评估。** 用户能选择范围，让 AI 生成可作答的试卷，完成答题，获得可核对的逐题反馈，知道哪些能力已测、哪些未测、哪些需要复习，并进入下一次训练。

### 2.2 用户可理解的概念

| 概念 | 回答的问题 | 举例 |
| --- | --- | --- |
| 笔记 | 原始资料写了什么？ | 《梯度下降学习笔记》 |
| 重点标记 | 我希望关注哪段内容？ | 一段参数更新说明 |
| 知识主题 | 这些知识如何组织？ | 优化方法 |
| 知识点 | 这是什么知识？ | 梯度下降的一步更新规则及适用说明 |
| 学习目标 | 我需要能够做什么？ | 能按给定梯度计算更新后的参数 |
| 考试考点 | 某个考试特别强调什么？ | 在指定考试范围中优先训练参数更新计算 |
| 题目与试卷 | 用什么任务检验能力？ | 给出参数与梯度，要求计算下一步结果 |
| 掌握情况 | 已有哪些表现能支持能力判断？ | 计算题表现稳定，原理解释尚未测试 |

“知识点／考点”不能长期混作同义词。普通学习只需知识点和学习目标；只有选择特定考试场景，才增加考试考点。[保留；F1 §2.1—2.5]

### 2.3 建议采用的完整链路

资料与笔记 → 选择分析范围（可以用重点标记） → AI 提炼知识候选 → 用户确认知识与学习目标 → 建立或确认知识关系。

此后形成两条相连的路径：

**知识探索路径：** 知识列表／知识点图谱／笔记图谱 → 找到相关材料与薄弱能力 → 阅读、整理或进入训练。

**训练反馈路径：** 选择知识与学习目标 → 可选考试配置 → 确认出卷方案 → AI 出题与组卷 → 答题 → 批改与必要复核 → 形成学习证据 → 更新掌握情况 → 安排复习与变式训练。

用户也可以不标重点，直接分析选区、章节、整篇笔记，或手动创建知识。阅读和知识整理不要求先建考试配置。[保留；F1 §2.2]

### 2.4 三条默认体验原则

**普通操作轻，关键确认明确。** 用户不必依次进入知识、目标、考点、题库等多个页面；允许在一个候选面板完成知识与目标的联合审阅。

**先忠实于来源，再允许扩展。** 默认不在原文缺失处偷偷补充外部知识。扩展必须单独启用、清楚标注，并重新确认。

**AI 辅助不等于事实已经成立。** “生成成功、用户采用、事实已核实”是不同含义，页面应保留区别。[保留并细化；F1 §9；F3 后端规范 §15]

## 3. 功能范围与默认决策

### 3.1 本次目标达标版必须包含

本版目标包含：三种重点标记；选区／章节／笔记／多篇范围提炼；知识与学习目标确认；基本知识管理；知识点图谱与基础笔记图谱；AI 快速练习与基础正式试卷；在线答题；逐题批改与复核；目标级掌握情况；错题与复习回链。

“正式试卷”在本文件中指题目、顺序、分值与作答记录稳定的一份个人测试，不表示官方考试、认证测评或具备监考能力。

### 3.2 后续增强，但不阻塞两个核心成果

大规模全局图谱、自动学习路径推荐、自动分析历年试题、复杂多考试映射、自适应测验、复杂遗忘模型、多模态题目自动评测、代码自动运行、试卷打印及批量导入导出，均可后续扩展。知识库问答也不是完成两个核心成果的必经步骤。

### 3.3 本次明确不讨论

多人协作、登录方式、服务器性能、本地云端同步、部署、接口、存储模型、前端框架和 AI 服务调用实现，均不属于本文件范围。这不表示它们不重要，仅表示不把它们混入本次功能审查。

## 4. 重点标记与分析范围

**原稿基础：F1 §2.2、§3.3—3.4、§8。以下操作规则为细化与新增。**

### FR-M01：选区重点

用户选中一段连续文字后，使用浮动菜单、右键菜单或快捷操作“标为重点”。保存后仍可查看原文、修改备注、更换标注类型、撤销重点、提炼该内容。一次点击即可完成默认标记，不强制填写标题或说明。

一次标记只覆盖明确选中的连续内容。多个不连续片段可以分别标记，在“重点清单”中多选后一起分析。普通加粗、着色和格式高亮不自动等于“用于知识提炼的重点”。

### FR-M02：内容块重点

用户可将一个或多个相邻内容块设为重点，包括段落、列表、引用、代码、公式和表格。标记只是附着在原内容上的重点属性，不把正文复制成第二份，不改变代码、公式或表格的原有含义。

“重点块”可以采用边线、图标或轻量背景呈现，但不应借用真正的代码块语法存放普通重点。用户取消重点后，原内容及原格式保留。整块标记随该块后续编辑变化；仅选中代码中的部分内容时，允许提示“仅分析选区”或“连同整段代码作为上下文”。

### FR-M03：标题范围重点

用户在标题旁或大纲中选择“将本节设为重点”。范围为该标题及其正文、下级标题内容，直到下一处同级或更高级标题之前；不会只标记标题文字。

例如，将某个二级标题设为重点，会包含其三级、四级小节，不包含下一处二级标题。页面应显示该节已被标记，支持“预览覆盖范围”。

标题范围默认动态跟随：之后在本节新增的内容自动纳入；本次 AI 分析仍固定使用开始分析时的内容。修改标题层级、拆分章节或移动内容导致覆盖边界改变时，要提示范围变化，不能悄悄扩大到整篇笔记。

### FR-M04：三种标记共用一种重点语义

三种方式最终都出现在同一重点清单，使用相同的“提炼知识”入口。它们不是三套不同知识来源，更不意味着三个重复知识点。

范围重叠时，分析内容按实际覆盖去重；原标注及用户备注仍分别保留。一个标记可产生多个知识点，多处标记也可共同支持一个知识点。[保留多对多原则；F1 §3.7]

支持“从本次分析排除这段”，也可保存为标题重点的局部排除。显式排除优先于继承的标题范围；若用户直接分析被排除的选区，应明确提示并由本次操作重新纳入。

### FR-M05：标记类型、重要性与考试优先级分离

保留“重点、疑问、补充、易错、临时笔记”等类型。疑问表达用户不确定，不得把疑问里的猜测直接提炼成正确结论；易错标记也不等于系统已有证据证明用户薄弱。

默认只标类型，不强迫填写重要程度。需要时可设置普通／重要／核心。该优先级用于提炼和训练建议，不自动变成某个考试的高频考点，也不直接改变掌握情况。

### FR-M06：重点清单与处理状态

笔记中提供重点清单，可按类型、章节及处理状态筛选。每条显示原文摘要、范围类型、备注及“未提炼、已有候选、已关联知识、内容变更待检查”等状态；点击可定位原文或查看产生的知识。

撤销或删除标记不删除已确认知识、不撤销历史试卷。用户主动归档相关知识时另行处理。只标记、不启动分析，不会自动调用 AI，也不会自动增加知识库内容。[保留并细化；F1 §3.3、§9]

### FR-M07：来源变化的可见处理

标注位置可靠时，继续定位到原文。无法可靠定位时显示“原文位置需重新确认”，保留生成时的摘录，允许用户重新选择来源；不跳到一处看似相似却未经确认的文本。

“位置失效”不等于“知识错误”。仅排版变化可确认原知识仍有效；原文论点或公式变化应比较差异，提示相关知识待检查；删除唯一来源时显示“来源不足”。后续是否允许出卷，按第 13 章统一规则处理。

### FR-M08：没有重点也能使用

支持提炼当前选区、当前章节、整篇笔记或选定的多篇笔记。选择文件夹或标签时，先展示本次实际纳入的笔记清单；之后新加入的笔记不自动改变已经开始的分析。

分析范围有两种默认模式：“只提炼已标重点”与“分析所选全部内容”。前者允许读取必要上下文来解释重点，但不把未选内容自动增加为新的正式知识或考查范围。

## 5. AI 提炼知识与人工确认

**原稿基础：F1 §3.4、§3.6—3.7、§5.1、§7。以下为输入、产出与操作规则的细化。**

### FR-K01：分析前确认范围

点击“提炼知识”后，展示来源笔记、所选章节／标注、分析模式及已有相关知识。默认保留上次常用偏好，不要求每次重新配置大量选项。

用户可补充一句要求，例如“重点提炼计算方法”“保留公式适用条件”“不要把示例中的每一行代码拆成知识点”。提炼颗粒度提供“概要、标准、细分”，默认标准，不要求用户指定必须生成几个知识点。

图片、附件或复杂格式只有确实被读入时才能作为已分析来源。不可识别内容必须列出并说明“尚未纳入”，不能仅凭文件名或图片描述声称理解了正文。

### FR-K02：分析范围与阅读上下文分开

AI 可读取标题层级、必要的前后段落、指代对象、代码所依赖的相邻定义，以理解所选内容。新增知识的范围仍受用户选择约束。

当重点只有“它解决了上述问题”等无法独立理解的片段时，应请求扩大上下文或标记“来源不足，暂不形成正式候选”，而不是编造对象。未选章节可作为引用上下文，但不能因此被偷偷加入试卷考查范围。

### FR-K03：知识候选的完整内容

每个候选至少提供：明确标题；能够独立理解的核心陈述；来源摘录与笔记位置；必要前提、限制或适用条件；建议学习目标；可能重复、冲突或不确定的提醒。

可选内容包括知识类型、主题建议、关键例子、公式符号说明、关联知识建议和建议重要性。解释应围绕来源，不以“写得越长越好”为目标。用户自己的理解单独保存，AI 不覆盖原有个人解释。

合格颗粒度是“一个相对独立的概念、规则、过程、算法、公式或比较”。目录标题不直接当作知识点；不同来源对同一知识的说明，不应仅因措辞不同就拆成多个节点。[保留粒度原则；F1 §3.6、§10]

### FR-K04：先核对知识，再选择处理方式

候选面板同时展示生成内容与来源，支持逐条或批量“确认、修改后确认、暂存、忽略”。存在来源缺失、实质冲突、含糊陈述或明显重复的候选，单独列入待处理，不混入无提示的“一键全部确认”。

用户可以在同一面板确认知识与其学习目标，避免重复跳转。用户也可只确认知识、暂不采用目标；此时知识可以进入可视化知识库，但不能进入要求正式目标的出题范围。

未确认候选默认只在候选视图中出现，不混入正式知识图谱。明确忽略的候选，在相同来源没有实质变化时不反复弹回。

### FR-K05：相同、互补和矛盾的内容分别处理

分析前后均检查已有知识。相同内容建议“关联到已有知识”；互补内容建议“增加来源或说明”；确有新语义才建议新建；矛盾内容同时展示两种表述、适用语境及各自来源，请用户决定后续核对方式。

自动判为相似只是一条建议，不能直接合并。名称相同但语境不同的概念应保留区别。多个来源相互引用也不代表已经完成独立核验。

### FR-K06：来源中的错误与 AI 扩展

默认采用“忠实提炼”：保留原文实际支持的内容；疑似错误需显式提醒，不能悄悄改写成 AI 认为正确的版本。用户可以选择补充可信资料、修改原笔记、保留为争议知识或暂不确认。

可提供单独的“允许扩展解释”模式。扩展部分清楚标记，不伪造原文引用；没有可核对来源的模型补充不自动成为“已核实知识”。用户明确采用时，保留“AI 补充／人工确认，尚无外部核验”的来源提示。真正新增的外部知识仍需独立确认后才纳入目标和出卷范围。

### FR-K07：重新提炼与增量更新

重新分析时展示“新增、建议修改、建议关联、没有变化、来源冲突”，而不是每次生成一整套平行知识。已确认的个人编辑不会被重跑结果直接覆盖。

来源分析途中被修改时，结果显示“基于分析开始时版本”；采用前提示与当前正文的差异。单篇失败不应丢弃其他篇已完成的候选；重试可只处理失败部分。

### FR-K08：手动创建和脱离 AI 的使用

用户可自行填写标题、核心陈述、主题与学习目标，并添加来源。纯手动知识允许保存，但必须显示“人工整理，未附引用”，不能表现为系统已验证。用户明确确认后可用于个人训练，出卷及报告保留其来源风险提示。[保留并细化；F1 §2.2、§9]

AI 不可用时，仍可阅读与管理已有知识、使用已有题目、查看历史报告；不以模型调用失败阻塞笔记使用。

## 6. 知识管理、学习目标与考试考点

**原稿基础：F1 §3.5—3.11、§5.2。保留概念分离，细化日常使用。**

### FR-O01：知识列表与详情

知识库提供候选、已确认、待修订及归档视图；支持按主题、来源笔记、标记类型、掌握情况、是否具备学习目标进行搜索和筛选。

知识详情默认显示核心陈述、来源、学习目标和最近训练情况；个人理解、历史变化、关系编辑按需展开。用户可从来源回到笔记，也可从笔记查看其产生或支持的全部知识。

知识主题用于课程、学科和章节组织，一个知识点可属于多个主题。主题目录中的从属不自动等于“两个知识概念之间的组成关系”，更不自动证明学习先后顺序。

### FR-O02：编辑、合并、拆分与归档

用户可以修改标题、陈述、个人解释、主题和来源。只改错别字不要求废弃所有关联；改变核心含义时应提示检查学习目标、相关题目和关系。

合并前展示来源、目标、题目、关系及训练记录的影响清单；重复来源和重复证据不能累计为双份掌握依据。拆分后，旧题只有在能确认考查新目标时才重新关联，不能把旧掌握状态复制给每个新节点。无法可靠归属的旧证据保留历史，不强行加入新目标评估。

归档默认从未来选题与常用图谱中隐藏，但保留历史回链。删除主题只改变组织，不连带删除主题中的知识。恢复归档内容前应重新检查来源和目标是否仍然有效。

### FR-O03：生成可评分的学习目标

知识确认时可同步生成目标建议。每个目标描述一个可观察动作，必要时包含条件和完成要求。例如“给定输入尺寸、卷积核大小、步长与填充，能计算输出尺寸”，而不是“掌握卷积”。

默认只生成来源支持、实际有必要的目标，不强行给每个知识点配满“记忆、理解、应用、分析”四种层级。用户可合并重复目标、拆开过大的目标、调整要求或补充自己的目标。[保留认知层级；F1 §3.9]

形式层面的认知层级不自动等于题目难度。基础应用题可能比某些复杂记忆任务更简单；出卷时分别表达“考查能力”与“预计难度”。

### FR-O04：目标确认与出题资格

已确认知识、已确认学习目标、可解释的来源状态，是正式选题的基本条件。目标暂缺时，系统明确提示“还没有可以用于出题的目标”，允许同页补充，而不是悄悄根据标题随便出题。

知识被实质修改、目标要求发生变化时，受影响目标进入待检查状态；历史题目和作答不随当前修改而改变。纯阅读、手动自评、在图谱上移动节点，不使目标自动达到“已掌握”。

### FR-O05：考试配置与考试考点

日常训练不要求创建考试配置。需要针对具体考试时，用户选择考试名称、目标范围、语言、常见题型、计划难度与考试说明；可上传或关联自己提供的大纲和历年材料。

系统在已有学习目标上形成考点建议，显示优先级、题型倾向及依据。“用户认为重要”“材料中明确列出”“AI 建议优先练习”必须区分。没有大纲、历史题或其他可核对依据时，不把 AI 推测写成“官方重点”或“高频必考”。

同一知识可以用于不同考试，不复制另一套知识点和掌握记录。考试要求确实增加新能力时，先补充并确认学习目标，再将其纳入该考试；不能只改考点说明便偷偷增加新考查要求。

## 7. 可视化知识库：两个视图，一个内容体系

**原稿基础：F1 §2.7、§3.8、§10。知识点图谱是细化；笔记图谱与跨视图联动是新增。**

### 7.1 推荐结论

**两种节点方式都保留，但不把所有节点默认混在一张图中。** 默认提供“知识点”与“笔记”两个切换视图：前者是学习、训练和能力反馈主视图，后者是资料整理与来源探索视图。二者通过来源关系相互跳转。

| 视图 | 节点与连接 | 主要用途 |
| --- | --- | --- |
| 知识点图谱 | 知识点；已确认的知识语义关系 | 看概念结构、先修知识、比较关系及薄弱能力 |
| 笔记图谱 | 笔记；明确引用、人工关联、共享知识等连接 | 找资料、梳理参考关系、发现可合并或对照的笔记 |
| 局部来源展开 | 当前知识及其来源笔记，或当前笔记及其知识 | 从结论回到依据，不默认铺开全部混合节点 |

笔记可能包含很多知识，也可能暂时没有提炼任何知识，仍应能在笔记图谱中存在。知识点也可以有多篇来源，不被强制归属某一篇“主笔记”。

### FR-G01：知识点关系的建立

用户可在知识详情或图中建立关系；AI 可提出带理由的关系候选，由用户逐条或批量确认。默认仅显示已确认关系，候选关系只在显式开启“关系建议”时以不同形式显示。

沿用原稿六类：组成／属于、先修于、对比、导致、应用于、相关。每条关系可查看含义、方向、理由和来源；“相关”不自动解释成因果或先修。[F1 §3.8]

涉及语义判断的连接不因关键词重复就自动确认为事实。明显循环的先修关系、自己指向自己的关系、互相矛盾的方向，应提示用户检查，而不是把它们用于自动学习路径。

### FR-G02：笔记连接的来源

基础笔记图谱至少支持明确的笔记引用及用户手动添加的关联。还可从“多篇笔记支持同一已确认知识”生成可展开的“共享知识”连接，并列出共享的具体知识点。

共享主题、相同标签、文字相似仅可作为可筛选的组织关系或推荐线索，不与真实引用混淆。“引用”保留方向，“共享知识”不强行指定方向。

笔记引用和人工关联应在笔记详情也可查看、编辑，不成为只能在图里维护的孤立关系。这是原稿仅定义知识点关系之外需要补充的笔记侧功能。

### FR-G03：图谱探索与阅读

支持搜索定位、缩放、拖动、选中节点、查看邻居、按关系类型筛选、按主题或笔记范围筛选。打开某一知识时优先显示它的一层邻居，再由用户继续展开。

节点过多时先展示局部，不自动把全部内容挤成不可读的一团。没有关系的知识显示为独立节点，不为了视觉饱满让 AI 硬造连接。图谱不可用或不适合当前屏幕时，提供内容相同的列表视图。

移动节点仅改变布局，不移动原笔记、不改变主题归属或知识关系。删除连接也不等于删除节点；归档节点应说明对后续训练的影响。

### FR-G04：掌握情况与训练联动

知识节点可显示“未评估、学习中、基础掌握、熟练掌握、薄弱”等摘要，另显示证据有限或待复习提示。状态来自关联学习目标，点击可见哪些已测、哪些未测，而不是一个缺乏解释的颜色。[保留目标聚合原则；F1 §2.5]

笔记节点只汇总其关联知识的训练覆盖情况，例如“已关联 8 个目标，已测 3 个”；不能因读过该笔记或其中一道题答对，就标为“整篇掌握”。

用户可选中一个知识、若干节点或某个主题后选择“生成练习／试卷”。生成前重新确认实际纳入的目标；图中相邻知识、先修知识或未确认节点不自动扩入考查范围。

### FR-G05：双向回链与候选管理

点击知识可查看来源笔记及相应片段，点击笔记可切换到它支持的知识集合。共享知识连接展开后可继续进入具体知识，不跳到不相关页面。

来源待检查、关系待确认与能力薄弱是不同状态，应能分别筛选。全局图谱与关系数量增长属于后续增强，不影响基础局部视图成为可用的知识库。

## 8. 题目生成、题库与正式组卷

**原稿基础：F1 §3.12—3.15、§5.3、§8—9。以下是从概念到可用试卷的功能细化。**

### FR-E01：统一训练入口

用户可从笔记、重点清单、知识详情、主题、图谱或错题页进入出题。系统将所选范围展开为具体知识与已确认学习目标，显示可用、待确认、来源待检查及不能出题的数量。

入口可以显示“根据本篇出卷”，但不能暗中省略知识与目标确认。如果尚无知识或目标，允许在同一向导中完成提炼与采用，再继续组卷。

### FR-E02：快速练习与正式试卷

快速练习面向即时巩固，默认少量题目、可选不限时，允许按题查看反馈。正式试卷面向阶段测试，先确定范围、题型、题量、分值与时限，统一交卷后显示答案和完整报告。

两种模式都保存实际使用的题目、答案和当次作答依据；快速练习不必永久进入题库，也不强迫建立考试配置。用户可将优质临时题在作答后审阅并保存到题库。

### FR-E03：出卷方案

普通模式优先展示范围、题量、题型和难度四项。高级设置再提供总分、时限、考试配置、能力层级分布、必考目标、已有题／新题偏好、错题复习比例及近期重复规避。

点击生成前，展示系统的组卷建议：计划覆盖哪些目标、哪些不覆盖、预计题型和分值。用户可修改、排除或锁定必须覆盖的目标。难度与完成时间为估计，不伪装成经过大量测试校准的结论。

“新题比例”与“错题复习比例”不直接当成互斥分组：一道错题的变式既可能是新题，也可能属于错题复习。界面需解释两者分别描述新旧程度与复习用途。[细化 F1 §3.14]

### FR-E04：题量与覆盖冲突

若题量不足以覆盖全部目标，必须显示未覆盖项；用户可选择增加题量、减少范围、优先覆盖核心目标或允许适当综合题。不能生成 5 道题却宣称已全面评估 20 项能力。

已有题不足时按用户设置补充生成新题。无法产生有可靠答案的题时，说明缺少的知识或来源，允许减少题数或调整范围，不使用近似重复题偷偷凑数，不静默改变题型、总分或必考范围。

### FR-E05：每道题必须具备的内容

至少包含完整题干、必要条件、题型、关联目标、参考答案或评分细则，以及可核对的知识依据。选择题同时包含选项；主观题说明主要得分点与可接受的等价表达；计算题说明单位、精度或允许误差。

题干不得依赖未展示的“上文”“如图”，除非材料与图实际随题提供。考查条件、公式、代码所需的信息必须完整；不应把不在目标范围内的新知识包装成“高难度”。

可以生成新的数值、案例和应用情境，但解题必须只依赖已确认目标和题干提供的信息。遇到必须引入新理论的扩展题，先明确提示并让用户确认新增目标。

### FR-E06：质量检查与缺陷处理

采用前检查题目是否可解、选项是否满足题型要求、答案是否与知识依据一致、分值是否匹配评分细则、是否重复或相互泄露答案、是否真实评估了绑定目标。

AI 检查通过只表示完成了机器检查，不等于人工核实。明显缺条件、存在多个未声明答案、评分依据冲突的题，不得作为无警告的正常试题交付；应修复、替换或剔除。

### FR-E07：自测保护与题目审核

默认“自测模式”先显示范围、覆盖情况与卷面结构，不显示参考答案；用户选择“使用本卷”确认采用。未人工审题的 AI 题标记为“AI 生成／未人工核验”，不宣称已经由教师验证。

用户可切换“审题模式”查看题干、答案、评分细则并编辑。看过答案的题会记录本次曝光，之后仍可训练，但不作为全新独立测试证据；需要独立测验时可换成未见过的变式。

**采用某份试卷与将题目确认为长期题库资产是两件事。** 新生成题可以作为本卷临时题使用，长期入库在审阅后另行确认；这是本次对原稿题目状态及正式组卷使用方式的补充决策，不以省略答案检查为前提。

### FR-E08：试卷预览、局部调整与锁定

生成后可调整题序与分值、替换指定题、保留满意题、重生成局部内容、保存草稿。修改后重新展示覆盖和总分；替换必考目标对应题时不能悄悄丢失该目标。

正式开始后，本次题干、题序、分值、参考答案与评分细则保持固定。题库后来修改不改变历史卷面。确有错误时走“争议／作废／重评”，保留原始版本与修正说明，而不是悄悄换题。[保留快照原则；F1 §3.15]

### FR-E09：题型范围与答题能力

目标达标版至少支持单项选择、判断、填空和简答；基本计算与文字／代码说明可通过主观题承载。多选及综合分小题可作为随后增强，但需明确各自评分规则。

可输入格式化文字、必要公式和代码内容。代码书写题的 AI 评阅不等同于真实运行结果；没有执行能力时必须写明“未运行验证”，不声称程序已经通过测试。手写图片识别和复杂图形题不作为本版必需能力。

## 9. 在线答题与训练记录

**原稿基础：F1 §3.16—3.17。以下为用户流程细化。**

### FR-A01：开始、保存与继续

开始前展示范围、题数、总分、计时规则和答案可见规则。答题过程中保存已输入内容，显示保存中、已保存或保存失败；中断后可回到同一次未提交训练继续，不默认新建另一份作答。

长卷提供题号导航、已答／未答、稍后检查和剩余时间。切换题目不丢答案；同一试卷再次练习建立新的训练记录，不覆盖前次表现。

### FR-A02：提示、参考答案与外部帮助

练习模式可按题请求提示，优先给思路，再允许查看参考答案，并记录使用情况。正式测试默认交卷前不显示答案；中途决定查看时，提示该题不再作为独立测试证据。

审题阶段看过答案也计入曝光。对系统外查资料、使用其他 AI 或他人帮助，允许用户主动标注；产品不能声称能检测所有外部帮助，也不能把“未记录帮助”说成严格监考的证明。

### FR-A03：计时与交卷

不限时练习可暂停；限时正式试卷默认开始后连续计时，离开页面不等于暂停。到时固定为停止修改并尝试提交已有答案；提交未成功时显示“时间已到，待提交”，保留答案，恢复后完成原次提交，不假装已经交卷成功。

交卷前展示未答题数，用户可返回检查或确认交卷。提交后不直接改动原答案，需要重新练习或进入复核。重复点击交卷不得产生多份训练结果。

### FR-A04：空题、放弃与技术中断

卷面上未答题按预先公布的规则计分，默认零分；但掌握报告区分“未作答”“明确不会”“提交失败／中断”。未作答不自动证明相关能力薄弱。

放弃的练习保留草稿或明确归档，默认不计入正式能力评估。只完成部分题目可保存部分练习结果，报告必须说明覆盖不完整。

## 10. 批改、复核与结果报告

**原稿基础：F1 §3.18—3.19、§9。新增重点是逐目标归因及争议处理。**

### FR-C01：按照题型和事先确定的标准批改

标准明确的单选、判断等按答案规则判断；填空支持事先规定的同义表述、顺序及单位规则，无法确定的等价答案进入复核。主观题按试卷确定的评分细则评阅，不在看到用户答案后随意改变满分要求。

报告包括得分与满分、正确部分、缺失部分、错误部分、对应得分点、参考答案和来源。允许合理的等价表达和不同解法，不只做关键词匹配；若 AI 不能确认另一种解法，应说明不确定而非直接判错。

### FR-C02：多目标题按得分点归因

一道综合题应将小题或得分点对应到具体学习目标。例如 10 分中，目标 A 的计算占 4 分、目标 B 的解释占 6 分；用户分别得到 4 分和 2 分，报告应反映两种不同表现，而不是两个目标都记 60%。

一个得分点同时涉及多个能力但无法区分时，记录“综合证据，无法单独归因”，保留总分，但不产生看似精确的各目标得分。仅作为解题前提出现、没有被直接检验的知识，不获得独立的掌握证明。

### FR-C03：批改结果的采纳与待复核

规则明确且无争议的客观题可直接计入有效结果。AI 主观题先展示评阅结果和依据；无警告部分可由用户一次性接受本次报告，疑似多解、来源冲突、识别失败或评分依据不足的题仍单独待复核。

是否需要复核不能仅依赖 AI 自报的置信度。只要存在上述可见问题，即使 AI 声称很确定，也应保留警告。待复核部分可以显示暂定分，但不进入正式掌握更新；整卷存在此类题时，总分也明确标为暂定。

### FR-C04：申诉、改判与错误题作废

用户可对单题选择“答案可能正确”“评分过严”“题目有误”“考查超出范围”，附上理由，重新请求 AI 复核或自行确认修正结果。自用系统中的“人工复核”指用户自行核对，不暗示存在教师或外部专家服务。

保留原判、改判、理由和当前采纳结果。重评替换该次训练的有效证据，不将旧判和新判算作两次独立学习。用户直接修改分数时显示人工修正来源，这不同于不依附作答的主观自评。

错误题可作废：从有效得分分母、目标证据和错误统计中剔除，展示调整后的有效满分与受影响范围；历史原卷仍可查看。相关目标标为未测或证据减少，不能因为题目作废就反向奖励用户掌握度。

### FR-C05：报告应回答四个问题

**这次表现如何？** 展示得分、有效满分、用时、完成度及暂定／已采纳状态。

**具体哪里会、哪里不会？** 展示逐题反馈和逐目标表现，区分知识错误、计算步骤、遗漏条件、表达不完整等；原因不确定时明确写成可能原因。

**哪些内容还没有测？** 展示已测目标／本次选择目标、未覆盖和未有效评估的项目，不能把范围内所有知识都染成已评估。

**下一步做什么？** 提供回看来源、整理理解、重做错题或做变式的直接入口。报告中的来源链接默认可定位到产生该知识的片段，而不是只回到笔记首页。

## 11. 掌握情况与证据展示

**原稿基础：F1 §2.5、§3.19—3.21、§10。保留证据驱动，调整用户可见状态的组织方式。**

### FR-P01：评估对象和可解释性

系统首先评估“某个用户对某个学习目标的表现”，再汇总到知识点、主题和笔记。不以知识点创建数量、阅读次数、标注数量、图谱连接数或试卷总分直接代替能力。

每次状态变化均可查看依据：哪次作答、哪道题、哪个目标、对应得分点、是否使用帮助、是否已采纳批改。默认显示近期有效表现与证据数量；不把平均正确率直接称为“真实掌握概率”。

### FR-P02：证据使用规则

独立作答、使用提示、看过答案后的作答分别展示。看过参考答案后的正确答案不提升独立掌握等级；提示辅助结果记录为辅助完成，需要无提示验证。

同题多次重做保留所有历史，但不能无限增加独立证据数量；熟练掌握必须有不同题目和不同时点的支持。用户主动声明“猜的”可标为低说服力证据；没有额外信息时，系统不能断言某个正确答案一定是蒙对的。

未测试、批改失败、待复核、题目作废和单纯未作答不当作有效的零分能力证据。知识来源出现问题时，提示检查，不把它误解释为用户能力下降。

### FR-P03：能力、证据与复习三个维度

能力状态沿用并翻译原稿的“未评估、学习中、基础掌握、熟练掌握、薄弱”。证据另显示“有限／较充分”及数量；复习另显示“待安排／已安排／到期／逾期”。

“待复习”不再与“熟练掌握”互斥。用户长期未测试时可以提示“近期证据不足”，但不改写历史成绩，也不未经解释就断言已经遗忘。

### FR-P04：建议采用的首版透明判定规则

以下是**本次建议的试运行产品规则，不是原稿已冻结内容，也不是经过科学校准的能力阈值**。目的是让第一版有可验收的行为；将来可根据实际反馈调整，调整时应保留规则说明和历史依据。

“有效独立结果”限定为：题目及评分无未解决争议、用户未查看该题答案或使用提示、结果已被采纳，并能直接归因到该目标。每道不同题目的独立证据代表记录采用其最近一条符合条件的结果，同题再做不增加题目种类。

| 状态 | 首版建议判定 |
| --- | --- |
| 未评估 | 没有有效独立结果；仅有辅助练习时同时显示辅助完成记录 |
| 薄弱 | 最近两道不同题目的有效独立目标得分均低于各自满分的 60%；仍附证据充分度 |
| 熟练掌握 | 至少五道不同题，覆盖至少两个不同日期；最近五道的有效独立目标得分均达到 80%，且直接考查了该目标要求 |
| 基础掌握 | 至少三道不同题，分布在至少两次训练中；最近三道有效独立目标得分均达到 60%，且不满足熟练条件 |
| 学习中 | 已有有效独立结果，但尚不满足其他条件；一次做错不会自动成为稳定误区 |

判定次序为未评估、薄弱、熟练掌握、基础掌握、学习中。证据达到“三道不同题、两次训练”之前默认显示有限；不把五道题就视为绝对可靠。数字可调整，但“证据可追溯、未测不算错、辅助不当独立、重复不无限累积”不可取消。

本版不默认使用未解释的时间衰减公式。调整规则导致状态变化时，要能区分“新作答改变结果”和“评价规则更新”，不能让用户误以为自己答过未做的题。

### FR-P05：知识、笔记与主题汇总

一个知识下有 4 个目标，只测了 1 个，即使该目标表现很好，也应显示“已评估 1/4，其他未测”，不能标记整项知识全部掌握。

建议汇总：全部未测为未评估；存在薄弱目标则显示“存在薄弱目标”及覆盖数；没有薄弱但尚有未测则显示部分已评估；全部目标基础及以上才汇总为基础掌握；全部达到熟练才汇总为熟练掌握。学习中目标不能被平均分掩盖。

主题与笔记按目标去重统计。同一个目标因多个知识来源或多主题归属出现多次时，不重复计数。汇总分母始终说明是“已经整理并确认的目标”，不声称覆盖了该学科全部知识。

### FR-P06：自评与系统评估并列

用户可标注“没学过、有印象、不太理解、感觉掌握”，并看到它与训练证据是否一致。自评可影响复习意愿和排序，但不覆盖系统的证据状态。[保留；F1 §3.21]

用户认为“会了”但系统证据不足时，文案表达为“尚缺测试依据”，不是否定用户。用户不认可某次结果，应修改对应批改或排除不合适的证据，而不是直接改系统掌握数字。

## 12. 错题、误区与复习闭环

**原稿基础：F1 §3.22—3.23；F2 §6.4。以下为操作规则细化。**

### FR-R01：错题与待复核题分开

已采纳的错误或部分正确作答进入错题记录，展示原题、本人答案、反馈、学习目标和知识来源。待复核题先进入争议列表，不提前贴上“你不会”的标签。

错题可标注错因、添加个人总结、标记已复习；仅标“已复习”不等于验证掌握。用户可在新训练中重做原题，也可生成相同目标的新情境变式题。

### FR-R02：误区保持候选性质

一次答错可以提出可能的错误理解，但必须写明“可能”，不自动形成永久误区。多次表现一致或用户明确确认后，才作为持续关注项；后续可标为已解决或误判。[保留；F1 §3.22]

错题解析若指出原笔记可能有错误，可发起知识修订候选；不得把用户的错误答案直接沉淀成新的正确知识。

### FR-R03：可执行的复习建议

复习列表显示目标、建议动作、安排日期与推荐理由，至少支持回看原文、主动回忆、原题重做和变式练习。优先考虑薄弱目标、证据不足但用户标为核心的目标、到期项目和用户指定考试重点；推荐理由可查看。

用户可接受、改期、暂缓或取消。系统不因错题数量增加就无限堆任务；同一目标的多个建议可以合并，并允许按用户愿意投入的题量筛选。

首版可采用透明的固定安排，例如错误纠正后次日做变式、一次验证成功后数日再测；必须显示为默认安排而非“精确预测遗忘时间”，用户可调整。不要求先建立完整任务或游戏化系统。

### FR-R04：复习完成后的反馈

阅读原文、修改个人理解、完成答题分别记录。只有产生新的有效作答证据时才更新系统掌握情况；完成一次阅读型复习可以结束该阅读任务，但仍提示是否需要验证。

变式题答对后回到知识详情和图谱可看到相应状态变化及依据。复习目标可以结束、再次安排或撤销，避免出现只能不断累加而无法收口的队列。

## 13. 内容变化、异常与信任边界

### 13.1 变更影响规则

**以下是对 F1 §3.2、§5.5、§9 的细化。历史内容保留与当前出题资格分开判断。**

| 发生的事情 | 用户应看到的结果 | 后续训练处理 |
| --- | --- | --- |
| 取消或删除重点 | 正文及已有知识保留，标注消失 | 不自动撤销已确认知识 |
| 笔记仅改排版，来源位置不明 | 保留旧摘录，提示重新定位 | 确认内容仍一致后恢复正常使用 |
| 来源知识内容实质变化 | 展示差异，知识／目标待检查 | 受影响部分暂停新增正式试卷，其他部分可用 |
| 笔记删除、唯一来源不可用 | 显示来源不足，保留历史依据说明 | 补充来源或明确采用为人工整理后方可继续 |
| 多个来源中的一个失效 | 显示失效项，检查剩余依据 | 其余来源足够且内容未冲突时不必整项停用 |
| 知识合并或拆分 | 展示关联变化，不复制历史能力 | 仅可可靠映射的题目证据进入新目标 |
| 修改或归档题库题 | 当前题库变化，历史卷面不变 | 不继续新选已归档题；旧卷可复盘 |
| 批改改判或试题作废 | 保留原判与原因，调整有效结果 | 更新相应证据与复习建议，不重复加分 |

原卷已经开始后，不因来源变化偷偷替换题目；在提交或报告阶段提示风险并进入复核。删除内容不等于立即擦除历史考试依据，本版按可恢复归档处理；彻底清除个人历史属于另一个明确的删除动作。

### 13.2 AI 和操作失败

分析、出题、批改应显示正在处理、部分完成、完成、失败、取消等状态。用户可离开当前页面再查看结果；失败时能重试失败部分，不必重复已确认内容。

取消任务不删除来源。已保存的候选、试卷草稿和作答保留；未完成结果不被写成完整成功报告。批改暂不可用时显示“已交卷，待批改”，不伪造分数。

重复触发同一操作不应制造一堆候选、试卷副本或多次掌握提升。若用户确实想重新生成，应有明确入口，并保留本次与上次的区别。

### 13.3 来源、AI 能力和隐私可见性

用户应能看清本次 AI 实际会处理哪些笔记和片段，排除不愿纳入的内容。默认不把全部知识库当作每次任务的隐含输入。

知识、关系、题目和报告均区分人工整理、AI 建议、用户采用及已核对来源，不以“AI 置信度很高”取代来源。没有读到的材料、没有运行的代码、没有测试的目标，不得声称已经完成处理。

## 14. 页面与核心操作分工

本章只定义入口与内容职责，不规定视觉风格、组件和布局实现。延续原稿三类页面，不因内部概念增多就新建大量一级菜单。[F1 §8；F3 UI 规范 §1、§4、§11]

| 页面 | 默认需要完成的事 | 按需展开的内容 |
| --- | --- | --- |
| 笔记／资料库 | 阅读编辑、三种重点、提炼、查看关联知识 | 重点清单、来源状态、候选确认 |
| 知识库 | 知识列表、主题、知识点／笔记图谱切换 | 目标编辑、关系候选、来源历史、个人解释 |
| 训练中心 | 选择范围、生成练习或试卷、继续答题、历史报告 | 考试配置、高级出卷、题库管理 |
| 报告／复习视图 | 看反馈、复核、回原文、做错题和变式 | 证据明细、误区候选、复习日历 |

学习目标可在知识详情中直接编辑；考点只在考试场景出现；评分细则在作答前默认隐藏；掌握计算细节按需查看。用户主要感知的是“资料、知识、训练、复习”，不是逐一操作领域对象。

## 15. 分阶段交付与目标达标条件

### 15.1 三个可用阶段

**阶段 A：把资料变成可信知识。** 交付三种重点、AI 提炼、来源回链、知识与目标确认、列表管理以及一小段可作答快速练习。完成后用户每天整理笔记就能真正用上，而不是只有管理入口。

**阶段 B：把训练变成完整评价。** 交付基本正式组卷、在线答题、逐题及逐目标反馈、争议复核、透明掌握规则、错题和复习回链。包含答案曝光保护和未测范围提示。

**阶段 C：让知识与训练在图谱中联动。** 交付局部知识点图谱、基础笔记图谱、双向来源跳转、薄弱筛选与从图中发起训练。无需等待大规模全局图谱或复杂自动布局。

这三个阶段都是用户可以实际操作的完整场景，不是把所有内容先做成内部能力后再补前台。A 的最小快练不是 B 的正式试卷；A、B、C 都完成，才达到本次“可视化知识库＋试卷系统”目标。

### 15.2 达标版与增强版

| 达标版必需 | 后续增强 |
| --- | --- |
| 选区、块、标题重点及范围预览 | 更复杂的标注样式和批量整理 |
| 来源可追溯、候选确认、增量提炼 | 多模态资料自动理解与深度核验 |
| 知识点图谱、基本笔记连接与联动 | 大规模全局混合图谱、自动学习路径 |
| AI 出题、基本正式试卷、在线答题 | 复杂组卷模板、适配多种真实考试 |
| 逐目标评价、复核、证据可解释 | 校准后的能力估计和自适应测验 |
| 错题、变式、原文复习闭环 | 复杂遗忘模型、自动周计划与周报 |

## 16. 用户场景验收清单

验收以真实操作和可见结果为准。下表的例子是建议测试场景，不代表已在当前产品中运行通过。

| 编号 | 用户操作或异常场景 | 通过标准 |
| --- | --- | --- |
| AT-01 | 给一个二级标题设重点 | 覆盖全部下级内容，在下一个同级或更高级标题前结束 |
| AT-02 | 在重点标题内新增段落并调整标题层级 | 新段落按规则纳入；边界改变时可见提示 |
| AT-03 | 同一段同时有选区、块、标题重点 | 标记分别保留，提炼内容不重复计入 |
| AT-04 | 取消重点块 | 文字、代码或公式原样保留，已有知识不被删除 |
| AT-05 | 整篇笔记没有任何标注 | 仍可分析整篇并产生候选知识 |
| AT-06 | 重点存在指代、公式缺少变量说明 | 扩展必要上下文或提示不足，不凭空补造结论 |
| AT-07 | 笔记包含尚未识别的图片 | 明确列为未纳入内容，不声称图片已被理解 |
| AT-08 | 同一知识在两篇笔记出现 | 提议关联已有知识并增加来源，不直接生成永久副本 |
| AT-09 | 两处来源表述冲突 | 分别展示依据并待处理，不悄悄改成统一结论 |
| AT-10 | 修改 AI 候选后重新运行分析 | 保留人工修改，提供差异，不直接覆盖 |
| AT-11 | 只确认知识、未确认学习目标 | 可进入知识管理；出卷明确提示目标尚不可用 |
| AT-12 | 没有考试大纲却要求生成重点 | AI 建议标明推测，不显示为官方高频依据 |
| AT-13 | 从同一知识切换到来源笔记 | 能定位来源片段，再返回相同知识 |
| AT-14 | 两篇笔记共享一个知识 | 连接标为共享知识并能展开依据，不说成互相引用 |
| AT-15 | AI 建议两知识之间是因果关系 | 未确认前不混入正式关系；可以查看理由并拒绝 |
| AT-16 | 在图中移动或取消一条连线 | 只改变布局或关系，不删除内容、不改变掌握度 |
| AT-17 | 选 12 个目标但只要 3 道题 | 明确显示覆盖方案和未覆盖范围，不宣称全面测评 |
| AT-18 | 只替换试卷中的一道题 | 其他题不变，并重新检查总分与必考目标 |
| AT-19 | 用户审题时看了参考答案 | 后续该题有曝光标记，不作为全新独立测试 |
| AT-20 | 做题中关闭页面再返回 | 能继续原次训练，已保存答案与计时规则一致 |
| AT-21 | 到时或交卷时网络失败 | 答案保留，显示待提交，不出现虚假的已交卷 |
| AT-22 | 综合题 A 得 4/4、B 得 2/6 | 分别记录目标表现，不都记为整题 60% |
| AT-23 | AI 无法确定另一种解法 | 进入复核；暂定得分不直接更新正式掌握状态 |
| AT-24 | 批改改判或整题作废 | 调整有效得分和证据；不新增第二次学习记录 |
| AT-25 | 一个知识的四个目标只测一个 | 显示覆盖 1/4，不能给整项知识“全部掌握” |
| AT-26 | 看过答案后连续重做同一道题 | 不无限提高独立掌握等级，建议做未见变式 |
| AT-27 | 用户只读笔记并点“我会了” | 自评可改变，系统独立证据不被覆盖 |
| AT-28 | 已熟练目标的复习日期到期 | 同时显示熟练与待复习，而非自动改为薄弱 |
| AT-29 | 删除标记、来源笔记或归档题目 | 分别执行影响规则；历史试卷和作答不被改写 |
| AT-30 | 知识合并或拆分 | 展示影响，历史依据不重复计数、不直接复制能力 |
| AT-31 | 从错题打开来源，再做一题变式 | 形成新作答和有效证据，知识页及图谱同步反映结果 |
| AT-32 | AI 提炼或批改只完成一部分 | 已完成结果保留，失败部分可重试，报告注明未完成 |

**验收结论必须同时覆盖两条成果链。** 能生成图但不能解释连接、不能返回来源，不算可用的可视化知识库；能生成题但不能作答、复核和解释目标表现，不算完整试卷系统。

## 17. 与原冻结稿的对照及本次建议决策

### 17.1 保留的骨架

保留笔记与知识分离、知识与学习目标分离、考试考点可选、来源可追溯、一题多目标、试卷历史固定、学习证据驱动掌握、自评分离、AI 候选先审阅等规则。[F1 §2—5、§9]

### 17.2 本次建议明确增加或调整的事项

建议增加三种统一语义的重点范围与继承／排除规则；AI 提炼的输入、质量、冲突和增量处理；笔记图谱及跨视图回链；正式组卷的实际覆盖报告；临时试卷题与长期题库确认的区分；审题答案曝光记录；逐目标评分归因；改判与作废联动。

建议将“能力状态、证据充分度、复习到期”分开显示。掌握算法依然可以演进，但首版不再只留一个未定义的百分比：第 11 章提供可解释、可替换的试运行规则。

建议保留原稿第一版快速练习定位，同时新设本文件的目标达标版，不把全局图谱、大型组卷、复杂算法全部提前塞入第一步。
