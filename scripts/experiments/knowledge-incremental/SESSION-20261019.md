费用约束：每请求 messages 序列化 UTF-8 至多 65,536 字节（发送前拒绝），max_tokens=4096。按每输入字节至多一个 token 的保守文本估算，并额外预留每请求 4096 输入 token 消息包装余量，采用峰价输入 2 元/百万、输出 8 元/百万：20 × ((65536+4096)×2 + 4096×8) / 1,000,000 = 3.44064 元，低于已授权 10 元余额。此为按当前计费与字节近似计算的保守费用估计，非供应商账单强制金额封顶；代码强制请求次数、输入字节及输出 token 上限。实际费用从 token usage 复算，失败也消耗请求额度。
